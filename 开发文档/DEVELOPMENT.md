# 开发日志

## 2026-10-09 — 1.11.0

- 新增：页面网址改为 `/p/<slug>/`。front matter 的 `slug` 用于手写英文网址，没写的页面按源文件路径生成 8 位短 ID；实现位于 `tools/obsidian_compat/urls.py`。
- 新增：构建时为每个页面的原中文路径生成跳转页，旧链接继续可用。
- 新增：slug 格式错误或重复时报 `E_SLUG_INVALID`、`E_SLUG_DUPLICATE`，旧路径与现有页面冲突时报 `E_REDIRECT_CONFLICT`。
- 内容：`04技术` 的 6 篇文章写上了 slug。
- 兼容性：不改动 Obsidian 文件名、目录和双链；评论区（按 pathname 匹配）和不蒜子访问统计会按新网址重新计数。

## 2026-10-08 — 1.10.0

- 新增：顶栏右侧链接到 GitHub 仓库（`mkdocs.yml` 的 `repo_url`），页脚显示 GitHub、X、哔哩哔哩、抖音图标（`extra.social`）。
- 兼容性：不改变 Obsidian 原始笔记、兼容转换行为或页面路径。

## 2026-10-07 — 1.9.0

- 新增：`tools/build_site.py` 的 `UNPUBLISHED_PATHS` 指定不部署到网站的一级目录或根目录文件（目前为 `07自己`、`AGENTS.md`）；这些页面及只被它们嵌入的附件不进入站点，公开页面指向它们的双链渲染为纯文字。
- 调整：一级目录重排，`03思考` 拆分为 `03学习方法论`、`05二次元`、`06读书`、`07自己`，作品、技术、归档目录依次改为 `08作品`、`04技术`、`09归档`。
- 兼容性：未发布页面仍参与双链检查，缺失或歧义引用照常阻止构建；它们仍随 Git 推送到 GitHub 仓库。

## 2026-10-07 — 1.8.0

- 新增：除首页外的页面底部显示 Giscus 评论区，留言存放在仓库 GitHub Discussions；参数位于 `mkdocs.yml` 的 `extra.giscus`。
- 兼容层增强：支持 Obsidian 内置 Callout 类型及别名（`tip`、`important`、`info`、`danger` 等）、表格内转义的双链别名 `[[目标\|别名]]`，以及图片嵌入尺寸 `|300`、`|300x200`。
- 修复：Callout 标题内的双链等内联语法此前未转换，会以原始文本出现在页面上。
- 兼容性：不改写 Obsidian 原生笔记；自定义 Callout 类型与非尺寸的嵌入选项仍会报错并阻止构建。

## 2026-09-20 — 1.7.0

- 新增：支持 Web 端 LaTeX 数学公式渲染（行内 `$...$` 与独立块 `$$...$$`）。
- 引入 MathJax 3 与 `pymdownx.arithmatex` 扩展，支持即时导航（`navigation.instant`）下公式动态重绘。
- 兼容层增强：自动隔离紧随正文的独立公式块，避免被换行规则破坏；公式内部角标与符号不干扰页面锚点解析。
- 兼容性：不改写 Obsidian 原生笔记，构建与全库回归测试全量通过。
