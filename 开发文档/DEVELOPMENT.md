# 开发日志

## 2026-09-20 — 1.7.0

- 新增：支持 Web 端 LaTeX 数学公式渲染（行内 `$...$` 与独立块 `$$...$$`）。
- 引入 MathJax 3 与 `pymdownx.arithmatex` 扩展，支持即时导航（`navigation.instant`）下公式动态重绘。
- 兼容层增强：自动隔离紧随正文的独立公式块，避免被换行规则破坏；公式内部角标与符号不干扰页面锚点解析。
- 兼容性：不改写 Obsidian 原生笔记，构建与全库回归测试全量通过。
