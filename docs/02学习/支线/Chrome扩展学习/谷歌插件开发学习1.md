## manifest.json文件

这是每一个插件必须要有的文件，里面会简单介绍插件的信息，以及插件的配置。
```json
{
    "name": "Running", // 插件名字
    "description": "Show the extension running", // 插件简介
    "version": "1.0", // 插件版本
    "manifest_version": 3, // manifest的版本
    "action": {
	    // 点击插件图标弹出的页面————弹出指定的html文件
        "default_popup": "running.html"
    },
    // 脚本
    "content_scripts": [
        {
	        // 执行指定的脚本
            "js": [
                "scripts/content.js"
            ],
            // 在哪一个网页中执行
            "matches": [
                "https://developer.chrome.com/docs/extensions/*",
                "https://chat.deepseek.com/*"
            ]
        }
    ]
}
```
> [!note] 小结
> Popup = 插件自己的小页面
Content Script = 插件派进目标网页里运行的 JS

## JavaScript

```js
console.log("我的插件运行了");
const div = document.createElement("div");  // 创建一个div
div.textContent = "我的插件运行了";           // 为div添加文本内容

// 设定div的样式
div.style.position = "fixed";
div.style.top = "20px";
div.style.left = "20px";
div.style.zIndex = "999999";
div.style.background = "white";
div.style.padding = "10px";
div.style.border = "1px solid black";

// 把div添加到页面
document.body.appendChild(div); 

// 定义一个控制台打印函数
function handleSend(text) {
    console.log('准备发送：', text);
}

// 监听document           // 监听的是按键按下
document.addEventListener('keydown', function (event) {
    // 监听特定的按键
    if (
        event.target.tagName === 'TEXTAREA' && // 事件发生的区域的名字得是“TEXTAREA”
        event.key === 'Enter' &&               // 事件发生的按键得是回车键
        !event.shiftKey                        // 按下的按钮不能有shift键
    ) {
        handleSend(event.target.value);        // 执行控制台打印函数，把事件发生的目标的值传入
    }
}, true);

// 监听document           // 监听的是鼠标点击
document.addEventListener('click', function (event) {
    const sendButton = event.target.closest(
        '[role="button"].ds-button--primary.ds-button--circle'
    );
    if (sendButton) {
        const input = document.querySelector('textarea');
        handleSend(input.value);
    }
}, true);
```
## 事件的阶段

一个事件发生，会经过2个阶段：**捕获**和**冒泡**。

捕获是这个指令的发生。比如点击一个发送按钮，捕获阶段是：从最外层到最内层。
```text
document      ← 捕获
   ↓
body          ← 捕获
   ↓
点击的元素
```

而冒泡阶段则是**返回这个事件发生的具体信息**的经过顺序，是从内向外。
```text
点击的元素
   ↑
body          ← 冒泡
   ↑
document      ← 冒泡
```
