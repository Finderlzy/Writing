双向链表是[[02学习/⭐概念/链表|链表]]的一种，和单向链表不同的是，每个结点除了指向后一个结点，还指向前一个结点。

```cpp
struct Node {
    int value;    // 存储的数据
    Node* prev;   // 指向前一个结点
    Node* next;   // 指向后一个结点
};
```

## 和单向链表的区别

单向链表只能从头往后走，要找一个结点的前驱就得再从头遍历一遍。双向链表的每个结点自己记录前驱，所以往两个方向都能走，插入和删除时也不用为了拿到前驱而重新遍历。

代价是每个结点多存一个指针，占用的空间更大，维护的时候两个方向的指针都要改。
