想象这么一个场景：在一个父类下有很多子类，每一个子类都有一个`work()`方法，并且每一个子类的具体工作内容不一样。那么问题来了：父类的`work()`方法该怎么写？

Java提供了抽象方法这个解决方案——也就是不写方法体，只需要在前面加上一个`abstract`修饰符使这个方法变为一个抽象方法。与此同时，这个类会自动变成抽象类。

```java
public abstract class Animal {  
    private String name;  
    private int age;  
  
    public abstract void eat();  // 这个就是抽象方法
}
```

> [!warnnig] 注意
> 1.抽象类不可以创建对象
> 2.抽象类的子类必须重写**所有的**抽象方法

## 好处
---
方便多人协作。只要把父类抽象类写好了，后续队友开发的时候按照抽象方法的格式创建方法就可以了。
