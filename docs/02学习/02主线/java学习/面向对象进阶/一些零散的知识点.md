## 包
---
在Java中，包就是文件夹，包是用来管理类的。一般来说，会把**同种功能的类**放在同一个包下。包的命名是：**公司域名的反写+包的作用**。

e.g.  `com.itheima.domin` 。而 `domain`  是用来放“**描述业务对象**”的类。

下面是一些常见的包及其作用

| 包名           | 一般放什么                            |
| ------------ | -------------------------------- |
| `domain`     | 业务对象，如 `Student`、`User`、`Animal` |
| `service`    | 业务逻辑，如“添加学生”“计算成绩”               |
| `controller` | 接收请求、调用业务逻辑                      |
| `util`       | 工具类                              |
| `test`       | 测试类                              |

## final

^e68fc5

---
final ”最终的“

1. final关键字修饰**类**，则这个类不能被[[02学习/02主线/java学习/面向对象进阶/继承/继承|继承]]
2. final关键字修饰**变量**，则这个变量是常量，存储的值不能被改变。注意：如果是引用数据类型，由于变量存储的值是地址值，所以不能被改变的是这个地址值。里面具体值是什么还是可以改变的。
3. final关键字修饰**方法**，则这个方法不能被[[02学习/02主线/java学习/面向对象进阶/继承/方法重写|重写]]。

## 代码块
---
### 定义

被`{}`围起来的部分就叫做代码块

### 局部代码块(被淘汰了)

作用：提前结束变量的生命周期，节约内存。但现在硬件发展的很好，因此被淘汰了

### 构造代码块(不够灵活)

写在类里面，构造方法之前的代码块。在每次创建对象的时候都会执行一次。

### 静态代码块

也是写在类里面，构造方法之前的代码块，只是会用[[02学习/02主线/java学习/面向对象进阶/static/static|static]]关键字修饰。**会在类第一次加载的时候执行一次**，==一般是用来初始化==。正因如此，在静态代码块执行的时候，一般来说都不会有实例对象，因此会说”静态代码块只能使用静态的变量和方法“。

本质是：==静态环境中可以直接访问静态成员；不能直接访问实例成员。要访问实例成员，必须先有具体对象==。
