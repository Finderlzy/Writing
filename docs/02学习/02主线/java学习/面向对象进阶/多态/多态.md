## 定义
---
顾名思义，多种形态。准确地说，是**对象的多种形态**。
> [!question] 疑问
> 何为“对象的多种形态”，这句话不好理解

在Java当中，多态具体指的是：**父类类型的变量接收子类对象**。`Person p = new Student();`
## 为什么会出现多态
---
想象一下这个场景：在教务管理系统中，有3种用户——`student`,`teacher`,`admin`。用户第一次使用肯定要注册嘛。这个时候就会出现一个问题：注册的方法要写3个一样的吗？如果是这样，那么如果后续又增加一个用户，那岂不是又要写一个新的方法？

多态就是解决这个问题的。在上述问题中，只需要写一个注册方法，而**这个方法的形参是这几个类的共同父类**即可。

假设这几个类（父类和子类）都有同一个名字的方法，多态还可以根据传进来的对象自动选择方法。
