## 结论
---
调用成员变量：==编译看左边，运行也看左边==
调用成员方法：==编译看左边，运行看右边==
如果调用的时候，左边没有调用的那个东西，直接报错。

什么叫“左边“，什么叫”右边“？看创建对象的那个语句

`Animal a = new Dog();`
   左边                  右边

> [!note] 理解
> 看调用的是哪种类型
> 像`a`,它是`Animal`类型的变量，当然是调用`Animal`的变量。
> 而方法，由于接收的是子类对象的数据，而子类对象[[02学习/02主线/java学习/面向对象进阶/继承/方法重写|方法重写]]之后会覆盖掉父类的方法，因此调用的是子类的方法。记忆就用”运行看右边“。
