## 为什么会有接口
---
假设一个父类下面有很多个子类，其中除了A子类，其余子类都有一个`swim()`方法。这个时候，如果把`swim()`写在父类下面不合理；给每一个其余子类写一个可能会出现一个子类写作`swim()`，另一个写作`swimming()`的情况。

接口的第一个作用就是规范。只要实现了这个接口，就得按接口规范的格式，[[02学习/02主线/java学习/面向对象进阶/继承/方法重写|重写方法]]。

## 接口的定义
---
新建一个`Interface`选项。

```java
public Interface swim(){
	public abstract swim();
}
```

使用的时候，通过`implements`来确定这个类要实现哪些接口。实现接口必须重写里面的所有抽象方法。

```java
public Class frog implements swim{
	@Override
	public abstract swim(){
		sout("狗刨");
	}
}
```

## 关于接口的深入理解
---
```text
但接口更重要的价值会在这里体现：

public static void goSwimming(Swim s) {
    s.swim();
}

这个方法根本不关心传进来的是 `Dog` 还是 `Frog`：

goSwimming(new Dog());
goSwimming(new Frog());

都可以。

因为这个方法只要求：

你是谁不重要，只要你实现了 `Swim`，我就知道你一定有 `swim()` 方法。

这就是接口除了“规范”之外非常重要的意义：让代码依赖“能力”，而不是依赖某一个具体的类。
```
