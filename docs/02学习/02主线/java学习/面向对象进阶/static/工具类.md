## 用来做什么的
---
工具类和[[02学习/02主线/java学习/day02/JavaBean类|JavaBean类]]不一样，不是用来描述一个东西的，而是作为一个工具。这个类里面提供了很多方法可以拿来使用。

突然很喜欢Java语言，什么东西都井井有条的。

## 特点
---
1. 构造方法私有化，也就是无法构造一个工具类的对象。
2. 这个类提供的方法使用static修饰。老师没说是什么原因。 ^37267f
```Java
package com.itheima.a03staticdemo3;  
  
import java.util.ArrayList;  
  
public class StudentUtil {  
	// 私有化构造方法
    private StudentUtil(){};  
	  
	// 提供的方法使用static修饰
    public static int getMaxAge(ArrayList<Student> list){  
        int max = list.get(0).getAge();  
        for (int i = 1; i < list.size(); i++) {  
            int tempAge = list.get(i).getAge();  
            if(tempAge > max){  
                max = tempAge;  
            }  
        }  
        return max;  
    }  
}
```
