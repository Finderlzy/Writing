## 结论
---
==子类不会继承父类的构造方法==

==子类的所有构造方法都会：先调用父类的空参构造，再调用自己==。因为子类的构造方法可能会给从父类继承下来的变量赋值。

`super()`这个是调用父类的空参构造。所有的子类构造方法的第一行，如果我们不写，虚拟机会自动帮我们写。因此，==子类构造的第一有效行，必须是`super()`==，也就是不能写别的。如果想写别的在构造方法里，那就自己先补上`super()`再写别的。比如：
```java
public class Manager extends Employ{  
    private int managerMoney;  
  
    public Manager(){  
        super();  
        System.out.println("hello");  
    }
}    
```
