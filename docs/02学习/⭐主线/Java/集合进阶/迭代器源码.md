## 基本
---
迭代器维护三个变量：

`int cursor`（当前指向的地方）

`int lastRet`（上一次操作的地方）

`int exceptedModCount`（记录创建迭代器的时候，这个集合操作了多少次）

> [!note] `next()`方法为什么这么绕？
> 1.因为这个方法是要**返回一个东西的**，也就是说，它最后一定是`return ...`
> 2.Java不愿意多拿一个变量来存**当前获得的元素**
>
> 所以这个方法**先移动cursor**，再使用**lastRet**去得到返回值
