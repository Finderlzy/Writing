## 概述
---
不确定的数据类型


## 使用
---
`<>`

定义泛型类、泛型方法、泛型接口。定义的时候<>里面一般写：T（type）、E（element）、K（key）、V（value）

在创建对象的时候，比如ArrayList，就可以在泛型当中，**写入这个集合要存储的数据类型**。


## 通配符
---
`?`

可以用来限定泛型里面的数据类型

```java

< ? extends 父类> 这个泛型可以传入“父类”及其所有子类

< ? super 子类>   这个泛型可以传入“子类”及其所有父类
```
