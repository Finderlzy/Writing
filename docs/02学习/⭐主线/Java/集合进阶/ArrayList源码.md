## 基本
---
ArrayList在底层是使用[[02学习/⭐主线/Java/集合进阶/线性数据结构#^1fd871|数组]]去存储数据的

ArrayList用来表示长度的变量`size`同时也用来表示**下一个添加的元素要存入的位置**。

ArrayLIst的空参构造是创建一个长度为0的数组


## 扩容机制
---
使用空参构造之后，第一次添加元素会扩容到长度为10。

接下来如果再次添加满了，这一次（一个一个地添加）扩容就会扩到**原来的1.5倍**。

但是如果是一次性添加很多个，就会直接扩容到**正好的长度**。
