## What
---
定义在[[02学习/⭐主线/Java/day01/class|类]]当中的类
```java
public Class Car{
	String carName;
	
	Class Engine{
		String engineName;
	}
}
```

## 什么时候使用内部类
---
当B类是A类的一部分，且B类单独存在意义不大。如上方：引擎是汽车的一部分，且引擎单独存在意义不大。

## 使用内部类时的注意事项
---
内部类可以直接访问外部类的成员，**包括私有的**。

但是，外部类想要访问内部类的东西，**必须先创建一个内部类对象**。很好理解，在创建外部类对象的时候，内部类对象并没有被一起创建。 

> [!question] 疑问
> 为什么？如果不会，它们怎么联系？

> [!note] 解决疑问——内存视角
内部类的字节码文件和外部类的字节码文件是分开的。
>
>创建外部类对象的时候，并不会自动创建一个内部类对象。但是，在创建内部类对象的时候，虚拟机会**自动加上一个变量`Outer.this`用来记录外部类对象的地址值**。别忘了：[[02学习/⭐主线/Java/面向对象进阶/内部类/成员内部类#^f60db9|直接创建内部类对象的时候，需要先创建一个外部类对象]]。
