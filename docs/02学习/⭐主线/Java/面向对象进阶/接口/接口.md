## 对接口的深入理解
---
接口定义的是一种**能力**。在今天的作业中，乒乓球运动员、教练和篮球运动员、教练都是人，而能不能说英语是一种能力。因此，单独做一个接口实现说英语，这样子规划才合理。

## 接口的写法
---
如果接口写为：
```java
public interface SpeakEng {
    public static void speak() {
        System.out.println("English");
    }
}
```
由于[[02学习/⭐主线/Java/面向对象进阶/static/static的深入理解|static]]关键字的存在，会把这个`speak()`方法提升到类所有，也就是说：**实现这个接口的对象是无法使用这个方法的**。

正确写法是这样：
```java
public interface SpeakEng {
	public abstract void speak();
}
```
这是在说明：**所有实现这个接口的对象，都要有一个这个方法**。因此实现类必须[[02学习/⭐主线/Java/面向对象进阶/继承/方法重写|重写]]这个方法。

## 为什么会有接口
---
假设一个父类下面有很多个子类，其中除了A子类，其余子类都有一个`swim()`方法。这个时候，如果把`swim()`写在父类下面不合理；给每一个其余子类写一个可能会出现一个子类写作`swim()`，另一个写作`swimming()`的情况。

接口的第一个作用就是规范。只要实现了这个接口，就得按接口规范的格式，[[02学习/⭐主线/Java/面向对象进阶/继承/方法重写|重写方法]]。

## 接口的定义
---
新建一个`Interface`选项。

```java
public Interface swim(){
	public abstract swim();
}
```

使用的时候，通过`implements`来确定这个类要实现哪些接口。实现接口必须重写里面的所有抽象方法。

```java
public Class frog implements swim{
	@Override
	public abstract swim(){
		sout("狗刨");
	}
}
```

于是这个类就被称为**实现类**。
