## 虚方法表

^7e1361

---
一个类中，所有**不被`private`、`static`、`final`修饰的方法**都是虚方法。

Java会把所有虚方法加载到虚方法表当中，并被子类继承下去。而子类又会添加自己的虚方法，如此下去，提高了运行的效率。
