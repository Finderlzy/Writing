## 时间原点
---

是C语言诞生的那一天——1970年1月1日

## Date类
---
### 空参构造

获取当前的时间
```java
Date d = new Date();
```

### 有参构造

传入的long类型数据会被Java理解为**从时间原点开始过了多少毫秒**。
```java
Date d2 = new Date(0L); // 从时间原点开始过了9毫秒
                    ↑
    // 因为是long类型，所以写一个“L”会好一些
```

### get

获取到Date对象存储的时间，可以用来比较时间的**早晚**。

### set

修改Date对象的时间
