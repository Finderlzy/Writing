## 目标
---
接下来做的一切都是为了**得到一个功能的门电路**。

## 列出真值表
---
先确定这个功能的输入与输出，这里假设输入是$x_1、x_{2}$，输出是$y$。

然后根据输入的情况以及输出的值，列出真值表。
> [!note] 小建议
> 输入的情况按二进制数值来排序

| 编号  | $x_{1}$ | $x_{2}$ | $y$ | 最小项                  | 最大项                               |
| --- | ------- | ------- | --- | -------------------- | --------------------------------- |
| 0   | 0       | 0       | 0   |                      | $M_{0} = x_{1} + x_{2}$           |
| 1   | 0       | 1       | 0   |                      | $M_{1} = x_{1} + \overline x_{2}$ |
| 2   | 1       | 0       | 0   |                      | $M_{2} = \overline x_{1} + x_{2}$ |
| 3   | 1       | 1       | 1   | $m_{3} = x_{1}x_{2}$ |                                   |
<div align="center"><b>表1：与门真值表</b></div>

## 写逻辑表达式
---
使用**最小项表达**或者**最大项**表达。

 最小项：对于所有输出为1的那一行，输入为1则为原变量，输入为0则为反变量，最终最小项是**与**的结构。
 
对于上方的真值表，最小项表达（使用最小项去表达这个逻辑表达式）为：$y = x_{1}x_{2}$。也可写为：$y = m_{3}$，因为输出为1是编号3（输入的情况转为二进制数值）。如果还有$m_{4}、m_{5}$，则$y = m_{3} + m_{4} + m_{5}$。----**积之和**。

最大项：和最小项表达式**完全相反**，对于所有输出为**0**的那一行，输入为**1**则为**反变量**，输入为**0**则为**原变量**，最终结果是**或**的结构。

对于上方的真值表，最大项表达为：$y = M_{0} * M_{1} * M_{2}$。----**和之积**。

最大项和最小项的关系，取反，德摩根定律。

## 化简
---
得到逻辑函数的表达式之后，可以直接使用，但是电路图会很复杂，因此需要化简。化简的方法有2种，第一种是代数形式，也就是使用[[02学习/⭐主线/数字逻辑/1.1~1.2 逻辑函数化简方法|1.1~1]]。

还有一种方式是使用**卡诺图**。

### 卡诺图

简单理解就是画一个表格，然后**几何相邻**就等价于**逻辑相邻**，于是就很方便地看出哪里可以化简。具体怎么使用，上课的时候摸鱼去了，今晚补一下。

怎么画卡诺图就不说了，重点讲一下怎么消。

写入相邻的数字1则可以圈起来，观察看一下这个圈中**是哪一个信号发生了改变**，就消掉它。
