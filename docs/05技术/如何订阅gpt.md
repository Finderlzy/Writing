## 整体思路
---
我的理解是：openAI 会从很多地方判断你是谁、在哪里，比如 IP、DNS、浏览器、时区、账号地区、付款方式。**只要其中一项露出“我其实在国内”，就有风险。**

所以下面每一步，其实都在做同一件事：**让所有信息看起来都来自同一个地方，而且像一个普通用户。**

**整体流程：** 准备网络环境 → 配置代理软件 → 检查泄漏 → 改时区 → 改 Google 账号地区 → 注册 gpt 并先用几天 → 订阅 → 慢慢增加使用量。

## 网络环境
---
这一块是最重要的，**千万不要用万人蹬的节点**。机场的 IP 是成百上千人在共用，很可能早就被 openAI 标记过了。

我用的是：**自建节点 + 套一层住宅 IP 的链式代理**。

```
你的电脑 → VPS → 住宅IP → chatgpt.com
```

VPS 负责“翻出去”，住宅 IP 负责“最后一跳”。这样 openAI 看到的是一个家庭宽带的 IP，而不是机房 IP，也不是机场 IP。

### 1. 自建节点

详细教程：[[05技术/自建梯子：VPS + 3x-ui + VLESS Reality|自建梯子：VPS + 3x-ui + VLESS Reality]]

简单说就是：买一台 VPS → SSH 连上去 → 装 3x-ui 面板 → 放行端口 → 建一个 VLESS + Reality 的节点 → 导入代理软件。

自建的好处是这个节点只有你自己在用，IP 不会被别人用脏。但云 VPS 的 IP 是机房 IP，openAI 这类对 IP 很敏感的服务能识别出来，所以还要再套一层住宅 IP。

### 2. 套住宅 IP

详细教程：[[05技术/给 VPS 节点套上住宅 IP|给 VPS 节点套上住宅 IP]]

1. **买住宅代理**：商家会给你协议、IP、端口和账号密码。下单前先找商家要 IP，用 ipinfo.io、scamalytics.com 交叉测一下，重点看 IP 类型是不是“住宅/ISP”、风险分数高不高。（ping0.cc 的结果不太靠谱，不建议只看它）
2. **新增出站**：在 3x-ui 的 Xray 设置里添加一个出站，填入住宅 IP 的信息，标签起个好认的名字，比如 `residential`。
3. **新增路由规则**：让 gpt 相关的域名走住宅 IP，出站标签选 `residential`：

```
domain:chatgpt.com
domain:openai.com
domain:oaistatic.com
domain:oaiusercontent.com
```

> [!note] 为什么要多加后面两个 ChatGPT 网页的图片、脚本、上传的文件等，会从 `oaistatic.com`、`oaiusercontent.com` 加载。只加前两个的话，这部分请求会从 VPS 的 IP 出去，同一次访问就出现了两个出口 IP。

4. **保存并重启 Xray**，不重启不生效。

如果住宅 IP 流量够多，也可以在“路由”的“默认出站”里直接选住宅 IP，所有流量都走它，省得一个个加域名。

### 3. 确认出口 IP

把 `domain:ipinfo.io` 也加进路由规则，开着代理访问 ipinfo.io，显示的是住宅 IP 就说明套上了。

**记住这个 IP 所在的地区**，后面的时区、Google 账号地区都要和它对上。

## 配置代理软件
---
节点搭好了，还要保证电脑和手机上的流量真的都走了它。

### 1. gpt 必须走代理

不管用的是“规则”模式还是“全局”模式，都要确认 gpt 相关的域名走的是代理，不能直连。不放心的话，用 gpt 的时候直接开全局。

### 2. 桌面端必须开 tun 模式

普通的“系统代理”只对浏览器这类会读系统代理设置的软件生效。gpt 的桌面客户端、一部分系统请求可能不认系统代理，就会绕过节点直连出去。

tun（虚拟网卡）模式会在系统里虚拟出一张网卡，接管整台电脑的流量，不管软件认不认代理，都会被送进节点。

以 v2rayN 为例：**要以管理员身份运行**，然后在主界面底部打开“启用 Tun”。

### 3. 手机

iOS 上的 Shadowrocket 这类软件本身就是以 VPN 的方式接管整台手机的流量，相当于自带 tun 模式。只要确认 gpt 走的是你的节点就行。

### 4. 不要频繁换节点

用 gpt 的时候，固定用这一个节点。一会儿美国、一会儿日本，本身就很可疑。

## 防止泄漏
---
就算 IP 换好了，还有两个地方可能会把你的真实位置漏出去：DNS 和 WebRTC。

最方便的检测网站是 **browserleaks.com**，它把 IP、DNS、WebRTC 都分开测了；也可以用 ipleak.net，一个页面全测完。

### 1. DNS 泄漏

**是什么：** 访问一个网站之前，电脑要先问 DNS 服务器“这个域名对应哪个 IP”。如果这一步没走代理，而是问了国内运营商的 DNS，那对方就知道你在国内，而且知道你在访问 chatgpt.com。

**怎么防：**

1. **开 tun （虚拟网卡）模式**。tun 模式会把系统的 DNS 请求也接管过来，这是最主要的一步。
2. **检查代理软件的 DNS 设置**。在 v2rayN 的 DNS 设置里，让国外域名使用远程 DNS（比如 `1.1.1.1`、`8.8.8.8`），并且通过代理去查询。
3. **关掉浏览器自己的“安全 DNS”**，或者把它也改成国外的 DNS 服务商，免得浏览器绕开代理软件自己去查。

**怎么测：** 打开 browserleaks.com/dns ，结果里**不应该出现任何国内的DNS 服务器**（比如显示“China Telecom”“China Unicom”这类运营商）。

### 2. WebRTC 泄漏

**是什么：** WebRTC 是浏览器用来做语音、视频通话的技术。它为了建立连接，可能绕过代理，直接把你的真实 IP 暴露给网页。

**怎么防：**

- **Chrome / Edge**：装一个插件，比如“WebRTC Leak Prevent”；或者如果你装了 uBlock Origin，在它的设置里勾选“防止 WebRTC 泄露本地 IP 地址”。
- **Firefox**：地址栏输入 `about:config`，把 `media.peerconnection.enabled` 改为 `false`。

**怎么测：** 打开 browserleaks.com/webrtc ，看 “Public IP” 那一栏，**只能出现你的住宅 IP**，不能出现国内的 IP。

### 3. IPv6 泄漏

如果你家的网络有 IPv6，而代理没有接管 IPv6，那 IPv6 的流量可能会直接连出去。检测网站上如果出现了一个国内的 IPv6 地址，最简单的办法是在电脑网卡设置里把 IPv6 关掉。

## 支付
---
支付也是非常重要的。用国内的卡直接订阅，基本不用想。

我的方法是：**美区 Apple ID + 礼品卡充值余额 + 在 gpt 的 iOS app 里直接订阅**。

### 1. 准备美区 Apple ID

可以新注册一个美区 Apple ID。

在 App Store 里登录这个美区账号，下载 ChatGPT 官方 app。

### 2. 买礼品卡充值

打开手机浏览器，搜索“pockyt shop”，进入之后点击左上角“游客”。然后看“其他登录方式”，里面有支付宝，去支付宝里面购买即可
![[09附件/微信图片_20261007133655_1_2.jpg|262]]

注意：

- **也可以从别的靠谱的渠道买**。来路不明的便宜卡可能是“黑卡”，兑换之后 Apple ID 可能被锁。
- **余额要比订阅价格多一点**。美区会按账单地址所在的州收销售税，余额刚好等于订阅价格的话可能扣款失败。账单地址填免税州（比如俄勒冈州）可以避免这个问题。

### 3. 在 app 内订阅

在 ChatGPT app 里登录你的 gpt 账号，点升级，选择要订阅的方案，用 Apple ID 余额付款。

订阅之后，可以在 iPhone 的“设置”→ 你的名字 →“订阅”里管理或取消。

## 时区
---
很早之前就有人说过：openAI 会检测时区。

**时区要和住宅 IP 的所在地保持一致。** 我改成了台湾。

> [!note] 都是 UTC+8，为什么还要改 北京和台北的时差一样，但浏览器能读到的不只是时差，还有时区的名字，比如 `Asia/Shanghai` 和 `Asia/Taipei`。名字对不上，一样会露馅。

**手机和电脑都要改。**

### 电脑（Windows）

“设置”→“时间和语言”→“日期和时间”：关闭“自动设置时区”，手动选择住宅 IP 所在地的时区。

改完之后，可以在 browserleaks.com 的 JavaScript 页面里看看浏览器报告的时区对不对。

### 苹果手机

1. 先关掉根据定位自动设置时区：“设置”→“隐私与安全性”→“定位服务”→“系统服务”（滑到最底下）→ 关闭“设定时区”；
2. 再到“设置”→“通用”→“日期与时间”：关闭“自动设置”，手动选择对应的城市。

只做第 2 步的话，手机可能还会根据定位把时区改回来，所以第 1 步不能省。

## 修改 Google 账号关联地区
---
我是用 Google 账号注册 gpt 的，所以 Google 账号这边也要和住宅 IP 对上。

Google 会给每个账号关联一个国家/地区。查看方法：打开 policies.google.com/terms ，页面上会写“国家/地区版本”。

如果显示的是中国大陆或者香港，可以在同一个页面里申请更改为住宅 IP 所在的地区。Google 会人工审核，可能要等一段时间，审核时你也最好一直处在住宅 IP 的网络环境下。

## 注册 gpt
---
1. **前面的步骤全部做完，再去注册。** 网络环境、泄漏检测、时区都确认没问题之后再开始，不要边注册边调。
2. **尽量使用 Google 账号注册。**
3. **一个 IP 不要注册好几个账号。**
4. **注册成功后先正常用几天，不要急着订阅。** 最好是把免费额度用完，等它主动弹出升级提示，再去订阅。

## 订阅成功后
---
- **刚开始不要用太多**，一点一点增加使用量。
- **网络环境保持不变**：继续用同一个节点、同一个住宅 IP，不要今天这里明天那里。
- **不要在一堆设备上同时登录**，尤其不要在没走代理的设备上登录。
