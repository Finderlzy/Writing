这篇教程会在上篇搭好的节点基础上，再加一个住宅 IP。做完之后，访问指定网站时，对方看到的是住宅 IP，而不是 VPS 的机房 IP。

**整体流程：** 购买住宅 IP → 在 3x-ui 里新增出站 → 新增路由规则 → 保存重启 → 检查效果。

## 为什么要套住宅 IP
---

云 VPS 的 IP 属于机房 IP。有些网站（比如部分 AI 服务、TikTok、流媒体）能识别出机房 IP，并限制访问。住宅 IP 是家庭宽带的 IP，看起来就像普通用户在上网。

套上之后，链路变成这样：

```
你的电脑 → VPS → 住宅IP → 目标网站
```

VPS 仍然负责"翻出去"，住宅 IP 只负责"最后一跳"。

### 下单前先测 IP

IP 纯净度是最重要的。下单前可以找商家要一下 IP 地址，用几个工具交叉检测：

- ipinfo.io
- scamalytics.com

重点看两项：IP 类型是不是"住宅/ISP"，风险分数高不高。各家工具的数据库不一样，不要只看一家（ping0.cc 的结果我觉得不太靠谱，不建议只用它）。

买好后，商家会给你下面这些信息，后面都要用：

|---|---|
|协议|SOCKS5 或 HTTP|

## 二、新增出站
---

在 3x-ui 面板里找到 Xray 的设置页面（不同版本叫法可能略有不同），切换到"出站"标签页，添加一个出站。

> [!note] 出站是什么 出站就是流量离开 VPS 的出口。原来只有一个出口：从 VPS 直接出去。新增出站后，就多了一个出口：经过住宅 IP 再出去。

按下表填写：

|设置项|填写内容|
|---|---|
|协议|商家提供的协议（SOCKS5 或 HTTP）|
|标签（Tag）|起一个好认的名字，比如 `residential`，后面要用|
|地址|住宅 IP 地址|
|端口|商家给的端口|
|用户名、密码|商家给的账号密码|

## 三、新增路由规则
---

有了出口，还需要规则来决定**什么时候走住宅 IP，什么时候走 VPS**。这就是路由的作用。

> [!question] 为什么不让所有流量都走住宅 IP？ 住宅 IP 一般按流量计费，什么都走它，流量很快就会用完，用完就会卡住。而且多绕了一跳，速度也会慢一些。所以一般只让需要住宅 IP 的网站走它。

切换到"路由规则"标签页，添加一条规则：

**域名（Domain）**：填需要走住宅 IP 的网站，例如：

```
domain:chatgpt.com
domain:openai.com
domain:claude.ai
domain:tiktok.com
```

**出站标签（Outbound Tag）**：选择刚刚建的 `residential`。

这样，访问上面这些网站会走住宅 IP，其他网站继续从 VPS 直接出去。

> [!tip] 流量充足的话 可以在左侧面板"路由"的"默认出站"中，直接选择住宅 IP 出站，这样所有流量都会走住宅 IP，不用一个个加域名。

## 四、保存并重启 Xray
---

改完之后一定要**先点保存，再点"重启 Xray"**。不重启的话，设置不会生效。

## 五、检查效果
---

开着代理，访问 ipinfo.io：

- 如果你把 `domain:ipinfo.io` 也加进了路由规则，显示的应该是**住宅 IP**；
- 没加的话，显示的是 **VPS 的 IP**，这是正常的。

最直接的检查方法，是打开你要用的网站，看还会不会被限制。

## 注意事项
---

- **流量算两次**：走住宅 IP 的流量，既消耗住宅 IP 的流量额度，也消耗 VPS 的流量。
- **规则不生效**：先确认已经重启 Xray，再检查路由规则里的出站标签，是否和出站的 Tag 完全一致。
- **住宅 IP 连不上**：检查地址、端口、账号密码是否填错，也可以联系商家确认这个 IP 是否正常。
