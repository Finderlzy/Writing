这篇是笔记库分类的唯一标准。[[01系统/我的 Obsidian 笔记系统|我的 Obsidian 笔记系统]]记录的是之前的想法，具体放哪个文件夹以这篇为准。Inbox Filer 插件会把这篇全文交给 AI，作为把 `00收集` 里的文章移到哪个文件夹的依据。

核心只问一句：**这篇是写给谁看的？**

- 写给自己回看的记录、整理和计划 → `02笔记`
- 写给别人读的 → `03文章`、`04技术`、`05作品`
- 只能自己看的 → `07自己`

主题（二次元、读书、学习、AI……）不决定文件夹，写在 `tags` 里。

## 文件夹与判断标准

下面每一项的路径就是库里的真实文件夹路径，选择目标时原样使用，不要自己拼新文件夹。

| 文件夹 | 判断标准 | 例子 | 是否公开 |
| --- | --- | --- | --- |
| `01系统` | 规定笔记库、写作或发布**该怎么做**的规则和方案 | 《笔记样式规范》《作品与碎碎念》（作品发布前怎么编辑） | 公开 |
| `02笔记/课程/<课程名>` | 跟着一门课或一套教程，按章节顺序记的学习笔记 | 《数字逻辑/2.1 Verilog》《Java/集合进阶/泛型》 | 公开 |
| `02笔记/概念` | 讲清**一个**以后会反复引用的概念，标题就是概念名 | 《链表》《VLESS》 | 公开 |
| `02笔记/专题/<主题>` | 课程以外、围绕某个主题的记录：看视频的笔记、AI 给的总结和建议、计划、阶段日志 | 《专题/学习方法/如何找第一段实习》（视频笔记）、《专题/Agent/Agent技术栈》 | 公开 |
| `03文章` | 我自己写的观点、心得、评价或感受，陌生读者也能读懂；不分子文件夹 | 《不想上课》《CLANNAD》（番评）、《《棋王 树王 孩子王》》（书评） | 公开 |

| `05作品` | 打磨过的文学成稿（小说、散文、随笔），以及它的改稿 | 《这一次，我们有了合照》《星期四》 | 公开 |

`02笔记/课程` 和 `02笔记/专题` 下面按课程或主题分子文件夹。文章属于某个已有子文件夹时放进去；找不到合适的子文件夹，就放在 `02笔记/专题` 根目录。

## 拿不准时按顺序判断

1. **写到家人、朋友等真实的人，或者写自己的隐私、情绪、生活片段** → `07自己`。宁可不公开，也不要公开错。
2. **有完整叙事或明显的文学修辞** → `05作品`。只是零散的场景、对话片段 → 留在 `00收集/灵感`，不移动。
3. **主体是别人可以照做的操作步骤，而且已经验证能跑通** → `04技术`。只是给自己备忘的步骤 → `02笔记/专题`。
4. **主要内容是谁写的？** 我自己的观点和感受 → `03文章`。转述视频或书本的内容、AI 生成的总结和建议、计划和阶段日志 → `02笔记`。例如《关于读书》（我对怎么读书的思考）放 `03文章`，《DeepSeek对我的学习方法的评价》（AI 写的）放 `02笔记/专题/学习方法`。
5. **讲笔记库或写作流程该怎么做** → `01系统`。

## 不作为目标的文件夹

- `00收集`：还没想好放哪的新文章，以及 `00收集/灵感` 里的灵感片段。整理时只会把文章**移出**这里。上面的规则都判断不了时，就留在 `00收集`，不要硬选一个。
- `09附件`：只放图片、PDF 等附件，不放文章。

## 网址提醒

一级文件夹决定公开网址前缀：`01系统 → system`、`02笔记 → notes`、`03文章 → articles`、`04技术 → tech`、`05作品 → opus`、`09归档 → archive`。文章换到别的一级文件夹，网址也会变。新增一级文件夹前，要先在 `tools/build_site.py` 的 `SECTION_SLUGS` 里补上英文前缀。
