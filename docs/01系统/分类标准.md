这篇是笔记库分类的唯一标准。[[01系统/我的 Obsidian 笔记系统|我的 Obsidian 笔记系统]]记录的是之前的想法，具体放哪个文件夹以这篇为准。Inbox Filer 插件会把这篇全文交给 AI，作为把 `00收集` 里的文章移到哪个文件夹的依据。

## 两条线

我写的东西大多沿着两条线往前走，每条线三步，每一步对应一个文件夹：

| | 第一步：刚冒出来 | 第二步：我自己写下来 | 第三步：Agent 帮忙后发布 |
| --- | --- | --- | --- |
| 想法线 | 想法 → `00收集` | 思考 → `02思考` | 博客 → `04博客` |
| 写作线 | 灵感 → `00收集` | 初稿 → `03初稿` | 作品 → `05作品` |

- **思考**：我自己的观点、心得、评价、感受和计划，都是我的思考。番评、书评、学习感想都算。
- **博客**：在 Agent 帮助下，把我的思考梳理清楚逻辑，写成一篇面向读者的文章或教程。它可以串联好几个主题，比如《如何订阅claude》。
- **初稿**：我自己写成的一整篇故事或散文，还没交给 Agent 润色。
- **作品**：Agent 润色后发布的版本，文件名一般是 `原名（作品）`，原稿留在 `03初稿`。

两条线之外，还有三个文件夹：

- **只能自己看的私人生活** → `07自己`。只有出现身边的真实人名（包括 wdx 这样的缩写），或者在剖析自己的内心和缺点时才放这里。刘未鹏这样的公众人物不算。
- **笔记库和写作该怎么做的规则** → `01系统`。
- **附件**（图片、PDF）→ `09附件`。

主题（二次元、读书、学习、AI……）不决定文件夹，写在 `tags` 里。

## 文件夹与判断标准

下面每一项的路径就是库里的真实文件夹路径，选择目标时原样使用，不要自己拼新文件夹。

| 文件夹 | 判断标准 | 例子 | 是否公开 |
| --- | --- | --- | --- |
| `01系统` | 规定笔记库、写作或发布**该怎么做**的规则和方案 | 《笔记样式规范》《作品与碎碎念》（作品发布前怎么编辑） | **不公开** |
| `02思考` | 我自己写的观点、心得、评价、感受和计划；不写身边的真实人名，也不剖析自己的缺点；提到公众人物没关系 | 《不想上课》《CLANNAD》（番评）、《与导师聊天后的思考》 | 公开 |
| `03初稿` | 我自己写成的整篇故事、散文，还没经过 Agent 润色 | 《黑框眼镜》《我讨厌BE结局》 | 公开 |
| `04博客` | Agent 帮忙梳理后、面向读者的文章或教程，可以串联多个主题；操作步骤要已经跑通 | 《如何订阅claude》《自建梯子：VPS + 3x-ui + VLESS Reality》 | 公开 |
| `04博客/原理版` | 系列文章里讲原理的那一套，和 `04博客/操作版` 成对 | 《如何订阅claude》 | 公开 |
| `04博客/操作版` | 系列文章里照着做就行的纯操作版 | 《如何订阅claude（纯操作版）》 | 公开 |
| `05作品` | Agent 润色后发布的文学作品 | 《黑框眼镜（作品）》《这一次，我们有了合照》 | 公开 |
| `07自己` | 私人生活：出现身边的真实人名或缩写（不含公众人物），或者剖析自己的内心和缺点 | 《自行车》（二表哥）、《不愿意教别人》（害怕被超越） | **不公开** |

`04博客` 下只为成对的系列建子文件夹，目前只有订阅教程的 `原理版` 和 `操作版`。其他文件夹都不再分子文件夹。

## 拿不准时按顺序判断

1. **先分清虚构还是真实**，按下面的顺序看：
   - front matter 里写了 `虚构: true` 或 `真实: true` 的，以标记为准。
   - 放在 `00收集` 里的文章，默认是创作素材，算虚构；除非正文写明是真实经历。
   - 标题或正文表明是幻想、设想、故事，或者写的是还没发生的未来，也是虚构。

   第一人称的“我”不等于作者本人，故事里的朋友、同事也不算真实的人。虚构的内容按第 3 条判断，不适用第 2 条。
2. **出现身边的真实人名（包括缩写），或者剖析自己的内心、缺点** → `07自己`。身边的人指亲友、同学、老师、同事这类不公开露面的普通人。作家、博主、学者、明星等公众人物（比如刘未鹏），以及作品里的角色，都不算，提到他们的文章照常按后面的规则判断。只是提到“导师”“朋友”这类称呼、没有名字，也不算。拿不准是不是公众人物时，宁可不公开，也不要公开错。
3. **写作线**：还没写完的故事，或者只是零散的场景、对话片段 → 留在 `00收集`，不移动。我自己写成的整篇 → `03初稿`。Agent 润色过、准备发布的版本 → `05作品`。
4. **Agent 帮忙梳理成面向读者的文章或教程** → `04博客`。只是给自己备忘的操作步骤 → 留在 `00收集`。
5. **讲笔记库或写作流程该怎么做** → `01系统`。
6. **其余都是我的思考** → `02思考`。例如《关于读书》（我对怎么读书的思考）。

## 不作为目标的文件夹

- `00收集`：还没想好放哪的新文章和灵感片段。整理时只会把文章**移出**这里。上面的规则都判断不了时，就留在 `00收集`，不要硬选一个。
- `09附件`：只放图片、PDF 等附件，不放文章。

## 网址提醒

一级文件夹决定公开网址前缀：`02思考 → thoughts`、`03初稿 → drafts`、`04博客 → blog`、`05作品 → opus`。文章换到别的一级文件夹，网址也会变。网址前缀写在 `tools/content.py` 的 `LAYOUT` 里，新增一级文件夹前要先在那里登记，否则构建报 `E_URL_SECTION_MISSING`。
