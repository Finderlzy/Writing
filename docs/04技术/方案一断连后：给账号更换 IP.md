## 前言
---
2026-10-17，方案一白嫖的住宅 IP 断了，用方案一的朋友现在都连不上 claude。商家的回复和读者的反馈，我放在了[[04技术/原理版/一、白嫖 ISP|一、白嫖 ISP]]开头的提示框里，这里就不重复了。

之前我让大家先别用 claude，因为我在找办法把原有账号换到新的 IP 上。现在我自己换完了，账号目前正常，所以把过程写下来。

先叠个甲：这只是我自己换了一次的经历，**只能说它目前对我管用**，没法保证长期有效，也没法保证每个人都能成功。

>[!caution] 先看这里
>- 本文只是记录个人的操作经历，仅供学习和技术交流，不构成任何建议。
>- 换 IP 本身也有风险，请先确认自己能承担。
>- 文中的 VoyraCloud 链接是我的推广链接，通过它购买我会拿到一点佣金，介意的话直接搜商家名字就行。

**整体流程：** 准备新节点 → 隔一段时间 → 在网页端退出登录 → 再隔一小会 → 用新节点登录。

## 一、准备好新节点
---
旧的住宅 IP 已经断了，所以先得有一个新的、能用的节点。

**一定要先测一下干不干净。** 换 IP 就是为了让账号继续活下去，要是换上去的是一个机房 IP，或者风险分很高的 IP，那还不如不换。怎么测，见 [[04技术/原理版/测 IP 质量|测 IP 质量]]，测完 AS Type 是 `isp`、Privacy 是 `false`、Scamalytics 分数低，再往下走。

### 我是怎么准备的

我这次是去 [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M) 买了一台住宅服务器，也就是[[04技术/原理版/方案二：住宅 IP 服务器|方案二]]。买好之后照着 [[04技术/原理版/三、把服务器变成节点|三、把服务器变成节点]] 做，再[[04技术/原理版/导入代理软件|导入代理软件]]就行。

为什么又买它家的？因为我之前买过一台，测出来分到的是机房 IP（见 [[04技术/原理版/实测：VoyraCloud 住宅服务器|它的实测]]），我想再确认一下它家服务器的质量到底怎么样。**这一次测出来的结果很好。**

### 为什么没去千宿网络的主站

千宿网络就是方案一里白嫖住宅 IP 的那家（proxy.qsu.hk），它的主站 qsu.hk 也卖住宅服务器。这次我没去它的主站买，原因是这次断连让我对它产生了不信任：

- 它**没有提前预告**，直接就把活动产品的线路断了。
- 商家的说法是并发高、拥堵了。但我个人更倾向于认为是**主动切断**，想把用户引到主站去买。这只是我的猜测，没有证据。

当然，**它主站服务器的 IP 质量是不错的**，这一点我不否认。介不介意，大家自己判断。

## 二、隔一段时间
---
新节点准备好之后，**不要马上就开着它去登录 claude**，先隔一段时间。

我的理解是：同一个账号，前一刻还在这个 IP，下一刻突然就跳到另一个 IP，看起来不太像一个普通人。隔一段时间再换，会自然一点。这是我的个人经验，没有依据。

## 三、在网页端退出登录
---
隔了一段时间之后，打开 claude 网页端：

1. 点**左下角**的账号（你的名字或头像那里）。
2. 选 **Log out**，退出登录。

## 四、再隔一小会，重新登录
---
退出之后，再过一小会，开着新节点重新登录 claude。

登录之前，记得确认代理软件用的是**新节点**，而且已经测过它的质量。能正常登录、正常使用，就说明换好了。
