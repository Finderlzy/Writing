## p1 1. 前言

说实话，我有点犹豫要不要现在发这篇。我的 claude 才订阅了七天。时间太短，我没法保证这套方法长期有效，只能说它目前对我管用。而且为了走到这一步，我前前后后折腾了很久，所以流程会有点繁琐。

这一版只写怎么做，不讲为什么。哪一步想知道原因，或者某个细节失效了想自己调，去原理版 [[如何订阅claude]] 里找同名的小节。

文中没写的情况，我不一定可以给出答案，请见谅。

**每一步都做完再做下一步。**

成本：我用的方案一，服务器每月 4.5 美元，另外还有 claude 本身的订阅费。钱花了，也可能订阅失败、可能被封号，请先确认自己能承担这个风险。

推广链接：文中的购买链接都是我的推广链接。通过它们购买，你的价格只会低，不会高，但同时我会拿到一点佣金。介意的话直接搜商家名字就行。每个链接后面都写了我自己有没有用过，没用过的是很多大佬推荐的，请自己判断。这几家都是小商家，建议先按月买，确认能用了再续费。

## p5 5. 方案一：普通服务器 + 白嫖 ISP

### 一、白嫖 ISP

1. 在 [proxy.qsu.hk](https://proxy.qsu.hk/) 注册（IP 质量怎么样，见 [[实测：proxy.qsu.hk 白嫖 ISP|它的实测]]）。注意它和主站 qsu.hk 卖的东西不一样，主站卖的是方案二的住宅服务器（见 [[实测：QSU 住宅服务器|它的实测]]）。
2. 选 **SOCKS5 协议**的套餐，下单时填优惠码 `qiansu998`，就可以免费拿到一个住宅 IP 端口。优惠码随时可能失效，流量额度等以下单页面为准。
3. 在线路详情里记下**住宅 IP、端口、用户名、密码**。这里的“住宅 IP”可能是一串域名，比如 `r52u2gaa.isp201.iisp.asia`，这很正常，照着记下来就行。

**先测一下质量**

每个人白嫖到的 IP 都不一样，别人测出来好，不代表你拿到的也好，一定要自己测。

1. 先关掉电脑上的代理软件，否则测出来的 IP 不对。
2. 打开命令行：Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”。
3. 输入下面这行，`用户名`、`密码`、`地址`、`端口` 换成第 3 步记下的：

```bash
curl -x socks5h://用户名:密码@地址:端口 https://ipinfo.io/json
```

4. 返回结果里 `"ip"` 那一行就是出口 IP，把它复制下来。
5. 打开 `https://ipinfo.io/` 加上这个 IP（比如 `https://ipinfo.io/1.2.3.4`），看 AS Type 和 Privacy；再把这个 IP 粘贴到 [scamalytics.com](https://scamalytics.com/) 查风险分。怎么看，见 [[测 IP 质量]]。

连不上的话：

- 密码里有 `@`、`:`、`#` 这类符号，命令会被拆错。可以在商家后台换一个只有字母和数字的密码。
- 商家后台有 IP 白名单的话，把你自己现在的 IP 加进去。

**测出来质量不好**

可以找商家客服换一个 IP，换完再测一次；也可以回到 [[选择方案]]，换别的方案。

还想继续走方案一的，也可以买付费的 ISP，见 [[四、购买 ISP 代理]]。

**一定要选 1 人独享，不要买共享套餐。**

1. 在 ipequal 注册，购买套餐，**“使用类型”选 1 人独享**（IP 质量怎么样，见 [[实测：ipequal 住宅节点|它的实测]]）。我**没用过**，因为一直买不到，是看到很多大佬推荐才放在这里，建议先买一个月试试。

   - 已经有节点：[ipequal](https://www.equaldcdn.com/?ref=6adabd0307)（需要开代理打开）
2. 复制订阅链接，按 [[导入代理软件]] 导入，**尽量通过剪贴板导入**。
3. 已经有别的节点的，也可以只让 claude 走住宅节点，见 [[分流规则具体怎么写？]]。用了分流的，测 IP 之前要把 `ipinfo.io` 也加进分流规则，否则测出来的是原来节点的 IP。

“1 人独享”怎么确认真的只有你在用，见 [[“1 人独享”怎么确认真的只有我在用？|常见问题]]。

## p8 8. 导入代理软件

先记住三条：

- **打开 tun 模式，不要用“自动配置系统代理”之类的选项。**
- 方案一、二有两个节点：**平时用主节点**（VLESS + Reality），主节点连不上或很慢时换备用节点（Hysteria2）。两个节点出口是同一台服务器，切换不算“换节点”。
- **用 claude 时固定用这一个节点，不要换来换去。**

**电脑：v2rayN**

1. 从 GitHub 下载 [v2rayN](https://github.com/2dust/v2rayN/releases)，选和你的系统对应的版本，解压。
2. 右键 v2rayN → **以管理员身份运行**。
3. 复制节点链接，在 v2rayN 里：配置项 → 从剪贴板导入。
   - 方案一、二：节点是运行脚本最后打印的那两个，**通过剪贴板导入**，不要截图发来发去。
   - 方案三：复制商家给的订阅链接，同样从剪贴板导入。
4. 选中主节点，设为当前使用的节点。
5. 主界面底部：系统代理选“清除系统代理”，打开“启用 Tun”。
6. 确认 claude 走代理：不管用“规则”还是“全局”模式，claude 相关的域名都不能直连。不放心的话，用 claude 时直接开全局。

**电脑：Clash Verge**

1. 从 GitHub 下载 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases)，安装。
2. 导入节点：
   - 方案一、二：Clash Verge 导入不了 `vless://`、`hysteria2://` 这种分享链接。在服务器上运行 `cat /root/clash.yaml`，复制全部内容，在 Clash Verge 里新建一个本地配置粘贴进去保存。两个节点都在里面，默认选中备用节点 Hysteria2（Clash 的内核连 Reality 节点目前有兼容问题，还在排查）。
   - 方案三：复制商家给的订阅链接，在 Clash Verge 里导入订阅。
3. 设置 → 系统设置：打开“虚拟网卡模式”（也就是 tun 模式），第一次打开会提示安装服务模式，照着装上；“系统代理”保持关闭。
4. 和 v2rayN 一样，确认 claude 相关的域名不会直连。

**手机**

手机现在先不用管，等到注册 Gmail 之前再导入，见 [[选择手机系统]]。

## p9 9. 测 IP 质量

测之前先打开代理软件，见 [[导入代理软件]]。方案一还要先做完 [[四、购买 ISP 代理]]。

用方案一的注意：只有 claude 和 ipinfo.io 走 ISP，所以**出口 IP 只能在 ipinfo.io 上看**，别的测 IP 网站显示的是服务器的机房 IP。各个网站测出来的 IP 不一样，见 [[测出来好几个不同的 IP？]]。

**1. 在 ipinfo.io 上看 IP 类型**

开着代理打开 [ipinfo.io](https://ipinfo.io/what-is-my-ip)，页面最上面显示的就是你的出口 IP，**先把它复制下来**，下一步要用。然后往下拉到 Summary，看下面几行：

![[09附件/住宅IP实测-ipinfo-作者的白嫖IP.png|600]]

| 字段 | 我的结果 | 怎么看 |
| --- | --- | --- |
| AS Type | Isp | **最关键的一项。** `isp` 可以用；`hosting` 是机房 IP，建议直接换；`business` 是企业网络，介于两者之间。 |
| Privacy | false | `false` 才对，`true` 基本就不能用了。 |
| Hosted domains | 0 | 0 比较好。 |

AS Type 是 `isp`、Privacy 是 `false`，这一关就算过了。不满足的话就别用了，直接换。

ASN 后面那个 `#6` 是 IPinfo 给这个网络的排名，不用管。

**2. 在 Scamalytics 上查风险分**

把刚才复制的 IP 粘贴到 [scamalytics.com](https://scamalytics.com/) 查风险分，越低越好。我这个是 0 分，但不一定都能做到 0，分数低就可以。**不要用 ping0.cc**，它会暴露你国内的真实 IP。

![[09附件/住宅IP实测-scamalytics-作者的白嫖IP.png|600]]

**3. 测出来质量不好**

赶紧找商家客服反馈，换一个 IP，换完再测一次；也可以回到 [[选择方案]]，换别的方案。

## p10 10. 防泄漏

要堵三个地方：DNS、WebRTC、IPv6。下面以 v2rayN 为例，用 Clash Verge 的看最后。设置完都要测一下，检测网站用 [browserleaks.com](https://browserleaks.com)，它把 IP、DNS、WebRTC 分开测；也可以用 [ipleak.net](https://ipleak.net/)，一个页面全测完。

**防 DNS 泄漏**

1. 确认代理软件开了 tun 模式（见 [[导入代理软件]]）。
2. v2rayN → DNS 设置：国外域名用远程 DNS（`1.1.1.1` 或 `8.8.8.8`），并且通过代理查询。
3. v2rayN → 路由设置：“域名解析策略”选 `AsIs`。
4. 关掉浏览器的“安全 DNS”，或者把它也改成国外的 DNS 服务商：
   - Chrome：设置 → 隐私和安全 → 安全 → 关闭“使用安全 DNS”。
   - Edge：设置 → 隐私、搜索和服务 → 关闭“使用安全 DNS”。

**检测**：打开 [browserleaks.com/dns](https://browserleaks.com/dns)，结果里不能有国内的 DNS（比如 China Telecom、China Unicom）。

**防 WebRTC 泄漏**

- Chrome / Edge：装插件“WebRTC Control”；或者在 uBlock Origin 设置里勾选“防止 WebRTC 泄露本地 IP 地址”。
- Firefox：地址栏输入 `about:config`，把 `media.peerconnection.enabled` 改为 `false`。

**检测**：打开 [browserleaks.com/webrtc](https://browserleaks.com/webrtc)，“Public IP”里不能出现你国内的 IP。用方案一的，这里显示的是服务器的 IP，这是正常的。DNS、WebRTC 测出来的 IP 看不懂的，见 [[测出来好几个不同的 IP？]]。

**防 IPv6 泄漏**

1. 先打开 [ipleak.net](https://ipleak.net/) 看一下，没有出现 IPv6 地址，或者出现的不是国内的，就不用管。
2. 出现了国内的 IPv6 地址，就在电脑上关掉 IPv6：
   - Windows：控制面板 → 网络和 Internet → 网络和共享中心 → 更改适配器设置 → 右键你正在用的网络（Wi-Fi 或以太网）→ 属性 → 取消勾选“Internet 协议版本 6 (TCP/IPv6)” → 确定。
   - Mac：系统设置 → 网络 → 你正在用的网络（Wi-Fi 或以太网）→ 详细信息 → TCP/IP → “配置 IPv6”选“仅本地链接” → 好。
3. 关掉之后再打开 ipleak.net 测一次，确认国内的 IPv6 不见了。

**用 Clash Verge 的**

1. 确认已经打开“虚拟网卡模式”（tun 模式），见 [[导入代理软件]]。
2. 设置 → Clash 设置：打开“DNS 覆写”，增强模式选 `fake-ip`。
3. 浏览器的“安全 DNS”、WebRTC、IPv6，和上面一样处理。
4. 检测方法也和上面一样。

<a id="p30"></a>iPhone：购买未完成

订阅成功了的，跳过这一页。

**别自己硬扛，让 AI 带着你走完。**

1. **先问 AI**。把报错截图、App Store 账户设置的截图发给 AI（比如 claude 免费版、ChatGPT 都可以），说明你在用美区 Apple ID 订阅 claude 时提示购买未完成。让它帮你逐项检查设置，比如付款方式、账单地址、是否允许 App 内购买。
2. **按 AI 说的联系客服**。检查完还是不行的话，打开苹果自带的“支持”app（Apple Support），在里面找在线客服。
3. **注意账号的区别**。“支持”app 里登录的是你 iCloud 的主账号，客服大概率会给你转接海外客服，对方说英文。客服发一句，你复制给 AI；AI 给出回答，你再复制给客服。开头记得让 AI 帮你跟客服说清楚，你要处理的是 App Store 上登录的那个美区账号，不是 iCloud 账号。
4. **客服让你等 72 小时的话**，记下 Case ID。**这 72 小时里什么都别做**：不要尝试购买，不换账号，也不要改付款信息和账单地址。
5. **72 小时后再买**。还是失败的话，带着 Case ID 再联系客服，同样让 AI 帮你沟通。
