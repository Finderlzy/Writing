## 整体思路

我的理解是：anthropic 会从很多地方判断你是谁、在哪里，比如 IP、DNS、浏览器、时区、账号地区、付款方式。**只要其中一项露出“我其实在国内”，就有风险。**

所以下面每一步，其实都在做同一件事：**让每一项信息都不露出“我在国内”，而且像一个普通用户。**

**整体流程：** 清理旧账号和配置 → 选择方案，准备节点和住宅 IP → 导入代理软件 → 测 IP 质量 → 防泄漏 → 改时区 → 手机导入代理软件、下载 Gmail（iPhone 和安卓分开走）→ 注册 Gmail → 登录谷歌浏览器 → 先用两天 → 修改 Google 账号地区 → 注册 claude → 订阅（iPhone 和安卓分开走）→ 订阅之后。

## 清理旧账号和配置

前面说了，anthropic 会从很多地方判断你是谁、在哪里。你之前登录过的账号、用过的配置，都是在原来的网络环境下留下的，里面可能就带着“我在国内”的信息。不清理的话，新账号一登录，这些旧信息就跟着过来了，后面做得再干净也白费。

所以在开始之前，先把它们都清掉，不残留之前的信息，确保一切都是干净的。要清理的地方有三个：网页端、Claude Code、手机 App。

1. **网页端退出账号**：打开 claude.ai → 左下角头像 → Settings → Account，在“Log out of all devices”这一行点 **Log out**。
![[09附件/截图 2026-10-15 13-43-53 1.png]]

2. **清理 Claude Code**：换另一个 Agent，让它清理本机 Claude Code 的一切缓存和配置。
3. **手机 App 退出账号**：手机上装过 claude App 的，也在 App 里退出登录。

## 一、白嫖 ISP

这一页不讲原理，因为主要是为了白嫖。为什么要用 ISP，放到 [[四、购买 ISP 代理]] 再讲。

1. 在 [proxy.qsu.hk](https://proxy.qsu.hk/) 注册（IP 质量怎么样，见 [[实测：proxy.qsu.hk 白嫖 ISP|它的实测]]）。注意它和主站 qsu.hk 卖的东西不一样，主站卖的是方案二的住宅服务器（见 [[实测：QSU 住宅服务器|它的实测]]）。
2. 选 **SOCKS5 协议**的套餐，下单时填优惠码 `qiansu998`，就可以免费拿到一个住宅 IP 端口。优惠码随时可能失效，流量额度等以下单页面为准。
3. 在线路详情里记下**住宅 IP、端口、用户名、密码**。这里的“住宅 IP”可能是一串域名，比如 `r52u2gaa.isp201.iisp.asia`，这很正常，照着记下来就行。

**先测一下质量**

白嫖到之后，先测一下它的质量，再决定要不要继续走方案一。为什么一定要测？因为**白嫖到的 ISP 质量参差不齐**，每个人拿到的 IP 都不一样。比如我和一位读者都是在这里白嫖的，结果差得挺多：

| | 我的 | 一位读者的 |
| --- | --- | --- |
| 登记在谁名下 | Cogent（AS174） | NTT（AS2914） |
| ipinfo：AS Type | ISP | ISP |
| IPKK：IP 属性 | — | 机房 IP |
| Scamalytics（越低越好） | 0 分 | 100 分，Very high Risk |

我的这个拿来订阅、使用 claude 都正常；读者的那个，ipinfo 说是 ISP，别的网站却认成机房 IP，风险分也拉满了，质量只能算一般。截图和详细数据见 [[实测：proxy.qsu.hk 白嫖 ISP|它的实测]]。所以别人测出来好，不代表你拿到的也好，一定要自己测。

商家给的是代理的地址，不是它的出口 IP，所以要先通过这个代理访问一次 ipinfo.io，拿到出口 IP：

1. 先关掉电脑上的代理软件，否则测出来的 IP 不对。
2. 打开命令行：Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”。
3. 输入下面这行，`用户名`、`密码`、`地址`、`端口` 换成第 3 步记下的：

```bash
curl -x socks5h://用户名:密码@地址:端口 https://ipinfo.io/json
```

4. 返回结果里 `"ip"` 那一行就是出口 IP，把它复制下来。
5. 打开 `https://ipinfo.io/` 加上这个 IP（比如 `https://ipinfo.io/1.2.3.4`），看 AS Type 和 Privacy；再把这个 IP 粘贴到 [scamalytics.com](https://scamalytics.com/) 查风险分。怎么看，见 [[测 IP 质量]]。

连不上的话：

- 密码里有 `@`、`:`、`#` 这类符号，命令会被拆错。可以在商家后台换一个只有字母和数字的密码。
- 商家后台有 IP 白名单的话，把你自己现在的 IP 加进去。

**测出来质量不好**

可以找商家客服换一个 IP，换完再测一次；也可以回到 [[选择方案]]，换别的方案。

还想继续走方案一的，也可以买付费的 ISP，见 [[四、购买 ISP 代理]]。


## 二、购买服务器

在动手之前，先讲一点网络的基础知识。

你有没有想过：为什么在浏览器里打开 claude.ai，就能看到一个网页？其实这背后是一来一回两件事。你按下回车的时候，你的设备向 claude 的服务器发出了一个**请求**，意思是“我要看这个网页”；claude 的服务器收到请求后，把网页的数据通过网络**返回**给你，你才看到了网页。

问题就出在“返回”这一步。服务器要把数据送回来，就得知道该送到哪儿，所以每个请求上都带着一个“回信地址”，这个地址就是 **IP**。你可以先简单理解成：每一台上网的设备都有一个 IP（这么说不是十分准确，但够用了）。

IP 不只是一个地址，它还能看出你在哪个国家。claude 不对中国用户提供服务，它的服务器一看请求来自中国的 IP，就会制裁你。也就是说，**claude 判断你是不是中国用户，最主要看的就是 IP。**

既然 claude 看的是 IP，那我们要做的就是：**让发给 claude 的请求，带着一个海外的 IP**。我们自己的 IP 改不了，那就找一台海外的服务器帮忙。我们先把请求交给这台服务器，由它替我们发给 claude。claude 看到的是这台服务器的海外 IP，就不会制裁了。claude 把数据返回给服务器，服务器再转交给我们。

这台替我们收发请求的海外服务器，就是常说的“**节点**”。这就是这一节要买服务器的原因。

1. 在 [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M) 买一台云 VPS（我用的就是它家的云 VPS。云 VPS 是机房 IP，访问 claude 时走的是 ISP，所以不用看它的 IP 质量），按下表选：

| 选项   | 怎么选                                |
| ---- | ---------------------------------- |
| 系统   | **Debian 12**（不要选 Ubuntu）             |
| 配置   | 1 核 CPU、1 GB 内存就够                  |
| 流量   | 每月几百 GB 足够                         |
| 机房位置 | 美国、日本、新加坡等                         |

系统只选 Debian。我自己用的就是 Debian，教程里的命令和脚本都是照着 Debian 来的。Ubuntu 和 Debian 是一家子，长得很像，但有读者反馈，Ubuntu 上有些命令有些许区别，照着教程做容易出岔子，所以干脆统一用 Debian。已经装成别的系统的，在商家后台把系统重装成 Debian 12 就行。

2. 买完在商家控制台记下**服务器 IP** 和 **root 密码**。


## 三、把服务器变成节点

买好服务器之后，我们就要把它变成一个节点。但是服务器在海外，它没有屏幕，也没有键盘，我们人在中国，该怎么操作它呢？

这个时候就轮到 **SSH** 登场了。SSH 是一项远程连接技术：连上之后，你在自己电脑上敲的命令，会被送到海外的服务器上执行，执行的结果再传回你的屏幕。就好像你坐在那台服务器面前一样。

要连上服务器，需要两样东西：一是服务器的 IP，告诉 SSH 要连到哪一台；二是 root 密码，证明你是这台服务器的主人。这两样就是上一节买完服务器后让你记下来的。

1. 打开命令行：Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”。
2. 输入下面的命令，`你的服务器IP` 换成真实 IP。问 `Are you sure...` 时输入 `yes`；出现 `password:` 时输入 root 密码（**屏幕不显示，正常**），回车。开头变成 `root@...:~#` 就连上了。

```bash
ssh root@你的服务器IP
```

提示 `Permission denied, please try again.`，见 [[SSH 提示 Permission denied？]]。

连上之后，就要把它变成一个节点了。

刚买来的服务器只是一台空电脑，什么都不会做。要让它替我们收发请求，就得在上面装一个专门干这件事的程序，这个程序叫 **Xray**。装好 Xray，这台服务器才真正变成了节点。

## 四、购买 ISP 代理

上一节让我们的请求带上了海外的 IP，请求能到达 claude 了。但只做到这一步还不够：claude 不光看你从哪个国家来，还会看你像不像一个普通人。不像的话，照样会被封号。

它怎么判断你像不像普通人呢？还是看 IP。IP 除了能看出国家，还能看出类型。每个 IP 都登记在某个组织名下，网站一查就知道：

- **机房 IP**：我们买的服务器放在机房里，它的 IP 登记在云服务商名下。普通人不会从机房上网，所以 claude 的风控一看到机房 IP，就容易把你当成在用代理，封号的风险就高了。
- **住宅 IP**：登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在家上网。
- **ISP**：也叫静态住宅 IP，是运营商的 IP 放在机房里长期固定使用，也算住宅这一类，被封号的概率比较低。

我们的服务器是机房 IP，所以要在节点外面再套一层 ISP 代理。套上之后，请求还是先到服务器，但访问 claude 的时候，服务器不从自己的出口出去，而是把请求转交给 ISP 代理，由它发给 claude。这样 claude 看到的就是 ISP 的 IP。

简单来说，这两层各管一件事：**服务器让请求能到达 claude，ISP 代理让 claude 觉得你是普通人，不封你的号。**

那是不是所有网站都要走 ISP 呢？这个由你自己决定，脚本会问你选哪一个：

- **只有 claude 走 ISP**：只有 anthropic 相关的网站（还有用来检查 IP 的 ipinfo.io）走 ISP，其他网站照旧从服务器出去。这是我自己用的。ISP 的流量只花在刀刃上，看视频、刷网页都不占它的流量，网速也不受 ISP 影响。
- **全部走 ISP**：不管访问什么网站，看到的都是 ISP 的 IP。代价是 ISP 的流量用得快，白嫖的那点额度可能撑不了多久，网速也要看 ISP 的脸色。

拿不准的话，选第一个。选错了也没关系，再运行一次同一行命令，重新选就行。

第一步白嫖到的 ISP，现在要把它配到节点上。

5. 脚本会先测一下这个代理能不能连上，再让你选的网站走它。看到 `===== 住宅 IP 加好了 =====` 就成功了，下面一行会写着哪些网站从哪个住宅 IP 出去。

提示“住宅代理连不上”：去商家后台检查端口、账号密码、IP 白名单（把服务器 IP 加进去）、套餐是否生效，再运行一次命令。这个脚本只支持 **SOCKS5** 协议的代理，买付费 ISP 的时候也要选 SOCKS5。

以后想换一个 ISP，或者想改选哪些网站走 ISP，再运行一次同一行命令，重新填、重新选就行。


## 五、安装面板

这一步是可选的。方案一、二的节点出问题时，或者你想自己改一些设置，就要用到**面板**。现在用不上的，可以先跳过，以后需要了再回来装。

面板是什么呢？前面我们一直是在命令行里操作服务器，敲命令、看输出。面板就是一个网页版的后台，装好之后，你在浏览器里就能看到节点的状态、改节点的设置，不用再敲命令。我用的面板叫 3x-ui。

装面板的时候，脚本会把现在的节点交给面板管理，节点链接不变，代理软件里不用重新导入。

## 方案二：住宅 IP 服务器

先讲一点网络的基础知识。你在浏览器里打开 claude.ai 的时候，你的设备向 claude 的服务器发出了一个**请求**；claude 的服务器收到后，把网页的数据**返回**给你，你才看到了网页。服务器要把数据送回来，就得知道该送到哪儿，所以每个请求上都带着一个“回信地址”，这个地址就是 **IP**。

IP 不只是一个地址，它还能看出两件事：

- **你在哪个国家**。claude 不对中国用户提供服务，一看请求来自中国的 IP，就会制裁你。
- **你是什么人**。每个 IP 都登记在某个组织名下：普通服务器放在机房里，IP 登记在云服务商名下，叫**机房 IP**，普通人不会从机房上网，claude 一看就容易把你当成在用代理；**住宅 IP** 登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在家上网。

所以我们要让 claude 看到的，是一个**海外的住宅 IP**。

方案二的做法，就是直接买一台**住宅服务器**。它是一台放在海外、自带住宅 IP 的服务器，从它这里出去的请求，claude 看到的直接就是住宅 IP。所以你**只需要把这台服务器变成一个节点**就好了：请求先交给它，由它替你发给 claude，claude 看到的就是这台服务器的住宅 IP；claude 返回的数据，再由它转交给你。这台替你收发请求的服务器，就是常说的“**节点**”。

不过要注意一点：**商家说是住宅服务器，分到你手上的不一定真是住宅 IP。** 我自己就买过一台 VoyraCloud 的美国住宅服务器（见 [[实测：VoyraCloud 住宅服务器|它的实测]]），测出来 ipinfo.io 显示 ASN 属于 Bunny Communications，类型是 **Hosting（机房）**，Privacy 为 true；Scamalytics 分数 16，属于低风险，但也识别出在用 VPN/代理。也就是说，我这一台风险分数不高，但分到的是机房 IP，不是住宅 IP。

这只是我一次购买的结果，不代表每次都这样。所以买到之后一定要测，后面“测 IP 质量”那一步会讲怎么测；不是住宅 IP 的话，找商家退款或者换 IP。

## 方案三：直接买住宅节点

## 导入代理软件

节点准备好之后，就可以把它导入代理软件了。那么代理软件又是做什么的呢？这里要涉及到一个东西：**我国的防火墙**。

前面讲过，claude 会看请求来自哪个 IP，这是我们要过的一道关。其实在这之前还有一道关，就是防火墙。我对防火墙了解得也不多，这里只讲用得上的部分。

防火墙守在国内网络通往海外的出口上。你的请求只要是发往海外的，都要从它这里过。它会看你要去哪儿、发的是什么，不让过的就拦下来，所以你在国内直接打不开 Google、YouTube。

我们的请求要先发到海外的节点，也得从防火墙这里过。如果就这么直接发过去，防火墙一眼就能看出“这是在通过代理访问外网”，请求会被拦下来，节点也可能被封掉。

代理软件就是来解决这个问题的。它装在你的电脑和手机上，你发出的请求先交给它。它把请求加密，再伪装成访问一个普通的大网站，然后发给节点。防火墙看到的只是一次普通的上网，看不出你真正要去哪儿，就放过去了。节点收到之后，拆开伪装，再替你把请求发给 claude。

导入的节点链接里，写着节点在哪儿、怎么加密和伪装。这就是为什么说节点链接就像钥匙，不能发给别人。

那请求是怎么交到代理软件手上的呢？代理软件一般有两种接法：系统代理和 tun 模式。

**系统代理**是在系统设置里登记一句“上网请先找代理软件”。会读这条设置的软件，就自己把请求交给代理软件。问题就出在“自己交”：软件是主动走的代理，所以它是知道你在走代理的，像 claude code 就能看出来。而且不读这条设置的软件、系统自己发出的 DNS 请求，干脆就不走代理，直接用国内网络连出去了。

**tun 模式**是在系统里虚拟出一张网卡，整台电脑的流量都从这张网卡过，被送进节点。软件还是像平常一样上网，根本不知道自己走了代理；不管它读不读系统代理的设置，都逃不掉。

所以，**使用代理软件时，打开 tun 模式就可以，不要用“自动配置系统代理”之类的选项。**

还有一件事：用方案一、二的，脚本给了你两个节点，主节点和备用节点。它们有什么区别呢？

区别在**协议**。协议就是代理软件和节点之间约定好的“说话方式”：怎么加密、怎么伪装。两边说的是同一种话，才能对上。

- **主节点：VLESS + Reality**。它伪装得很像：防火墙去看，看到的是你在访问一个真实存在的大网站，脚本装的时候就挑好了是哪一个。它走的是 TCP，稳定，平时就用它。
- **备用节点：Hysteria2**。它走的是 UDP，网络不好、晚高峰的时候往往更快。但有些地方的网络会限制 UDP，所以它只当备用：主节点连不上或者很慢的时候，再换它。

两个节点出口用的是同一台服务器（方案一访问 claude 时还都会转交同一个 ISP），所以在两个节点之间切换，claude 看到的 IP 是一样的，不算“换节点”。

用 claude 的时候，还要**固定用这一个节点，不要换来换去**。一会儿美国、一会儿日本，本身就很可疑。

**电脑：v2rayN**

1. 从 GitHub 下载 [v2rayN](https://github.com/2dust/v2rayN/releases)，选和你的系统对应的版本，解压。
2. 右键 v2rayN → **以管理员身份运行**。tun 模式要虚拟出一张网卡，需要管理员权限。
3. 复制节点链接，在 v2rayN 里：配置项 → 从剪贴板导入。
   - 方案一、二：节点是运行脚本最后打印的那两个，**通过剪贴板导入**，不要截图发来发去。
   - 方案三：复制商家给的订阅链接，同样从剪贴板导入。
4. 选中主节点，设为当前使用的节点。
5. 主界面底部：系统代理选“清除系统代理”，打开“启用 Tun”。
6. 确认 claude 走代理：不管用“规则”还是“全局”模式，claude 相关的域名都不能直连。不放心的话，用 claude 时直接开全局。

**电脑：Clash Verge**

1. 从 GitHub 下载 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases)，安装。
2. 导入节点：
   - 方案一、二：Clash Verge 导入不了 `vless://`、`hysteria2://` 这种分享链接。在服务器上运行 `cat /root/clash.yaml`，复制全部内容，在 Clash Verge 里新建一个本地配置粘贴进去保存。两个节点都在里面，默认选中备用节点 Hysteria2，因为 Clash 的内核连 Reality 节点目前有兼容问题，还在排查。
   - 方案三：复制商家给的订阅链接，在 Clash Verge 里导入订阅。
3. 设置 → 系统设置：打开“虚拟网卡模式”（也就是 tun 模式），第一次打开会提示安装服务模式，照着装上；“系统代理”保持关闭。
4. 和 v2rayN 一样，确认 claude 相关的域名不会直连。

不管用的是哪个方案，最后拿到的 IP 能不能用，都得测过才知道。IP 也有好有坏：有的被检测网站认成了机房 IP，有的被很多人用脏了、风险分很高。用这样的 IP 去注册 claude，前面做的就白费了。

## 小结：从服务器到代理软件

前面一下子讲了好多新东西：IP、节点、ISP、防火墙、代理软件、tun 模式。这一页不讲新的，只把它们串起来，看看你在电脑上打开 claude.ai 的那一刻，到底发生了什么。

**先回顾一下，我们要过两道关**

1. **防火墙**：守在国内网络通往海外的出口上，看你要去哪儿，不让过的就拦下来。
2. **claude 的风控**：看请求来自哪个 IP。来自中国的，制裁；来自机房的，像在用代理，容易封号。

前面做的所有事，都是为了把这两道关过了。

**打个比方**

把上网想成寄信。你访问 claude，就是给 claude 寄一封信，信封上写着你的寄件地址，也就是 IP，claude 看到寄件地址是中国，就不回信，还要制裁你。

- **节点**：你在海外找了个朋友，信先寄给他，由他用自己的地址转寄给 claude。claude 看到的寄件地址就是海外的了。
- **ISP 代理**：可这个朋友住在机房里，claude 一看就知道是代收代寄的。所以朋友再把信交给一个住在居民区的邻居，由邻居寄出去。claude 看到的就是一个普通居民的地址。
- **防火墙**：你的信要寄出国，先得过国内邮局的检查。邮局一看信是寄给海外朋友、要他帮忙转寄的，就会扣下来。
- **代理软件**：它把你的信装进一个不透明的信封，外面写成寄给一家普通的大公司。邮局看不出里面是什么，就放行了。朋友收到后拆开外层信封，再帮你转寄。
- **tun 模式**：规定家里所有人寄的信，都必须先交给代理软件装信封，谁也不能自己偷偷寄。

claude 回信的时候，也是原路返回：claude → 邻居 → 朋友 → 代理软件拆信封 → 你。

## 防泄漏

测完 IP 没问题，就可以开始配置防泄漏了。就算 IP 换好了，还有几个地方可能会把你的真实位置漏出去。

**DNS**

我们平时访问一个网站，输入的都是 `claude.ai`，而不是 IP 地址那一串数字。`claude.ai` 这个叫做**域名**，它的作用就是好记，方便用户访问。不然每次都要输入一大串数字，谁记得住？

那问题来了：输入的是域名，浏览器怎么知道请求要发给谁呢？毕竟网络是靠 IP 来找人的嘛。**DNS** 就是做这个的，它负责把域名翻译成 IP 地址。你可以把它想成一本电话簿：你报一个名字，它告诉你对应的号码，浏览器拿到号码，才能把请求发出去。

而这个过程，就有可能把我们真实的 IP 漏出去。

因为查电话簿本身也是一次请求，也要发给某个 DNS 服务器。如果这一步没走代理，而是直接问了国内运营商的 DNS 服务器，那对方就知道了两件事：你在国内，而且你要访问 claude.ai。你的请求明明是从海外节点出去的，查电话簿的时候却露了馅，这就叫 **DNS 泄漏**。

那换成国外的 DNS，比如 Cloudflare 的 `1.1.1.1`、Google 的 `8.8.8.8`，是不是就没事了？也不一定。如果你用国内的网络直接去问 `8.8.8.8`，它看到的提问者还是你国内的 IP。所以**关键不在 DNS 服务器是不是国外的，而在查电话簿的这个请求有没有走代理**。代理软件里说的“远程 DNS”，指的就是通过代理去查。

还有一个坑：浏览器自己也会查电话簿，叫“安全 DNS”。它可能绕过代理软件自己去查，所以除了设置代理软件，浏览器也要处理。

**WebRTC**

再来说 WebRTC。你在网页上直接打语音、视频电话，用的就是 WebRTC，它是浏览器自带的一项技术。

为了把电话接通，WebRTC 要知道你的 IP，有时候还会绕过代理，直接把你真实的 IP 交给网页。这样一来，前面 IP 换得再好，网页也能通过 WebRTC 拿到你国内的 IP，这就叫 **WebRTC 泄漏**。

所以要在浏览器里管住 WebRTC，不让它把真实 IP 交出去。

**IPv6**

IP 其实有两种。我们前面说的 IP，大多是 **IPv4**，就是 `1.2.3.4` 这样的四段数字。但上网的设备越来越多，IPv4 不够分了，于是又有了 **IPv6**，它长得像 `240e:3b5:...` 这样一大串，数量多到用不完。

现在国内很多家庭宽带，同时有 IPv4 和 IPv6。问题是，代理不一定接管了 IPv6。如果你访问的网站也支持 IPv6，电脑就可能直接用 IPv6 连过去，不经过代理，网站看到的就是你国内的 IPv6 地址，这就叫 **IPv6 泄漏**。

最简单的办法，就是在电脑上把 IPv6 关掉。

**怎么防**

下面的设置以 v2rayN 为例，用 Clash Verge 的看后面单独的说明。设置完都要测一下，检测网站用 [browserleaks.com](https://browserleaks.com)，它把 IP、DNS、WebRTC 分开测；也可以用 [ipleak.net](https://ipleak.net/)，一个页面全测完。

防 DNS 泄漏：

1. 确认代理软件开了 tun 模式（见 [[导入代理软件]]）。tun 模式会接管整台电脑的流量，系统发出的 DNS 请求也会被送进节点，这是最主要的一步。
2. v2rayN → DNS 设置：国外域名用远程 DNS（`1.1.1.1` 或 `8.8.8.8`），并且通过代理查询。
3. v2rayN → 路由设置：“域名解析策略”选 `AsIs`。这样代理软件只看域名决定走哪条线，不会为了判断先在本地查一次电话簿。
4. 关掉浏览器的“安全 DNS”，或者把它也改成国外的 DNS 服务商：
   - Chrome：设置 → 隐私和安全 → 安全 → 关闭“使用安全 DNS”。
   - Edge：设置 → 隐私、搜索和服务 → 关闭“使用安全 DNS”。

**检测**：打开 [browserleaks.com/dns](https://browserleaks.com/dns)，结果里不能有国内的 DNS（比如 China Telecom、China Unicom）。

防 WebRTC 泄漏：

- Chrome / Edge：装插件“WebRTC Control”；或者在 uBlock Origin 设置里勾选“防止 WebRTC 泄露本地 IP 地址”。
- Firefox：地址栏输入 `about:config`，把 `media.peerconnection.enabled` 改为 `false`。

**检测**：打开 [browserleaks.com/webrtc](https://browserleaks.com/webrtc)，“Public IP”里不能出现你国内的 IP。用方案一的，这里显示的是服务器的 IP，这是正常的，因为只有 claude 和 ipinfo.io 走 ISP。DNS、WebRTC 测出来的 IP 看不懂的，见 [[测出来好几个不同的 IP？]]。

防 IPv6 泄漏：

1. 先打开 [ipleak.net](https://ipleak.net/) 看一下，没有出现 IPv6 地址，或者出现的不是国内的，就不用管。
2. 出现了国内的 IPv6 地址，就在电脑上关掉 IPv6：
   - Windows：控制面板 → 网络和 Internet → 网络和共享中心 → 更改适配器设置 → 右键你正在用的网络（Wi-Fi 或以太网）→ 属性 → 取消勾选“Internet 协议版本 6 (TCP/IPv6)” → 确定。
   - Mac：系统设置 → 网络 → 你正在用的网络（Wi-Fi 或以太网）→ 详细信息 → TCP/IP → “配置 IPv6”选“仅本地链接” → 好。
3. 关掉之后再打开 ipleak.net 测一次，确认国内的 IPv6 不见了。

用 Clash Verge 的：

1. 确认已经打开“虚拟网卡模式”（tun 模式），见 [[导入代理软件]]。
2. 设置 → Clash 设置：打开“DNS 覆写”，增强模式选 `fake-ip`。这样软件拿到的是一个假的地址，真正的查询交给节点去做，不会在本地问国内的 DNS。
3. 浏览器的“安全 DNS”、WebRTC、IPv6，和上面一样处理。
4. 检测方法也和上面一样。

## 改时区

到这里，IP 换好了，泄漏的小缝也堵上了。那是不是就可以去注册 claude 了？还不行，还有一个容易忽略的地方：**时区**。

很早之前就有人说过：anthropic 会检测时区。浏览器会把你电脑的时区告诉网页，claude 一看：IP 在美国，时区却是中国，这就对不上了。

那问题来了：时区要改成哪儿？不一定要和住宅 IP 的所在地一致，但要是 **claude 支持的地区**，也就是 claude 官方公布的可用国家和地区名单。中国大陆和香港不在里面，台湾在。

我选的是台湾，因为它和北京一样是 UTC+8，看时间不会别扭。你可能会想：既然时间都一样，改不改有什么区别？区别在于，浏览器能读到的不只是时差，还有时区的**名字**，比如北京是 `Asia/Shanghai`，台北是 `Asia/Taipei`。名字对不上，一样会露馅。

**操作**

时区选 claude 支持的地区，比如台湾、新加坡；不确定就选住宅 IP 所在城市的时区，比如洛杉矶的 IP 就选 `America/Los_Angeles`。**中国大陆和香港不行。**

**手机和电脑都要改。**

**电脑**

- Windows：设置 → 时间和语言 → 日期和时间 → 关闭“自动设置时区” → 手动选时区。
- Mac：系统设置 → 通用 → 日期与时间 → 关闭“使用你的当前位置自动设定时区” → 手动选城市。

改完可以在 browserleaks.com 的 JavaScript 页面里看看浏览器报告的时区对不对。

**iPhone**

1. 设置 → 隐私与安全性 → 定位服务 → 系统服务（滑到最底下）→ 关闭“设定时区”。
2. 设置 → 通用 → 日期与时间 → 关闭“自动设置” → 手动选城市。

两步都要做。只做第 2 步的话，手机可能还会根据定位把时区改回来。

**安卓**

设置 → 系统 → 日期和时间 → 关闭“自动设置时区” → 手动选时区。不同品牌的菜单位置不太一样，找不到就在设置里搜“时区”。

## 注册 Gmail

电脑和手机的网络环境到这里就全部弄好了，接下来要准备账号。

先想一个问题：claude 要用什么注册？可以用邮箱，也可以直接用 Google 账号。我是用 **Google 账号**注册的。后面注册美区 Apple ID，也要用 **Gmail** 邮箱，因为 QQ 邮箱现在已经不能注册美区 Apple ID 了。所以一个 Google 账号（自带 Gmail）两边都用得上。

还记得整体思路里说的吗？claude 会看你是谁、在哪里。用一个国外常见的 Google 账号去注册，比用国内邮箱更像一个普通的海外用户。

**操作**

## 登录谷歌浏览器

Gmail 注册好了，你也就有了一个 **Google 账号**。Gmail 只是 Google 账号里的一个服务，同一个账号还能登录谷歌浏览器（Chrome）、YouTube、Google Play 这些。

接下来在电脑上用它登录谷歌浏览器。后面注册 claude 的时候，在浏览器里就能直接用这个 Google 账号登录，很方便。

登录之后，再把账号的基本信息完善一下。为什么呢？一个真实的人用的 Google 账号，名字、头像、生日这些一般都是填好的；一个什么都没有的空账号，看起来就像刚注册来干别的事的。

但是有一样**一定不要填：付款信息**，空着就可以。还记得订阅那里说的吗？付款方式也会暴露你在哪里。绑一张国内的卡上去，前面做的就白费了。我们后面也用不到 Google 账号付钱。

**操作**

1. 电脑上确认代理软件已经打开，下载 [谷歌浏览器](https://www.google.com/chrome/) 并安装。
2. 打开谷歌浏览器，点右上角的头像 → 登录，用刚注册的 Gmail 登录。
3. 打开 [myaccount.google.com](https://myaccount.google.com/)，在“个人信息”里完善基本信息，比如名字、头像、生日。
4. **“付款和订阅”里什么都不要填**，付款方式保持空着。


## 先用两天

Google 账号到手了，是不是马上就能去注册 claude？我建议先别急。

因为 **Google 账号也会封号**。一个刚注册的新号，什么都没干，转头就拿去注册 claude，有可能过几天 Google 账号自己先被封了，claude 账号也跟着受牵连。

所以我的建议是：**先简单用两天**。像一个普通人那样用这个 Google 账号：用它注册注册 X、Instagram，刷刷 YouTube，看一看外网。好不容易翻出来了，也顺便体验一下。

先用两天还有一个好处：这两天你一直在住宅 IP 的网络环境下用这个账号，下一步修改 Google 账号的关联地区也更方便。

这两天里会有两种情况：

- **封号了**：别慌，去申诉，见 [[被封了：申诉解封]]。一般很快就能通过。
- **一直没封**：说明这个号没问题，接着往下走，修改关联地区，再去注册 claude。

**操作**

1. 开着代理，用这个 Google 账号正常用两天：注册 X、Instagram，刷刷 YouTube，随便逛逛外网。
2. 两天后看看账号还能不能正常登录。能的话，进入下一步。


## 被封了：申诉解封

没被封的跳过这一页。

Google 账号被封，不一定是你做错了什么。新注册的号本来就容易被风控误伤。好在 Google 给了申诉的机会，一般**很快就可以通过**。

**操作**

1. 登录被封的账号时，页面会提示账号已停用，点页面上的申诉按钮（“申请恢复”或类似的字样）。
2. 跟着提示填写申诉理由，简单说明这是你自己在正常使用的账号就行。

## 修改 Google 账号地区

Google 账号也有一个“地区”。它指的是你的 Google 账号适用哪个国家/地区的服务条款，和 Google Play 的付款地区不是一回事，改了也不会删除你的邮件、云盘等数据。

## 注册 claude

终于到注册了。这一步本身很简单，用 Google 账号点几下就注册好了。难的是注册之前和注册之后的那些讲究。

为什么这么多讲究？因为注册是 claude 第一次认识你的时候。这一刻它看到的所有信息，IP、DNS、时区、账号，都会留下来。如果这时候还有哪一项没弄好，边注册边调，那它第一眼看到的就是一个“有问题的人”，后面再怎么补也晚了。

注册之后也一样。一个真实的用户，一般是先用一用免费版，觉得好用、额度不够了，才去订阅。刚注册就马上订阅，反而不像正常人。所以我建议先正常用几天，留下一段正常使用的记录，等它主动弹出升级提示，再订阅。这也是我的个人经验，anthropic 没有公布过相关规则。

还有一点：一个 IP 不要注册好几个账号。正常人一个人一个账号，同一个 IP 冒出一堆新账号，就像在批量注册。

**操作**

1. **前面的步骤全部做完、检测都通过，再去注册。** 不要边注册边调。
2. **用 Google 账号注册。**
3. **一个 IP 不要注册好几个账号。**
4. **注册后先正常用几天，不要急着订阅。** 最好把免费额度用完，等它主动弹出升级提示，再订阅。

## iPhone：在 App Store 登录

iPhone 上其实有两个地方登录 Apple ID：“设置”里的，和“App Store”里的。“设置”里的是 iCloud 账号，管的是照片、通讯录这些；App Store 里的账号只管买东西、下载 app。两边可以不是同一个账号。所以我们只在 **App Store** 里换成美区 Apple ID，“设置”里的还是你原来的账号，照片、通讯录都不受影响。

登录之后还要做几件事，每一件都有原因：

- **账单寄送地址填免税州**。美区会按账单地址所在的州收销售税。填免税州就不会多扣钱；不是免税州的话，余额刚好等于订阅价格时，会因为加了税不够扣，导致付款失败。
- **地址要真实存在、格式正确**，但不一定是你所在的地址，网上搜“免税州地址”都能找到。
- **付款方式保持“无”**。我们是用礼品卡充的余额付钱，不需要绑卡。
- **允许 App 内购买**。这是我遇到“购买未完成”时，Apple 客服让我检查的地方，最好提前设置好。

**操作**

1. 打开 **App Store（不是“设置”）** → 右上角头像 → 拉到最底部，退出原账号，登录美区 Apple ID。“设置”里的账号可以还是你原来的账号。
2. 配置**账单寄送地址**，**付款方式不要动**，保持“无”：
   1. 右上角头像 → 你的名字 →“账单寄送地址”。这一页的“付款方式”应该显示“无”。

![[09附件/订阅claude-AppleStore-1-账户设置.jpg|262]]

   2. 跳到“添加付款方式”页面，不用填。第一次进入时它可能要求把付款方式也填了才能保存，同样不用管，直接返回。

![[09附件/订阅claude-AppleStore-2-添加付款方式.jpg|262]]

   3. 返回后进入“管理付款方式”，点下面的“账单寄送地址”→ 右上角“编辑”，填一个**免税州的真实地址**（比如俄勒冈州），保存。

![[09附件/订阅claude-AppleStore-3-管理付款方式.jpg|262]]
![[09附件/订阅claude-AppleStore-4-账单寄送地址.jpg|262]]

## iPhone：购买未完成

订阅成功了的，跳过这一页。出问题才需要看。

我遇到过：在 app 里订阅 Pro 时提示“Purchase Not Completed”，付款被拒绝，没订阅上。我的建议是：**别自己硬扛，让 AI 带着你走完。**

为什么靠 AI？因为这一步要和 Apple 客服打交道，而且很可能是英文客服。每一步该检查什么、该怎么跟客服说，AI 比我们自己摸索要快得多。

1. **先问 AI**。把报错截图、App Store 账户设置的截图发给 AI（比如 claude 免费版、ChatGPT 都可以），说明你在用美区 Apple ID 订阅 claude 时提示购买未完成。它会帮你逐项检查设置，比如付款方式、账单地址、是否允许 App 内购买。
2. **按 AI 说的联系客服**。检查完还是不行的话，AI 最后一般会让你联系 Apple 客服。打开苹果自带的“支持”app（Apple Support），在里面找在线客服。
3. **注意账号的区别**。用来订阅的是美区账号，但“支持”app 里登录的是你 iCloud 的主账号，也就是国区账号。所以客服大概率会给你转接海外客服，对方说英文。**别担心，继续靠 AI**：客服发一句，你复制给 AI；AI 给出回答，你再复制给客服。开头记得让 AI 帮你跟客服说清楚，你要处理的是 App Store 上登录的那个美区账号，不是 iCloud 账号。
4. **最好的情况是客服让你等 72 小时**。我就是这样。客服会给你一个 Case ID，记下来。**这 72 小时里什么都别做**：不要尝试购买，不换账号，也不要改付款信息和账单地址。
5. **72 小时后再买**。还是失败的话，带着 Case ID 再联系客服，同样让 AI 帮你沟通。

## SSH 提示 Permission denied？

输完 root 密码回车，屏幕上出现 `Permission denied, please try again.`，接着又让你输 `password:`。意思是服务器不认这个密码，不让你进。

最常见的原因是密码输错了。输密码的时候屏幕上什么都不显示，多一个空格、少一个字符都看不出来。先仔细地再输一两次，还是不行的话，按下面的顺序一个一个试：

1. **重置密码，重新连。** 在商家后台把 root 密码改成一个新的，然后关掉现在的命令行窗口，新开一个，重新 `ssh root@你的服务器IP`，输入新密码。
2. **重启电脑**，再重新连一次。
3. **不用 SSH，从商家后台进服务器。** 商家后台一般有一个“登录控制器”（有的叫“控制台”或者“VNC”），点进去就是这台服务器的命令行，和 SSH 连上之后是一样的。在里面用 root 和密码登录，直接把脚本的命令粘贴进去运行就行。最后打印的节点链接复制不出来的话，手机可以直接扫下面的二维码。
4. **申请退款。** 上面都试过还是不行，就找商家退款。还想用这个方案的话，可以再买一台。

## 装过了，想重装？

在服务器上运行同一行脚本命令就行。脚本发现装过会先问你，回答 `y` 删掉旧的重新装，回答别的什么都不动。重装后节点链接会变，代理软件里要删掉旧节点、重新导入。

**重装前先关掉电脑上的代理软件**（或者关掉 TUN / 全局模式），再 SSH 连服务器。为什么呢？因为 SSH 可能正好走的是这台服务器上的节点，脚本一删旧节点，SSH 就跟着断了，出现 `Connection to ... closed by remote host`，之后还可能连不上服务器。新版脚本遇到这种情况会提示你先关代理，什么都不删。已经遇到的，关掉代理（或者干脆重启电脑）再 SSH 连上，重新运行一次命令就好。

## 面板的用户名、密码、端口，大家都一样，安全吗？

是的，用我的脚本装的面板，每个人都一样：用户名 `admin`，密码 `123456`，端口 `8080`。这是我故意设成一样的，最开始是为了方便我远程连上去，帮大家排查问题。

那别人知道了这套用户名密码，能不能登上你的面板呢？不能。还记得打开面板之前，你在自己电脑上运行的那行 `ssh -L` 命令吗？它后面跟着你的服务器 IP，接着还要你输服务器的 root 密码。面板只开在服务器本机，从外面直接访问是打不开的，要进面板，就得先用 SSH 打一条隧道，而打隧道要服务器密码。也就是说，面板外面还有一道门，钥匙是你的服务器密码。**除非别人知道你的服务器密码，不然是上不了你的面板的。**

所以不改也行。想改当然也可以，**直接在浏览器的面板里改最方便**。终端里也能改，但是麻烦。我装面板，本来就是为了方便大家手动操作。

改了之后，原来的节点还能不能用？得看你改了什么。面板是管理节点的后台，节点是代理软件要连的东西，这是两回事：

- **面板的用户名、密码**：没关系，节点照常用。
- **面板的端口**：也没事。只是下次打开面板，`ssh -L` 命令和浏览器地址里的 `8080` 要换成新端口。
- **节点的端口**：节点就不能用了。为什么呢？因为节点链接里写着要连哪个端口，代理软件还在按旧端口去连。你需要去放开节点的新端口，并重新导出链接，在代理软件里删掉旧节点、重新导入。
- **“入站”里的其他设置**：同样的道理，改了要重新导出链接，重新导入。

## 测出来好几个不同的 IP？

ipinfo.io 上是一个 IP，商家后台写的是另一个，别的测 IP 网站又是一个，DNS 检测里还有别的……看懵了很正常。其实这几个 IP 各是各的东西，并不是哪里出错了。

先回忆一下方案一的结构：你的请求先到服务器，**只有 claude 和 ipinfo.io 再从服务器转给 ISP 出去**，其他网站都从服务器自己的出口出去（见 [[四、购买 ISP 代理]]）。按这个去对：

- **ipinfo.io 上看到的，是 ISP 的 IP。** 它是住宅 IP，claude 看到的就是这一个。
- **商家后台、别的测 IP 网站（比如 api.ipify.org）看到的，是服务器的 IP。** 服务器大多是机房 IP。ISP 的流量少，所以我只让 claude 和 ipinfo.io 走它，别的网站看到的自然就是服务器。
- **DNS 检测里列出来的，是 DNS 服务器的 IP。** 防泄漏那一步，我们让代理软件不在本地查电话簿，而是借用 Cloudflare、Google 这些大公司的 DNS 去查（见 [[防泄漏]]）。所以测出来的是它们的地址，不是你的，也不在国内，这正是我们想要的。
- **WebRTC 检测里 Local IP、Public IP 显示 `-`**，说明 WebRTC 已经被管住了，什么 IP 都没交出去，也是对的。

如果你在 [[四、购买 ISP 代理]] 选了所有网站都走 ISP，那除了 DNS，别的网站看到的也都是 ISP 的 IP。

## 分流规则具体怎么写？

意思是只让 claude 相关的网站走住宅节点，其他网站照旧走原来的节点。方案一、二的脚本已经在服务器上做好了分流，不用管这一条；这里说的是方案三“已经有节点”的情况。

至少要包含这几个域名：`claude.ai`、`claude.com`、`anthropic.com`，再加上用来检测的 `ipinfo.io`。

**Clash Verge（mihomo 内核）**：在规则里加上下面几行，`住宅节点` 换成你的节点或策略组名字，并且放在其他规则前面：

```
- DOMAIN-SUFFIX,claude.ai,住宅节点
- DOMAIN-SUFFIX,claude.com,住宅节点
- DOMAIN-SUFFIX,anthropic.com,住宅节点
- DOMAIN-SUFFIX,ipinfo.io,住宅节点
```

**Shadowrocket**：在“配置”→“规则”里新增 `DOMAIN-SUFFIX` 类型的规则，域名同上，策略选住宅节点。

**v2rayN**：它的路由规则一般只能选“代理 / 直连 / 阻断”，不方便指定某一个节点。用 v2rayN 的话，最简单的办法是用 claude 时直接切到住宅节点。

看不懂也没关系：不分流，用 claude 时直接全局走住宅节点，最不容易出错。
