## 整体思路
---
我的理解是：anthropic 会从很多地方判断你是谁、在哪里，比如 IP、DNS、浏览器、时区、账号地区、付款方式。**只要其中一项露出“我其实在国内”，就有风险。**

所以下面每一步，其实都在做同一件事：**让每一项信息都不露出“我在国内”，而且像一个普通用户。**

**整体流程：** 准备网络环境 → 配置代理软件 → 检查泄漏 → 改时区 → 准备 Google 账号 → 注册 claude 并先用几天 → 用美区 Apple ID 订阅 → 慢慢增加使用量。

这里面涉及好几个账号和环节，先看清它们的关系：

```
【你是谁】  Google 账号 ──注册/登录──▶ claude 账号
                                          ▲
【从哪来】  手机/电脑（tun、分流）──▶ 住宅 IP ──▶ claude.ai
            （注册、使用、订阅，全程都走这条线）     │
                                          │
【谁付钱】  支付宝 ─买─▶ 礼品卡 ─充值─▶ 美区 Apple ID 余额
                                   │
                                   ▼
                    在 claude iOS app 里升级，用余额付款
                    订阅加到你的 claude 账号上
```

**claude 账号是用 Google 账号注册的，和 Apple ID 没有关系**，美区 Apple ID 只负责付钱。

## 网络环境
---
这一块是最重要的，千万不要用万人蹬的机场节点。机场的 IP 是成百上千人在共用，很可能早就被 anthropic 标记过了。

我们要的效果是：**anthropic 看到的是一个家庭宽带的 IP，而且只有你自己在用。** 机房 IP 能被识别出来，机场 IP 被人用脏了，都不行。

>[!note] 机房 IP 和住宅 IP
>每个 IP 都登记在某个组织名下，网站一查就知道。VPS 放在机房里，IP 登记在云服务商名下，就是**机房 IP**，普通人不会从机房上网，所以容易被当成代理。**住宅 IP** 登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在上网。检测网站上的 **ISP** 类型，指的是运营商的 IP 放在机房里长期固定使用，也算这一类。

下面三种方案都能达到这个效果，区别在于花多少钱、折腾多少。先看对比，再挑一个照着做：

| 方案                 | 链路                           | 折腾程度 | 适合谁           |
| ------------------ | ---------------------------- | ---- | ------------- |
| 一：自建节点 + 套住宅 IP    | 电脑 → VPS → 住宅 IP → claude.ai | 高    | 喜欢折腾、想自己完全掌控  |
| 二：住宅 IP 服务器 + 自建节点 | 电脑 → 住宅 IP 服务器 → claude.ai   | 中    | 愿意自建，但不想配链式代理 |
| 三：直接买住宅节点          | 电脑 → 住宅节点 → claude.ai        | 低    | 不想碰服务器，导入就能用  |

**选好方案后，只看对应的那一小节，看完直接跳到「确认出口 IP」**，其他两个方案不用看。

不管选哪种，买之前都先找商家要 IP，用 [ipinfo.io](https://ipinfo.io/what-is-my-ip)、[scamalytics.com](https://scamalytics.com/) 交叉测一下，重点看 IP 类型是不是“住宅/ISP”、风险分数高不高。（ping0.cc 会暴露你国内的真实 IP，不建议用）

### 方案一：自建节点 + 套住宅 IP

这是我自己在用的方案。VPS 负责“翻出去”，住宅 IP 负责“最后一跳”。

**1. 自建节点**

详细教程：[[04技术/自建梯子：VPS + 3x-ui + VLESS Reality|自建梯子：VPS + 3x-ui + VLESS Reality]]

简单说就是：买一台 VPS → SSH 连上去 → 装 3x-ui 面板 → 放行端口 → 建一个 VLESS + Reality 的节点 → 导入代理软件。

自建的好处是这个节点只有你自己在用，IP 不会被别人用脏。但普通云 VPS 的 IP 是机房 IP，anthropic能识别出来，所以还要再套一层住宅 IP。

**2. 套住宅 IP**

详细教程：[[04技术/给 VPS 节点套上住宅 IP|给 VPS 节点套上住宅 IP]]

1. 买住宅代理：商家会给你协议、IP、端口和账号密码。我用的是 [proxy.qsu.hk](https://proxy.qsu.hk/)，注意它和主站 qsu.hk 卖的东西不一样，主站卖的是方案二的住宅服务器。
   **免费套餐**：在 proxy.qsu.hk 注册账号后，选择 **SOCKS5 协议**的套餐，下单时填写优惠码 `qiansu998`，就可以免费拿到一个住宅 IP 端口。优惠码随时可能失效，流量额度等以下单页面为准。
2. 新增出站：在 3x-ui 的 Xray 设置里添加一个出站，然后按下表填写信息：

| 设置项     | 填写内容                           |
| ------- | ------------------------------ |
| 协议      | SOCKS5                         |
| 标签（Tag） | 起一个好认的名字，比如 `residential`，后面要用 |
| 地址      | 住宅 IP 地址                       |
| 端口      | 商家给的端口                         |
| 用户名、密码  | 商家给的账号密码                       |

3. 新增路由规则：让 anthropic 相关的域名走住宅 IP，出站标签选 `residential`：

```
domain

geosite:anthropic
```

4. 保存并重启 Xray，不重启不生效。

如果住宅 IP 流量够多，也可以在“路由”的“默认出站”里直接选住宅 IP，所有流量都走它，省得一个个加域名。

### 方案二：买住宅 IP 服务器，再自建节点

如果你愿意自建，但嫌链式代理麻烦，可以直接买一台**自带住宅 IP 的服务器**。服务器本身的出口就是住宅 IP，只要在上面自建节点，不用再套一层。

推荐的购买地址：
- [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M)（我使用的是它家的云VPS，住宅服务器**我没有使用过**。网上关于住宅服务器的主要的负面评价是：这个产品不是真正的家庭宽带，也不是双 ISP，所以仅供参考。）
- [QSU](https://qsu.hk/aff/GAZUQBSL)（我用的是它家子站 proxy.qsu.hk 的住宅代理，主站的住宅服务器**我没有使用过**。）

1. 买之前先测服务器 IP，确认是“住宅/ISP”类型、风险分数低。
2. 拿到服务器后，按 [[04技术/自建梯子：VPS + 3x-ui + VLESS Reality|自建梯子：VPS + 3x-ui + VLESS Reality]] 走一遍：SSH 连上 → 装 3x-ui → 放行端口 → 建 VLESS + Reality 节点 → 导入代理软件。
3. 不用再套住宅 IP。

### 方案三：直接买住宅节点

完全不想碰服务器的话，就直接买现成的住宅节点。比如 ipequal，它卖的是 VLESS Reality 节点，出口是美国静态住宅 IP，国内直连，不需要再套链式代理，导入订阅链接就能用。

选套餐时注意看“使用类型”，**选 1 人独享的**。共享套餐是几个人用同一个 IP，和机场一个道理，用的人多了照样可能被标记。

**还没有节点**

推荐的购买地址（国内可直接打开）：[ipequal](https://www.ipequal.com/?ref=6adabd0307)（**我没用过**，因为一直买不到。我在研究网络环境时，看到很多大佬推荐过 IPEqual，它是直接卖带住宅 IP 的订阅，不用自己搭。建议先买一个月试试。）

```
你的电脑 → 住宅节点 → claude.ai
```

1. 注册并购买独享套餐。
2. 复制订阅链接，导入代理软件（Clash Verge、v2rayN、小火箭等都支持，**尽量通过剪贴板导入**）。
3. 选中这个节点，开启代理即可。

**已经有节点**

推荐的购买地址（需要开代理打开）：[ipequal](https://www.equaldcdn.com/?ref=6adabd0307)

```
你的电脑 → 住宅节点 → claude.ai（anthropic 相关）
你的电脑 → 原来的节点 → 其他网站
```

1. 注册并购买独享套餐，把订阅链接导入代理软件。
2. 在代理软件里加分流规则，让 anthropic 相关的域名走住宅节点，其他流量照旧走原来的节点。这样住宅流量只花在刀刃上。
3. 嫌分流麻烦，也可以直接把全部流量切到住宅节点，只是流量消耗会快一些。

### 确认出口 IP

不管用哪种方案，最后都要确认一下出口。

开着代理访问 [ipinfo.io](https://ipinfo.io/what-is-my-ip)，显示的是住宅 IP、类型是住宅/ISP，就说明成功了。如果你只让 anthropic 的域名走住宅 IP（方案一的分流，或方案三“已经有节点”的分流），要把 `ipinfo.io` 也加进同一条规则，否则测出来的是原来节点或 VPS 的 IP。方案一在 3x-ui 里加：

```
domain:ipinfo.io
```

记住这个 IP 所在的地区，后面选时区、改 Google 账号地区时都会用到。

## 配置代理软件
---
节点搭好了，还要保证电脑和手机上的流量真的都走了它。

### 1. claude 必须走代理

不管用的是“规则”模式还是“全局”模式，都要确认 claude 相关的域名走的是代理，不能直连。不放心的话，用 claude 的时候直接开全局。

### 2. 桌面端必须开 tun 模式

普通的“系统代理”只对浏览器这类会读系统代理设置的软件生效。claude 的桌面客户端、一部分系统请求可能不认系统代理，就会绕过节点直连出去。

tun（虚拟网卡）模式会在系统里虚拟出一张网卡，接管整台电脑的流量，不管软件认不认代理，都会被送进节点。

以 v2rayN 为例：**要以管理员身份运行**，然后在主界面底部打开“启用 Tun”。

### 3. 手机

iOS 上的 Shadowrocket 这类软件本身就是以 VPN 的方式接管整台手机的流量，相当于自带 tun 模式。只要确认 claude 走的是你的节点就行。

### 4. 不要频繁换节点

用 claude 的时候，固定用这一个节点。一会儿美国、一会儿日本，本身就很可疑。

## 防止泄漏
---
就算 IP 换好了，还有两个地方可能会把你的真实位置漏出去：DNS 和 WebRTC。

最方便的检测网站是 [browserleaks.com](https://browserleaks.com) ，它把 IP、DNS、WebRTC 都分开测了；也可以用 [ipleak.net](https://ipleak.net/) ，一个页面全测完。

### 1. DNS 泄漏

**是什么：** 访问一个网站之前，电脑要先问 DNS 服务器“这个域名对应哪个 IP”。如果这一步没走代理，而是问了国内运营商的 DNS，那对方就知道你在国内，而且知道你在访问 `claude.ai`。

**怎么防：**

1. **开 tun 模式**。tun 模式会把系统的 DNS 请求也接管过来，这是最主要的一步。
2. **检查代理软件的 DNS 设置**。在 v2rayN 的 DNS 设置里，让国外域名使用远程 DNS（比如 `1.1.1.1`、`8.8.8.8`），并且通过代理去查询。
   另外，把 v2rayN 路由设置里的“域名解析策略”选为 `AsIs`。这样代理软件只按域名分流，不会为了判断走哪条线先在本地查一次 DNS。它是远程 DNS 的补充，不能代替上面的设置。
3. **关掉浏览器自己的“安全 DNS”**，或者把它也改成国外的 DNS 服务商，免得浏览器绕开代理软件自己去查。

**怎么测：** 打开 browserleaks.com/dns ，结果里**不应该出现任何国内的 DNS 服务器**（比如显示“China Telecom”“China Unicom”这类运营商）。

### 2. WebRTC 泄漏

**是什么：** WebRTC 是浏览器用来做语音、视频通话的技术。它为了建立连接，可能绕过代理，直接把你的真实 IP 暴露给网页。

**怎么防：**

- **Chrome / Edge**：装一个插件，比如“WebRTC Leak Prevent”；或者如果你装了 uBlock Origin，在它的设置里勾选“防止 WebRTC 泄露本地 IP 地址”。
- **Firefox**：地址栏输入 `about:config`，把 `media.peerconnection.enabled` 改为 `false`。

**怎么测：** 打开 browserleaks.com/webrtc ，看 “Public IP” 那一栏，**只能出现你的住宅 IP**，不能出现国内的 IP。

### 3. IPv6 泄漏

如果你家的网络有 IPv6，而代理没有接管 IPv6，那 IPv6 的流量可能会直接连出去。检测网站上如果出现了一个国内的 IPv6 地址，最简单的办法是在电脑网卡设置里把 IPv6 关掉。

## 时区
---
很早之前就有人说过：anthropic 会检测时区。

**时区不一定要和住宅 IP 的所在地保持一致，但是需要是claude支持的地区**，比如新加坡、台湾都可以，我改成了台湾。“支持的地区”指 claude 官方公布的可用国家和地区名单，中国大陆和香港不在里面，台湾在。我选台湾，是因为它和北京一样是 UTC+8，电脑和手机上的时间跟我的日常作息对得上，看时间不会别扭。

如果你不确定选哪个，直接选住宅 IP 所在城市的时区最省心，比如洛杉矶的 IP 就选 `America/Los_Angeles`。

> [!note] 都是 UTC+8，为什么还要改 北京和台北的时差一样，但浏览器能读到的不只是时差，还有时区的名字，比如 `Asia/Shanghai` 和 `Asia/Taipei`。名字对不上，一样会露馅。

**手机和电脑都要改。**

### 电脑（Windows）

“设置”→“时间和语言”→“日期和时间”：关闭“自动设置时区”，手动选择你要用的时区（比如我选的是台北）。

改完之后，可以在 browserleaks.com 的 JavaScript 页面里看看浏览器报告的时区对不对。

### 苹果手机

1. 先关掉根据定位自动设置时区：“设置”→“隐私与安全性”→“定位服务”→“系统服务”（滑到最底下）→ 关闭“设定时区”；
2. 再到“设置”→“通用”→“日期与时间”：关闭“自动设置”，手动选择对应的城市。

只做第 2 步的话，手机可能还会根据定位把时区改回来，所以第 1 步不能省。

## Gmail 与 Google 账号
---
后面注册 claude 要用到谷歌账号、注册美区 Apple ID 要用到 Gmail。**美区 Apple ID 现在已经不能用 QQ 邮箱注册了**，所以没有 Gmail 的话，先注册一个。

### 1. 注册 Gmail

1. **先把手机的代理也配好**。电脑上的节点确认没问题之后，在手机上做同样的设置，Gmail 的注册在手机上完成。
2. **下载 Gmail**。iOS 用户在 App Store 直接搜索 Gmail；安卓用户先下载 Google Play，再从 Google Play 里下载 Gmail。Google Play 要从手机自带的应用商店或其他可信的来源下载，不要随便在网上找安装包，来路不明的版本可能被改过。
3. **创建邮箱以及账号**。打开 Gmail，在“设置电子邮件”里选择“Google”，然后点“创建账号”，跟着提示操作就行。手机号验证可以用 +86 的国内号码。

### 2. 修改关联地区（非必需的操作）

我是用 Google 账号注册 claude 的，所以想让 Google 账号这边也和住宅 IP 对上。这个做法网络上并没有依据，**只是我个人觉得**如果Google账号关联地区和IP对上会好一点。

Google 会给每个账号关联一个国家/地区。查看方法：打开 policies.google.com/terms ，页面上会写“国家/地区版本”。

如果显示的是中国大陆或者香港，可以在同一个页面里申请更改为住宅 IP 所在的地区。Google 会人工审核，可能要等一段时间，审核时你也最好一直处在住宅 IP 的网络环境下。

## 注册 claude
---
1. **前面的步骤全部做完，再去注册。** 网络环境、泄漏检测、时区、Google 账号都确认没问题之后再开始，不要边注册边调。
2. **尽量使用 Google 账号注册。**
3. **一个 IP 不要注册好几个账号。**
4. **注册成功后先正常用几天，不要急着订阅。** 最好是把免费额度用完，等它主动弹出升级提示，再按下面的方法订阅。

## 支付
---
支付也是非常重要的。用国内的卡直接订阅，基本不用想。

我用的是 iPhone，所以下面只写了苹果的方法。**安卓用户我没办法给出验证过的方案**。听说可以用美区 Google Play 礼品卡，但我没试过，也没仔细了解过，需要的话请到别处找找做过的人的经验。

我的方法是：**美区 Apple ID + 礼品卡充值余额 + 在 claude 的 iOS app 里直接订阅**。

这样 anthropic 那边看到的付款方是美区 App Store。支付宝只用来买礼品卡，不会直接出现在 claude 的订阅里。

### 1. 准备美区 Apple ID

新注册一个美区 Apple ID，具体步骤见文末常见问题里的「美区 Apple ID 怎么注册？」。如果你已经有一个正常使用的美区 Apple ID，直接用就行，不用重新注册。

注册好之后，在 **App Store（不是设置）** 里登录这个美区账号：右上角头像 → 拉到最底部，退出原账号，再登录美区账号。设置里的账号可以是你原来就用的账号。然后搜 Claude，认准开发者是 Anthropic，下载官方 app。

登录之后，要配置**账单寄送地址**。**只填账单地址，付款方式不要动**，保持“无”就行，不要添加或修改。地址可以填一个免税州的（比如俄勒冈州）。美区会按账单地址所在的州收销售税，填免税州就不会多扣钱，余额不够扣税会导致付款失败（见下一步的注意事项）。

1. 打开 App Store → 右上角头像 → 点你的名字 →“账单寄送地址”。这一页的“付款方式”应该显示“无”。

![[09附件/订阅claude-AppleStore-1-账户设置.jpg|262]]

2. 这时会跳转到“添加付款方式”页面，不用管它。第一次进入时，它可能要求把付款方式也填了才能保存，同样不用管，直接返回。

![[09附件/订阅claude-AppleStore-2-添加付款方式.jpg|262]]

3. 返回后会进入“管理付款方式”页面，下面就有“账单寄送地址”。点进去，再点右上角“编辑”，修改并保存。

![[09附件/订阅claude-AppleStore-3-管理付款方式.jpg|262]]
![[09附件/订阅claude-AppleStore-4-账单寄送地址.jpg|262]]

然后确认手机允许 App 内购买。这是我遇到“购买未完成”时，Apple 客服让我检查的地方，最好提前设置好：“设置”→“屏幕使用时间”→“内容与隐私访问限制”→“iTunes 与 App Store 购买项目”→“App 内购买项目”，选“允许”。

### 2. 买礼品卡充值

我是在 pockyt shop 用支付宝买的：

1. 打开手机浏览器，搜索[pockyt shop](https://shop.pockyt.io)，认准网址是 shop.pockyt.io。

![[09附件/订阅claude-pockyt-1-搜索.jpg|262]]
![[09附件/订阅claude-pockyt-2-搜索结果.jpg|262]]

2. 进入之后，点击左上角“游客”，进入登录页。

![[09附件/订阅claude-pockyt-3-游客.jpg|262]]
![[09附件/微信图片_20261007133655_1_2.jpg|262]]

3. 在登录页的“其他登录方式”里选择支付宝，会跳转到支付宝里。在“美国”分类下选择“App Store & iTunes”，输入面额购买。建议是先买2刀，确认到账再买5刀，一点一点增加，不要一下子就买20刀；如果显示“缺货”，等页面上写的恢复时间再来买。

![[09附件/订阅claude-pockyt-5-登录后首页.jpg|262]]
![[09附件/订阅claude-pockyt-6-选择礼品卡.jpg|262]]
![[09附件/订阅claude-pockyt-7-输入面额.jpg|262]]

4. 买到后，在订单页面复制礼品卡号码。回到 App Store，点右上角头像 →“兑换代码”，把号码填进去，余额就充进美区 Apple ID 了。

![[09附件/订阅claude-兑换-1-礼品卡号码.jpg|262]]
![[09附件/订阅claude-兑换-2-兑换代码.jpg|262]]

注意：

- **也可以从别的靠谱的渠道买**。来路不明的便宜卡可能是“黑卡”，兑换之后 Apple ID 可能被锁。
- **余额要比订阅价格多一点**。如果账单地址不在免税州，会多扣一笔销售税，余额刚好等于订阅价格的话可能扣款失败。

### 3. 在 app 内订阅

在 Claude app 里登录你的 claude 账号，点升级，选择要订阅的方案，用 Apple ID 余额付款。

订阅之后，可以在 App Store → 右上角头像 →“订阅”里管理或取消。

如果提示“购买未完成”（Purchase Not Completed）或付款被拒绝，先别反复重试，看文末常见问题里的「订阅时提示购买未完成怎么办？」。

首先恭喜你成功订阅🎉。我成功订阅的时候，就像我发的帖子说的，手在微微发抖。但是有一些注意事项你要知道：

- **刚开始不要用太多**，一点一点增加使用量。
- **网络环境保持不变**：继续用同一个节点、同一个住宅 IP，不要今天这里明天那里。
- **不要在一堆设备上同时登录**，尤其不要在没走代理的设备上登录。

## 常见问题
---
这一部分是正文没展开的细节，卡住了再来查，不看也能照着正文做完。

### “1 人独享”怎么确认真的只有我在用？

说实话，**没法百分百确认**，只能间接看：

- 连续几天测 IP，地址一直不变；
- scamalytics 上的风险分数一直很低，没有慢慢变高；
- 买之前问清楚商家，是“独享 IP”，还是只是“独享带宽”。

所以才建议先买一个月试试。

### 分流规则具体怎么写？

意思是只让 claude 相关的网站走住宅节点，其他网站照旧走原来的节点。至少要包含这几个域名：`claude.ai`、`claude.com`、`anthropic.com`，再加上用来检测的 `ipinfo.io`。

**Clash Verge（mihomo 内核）**：在规则里加上下面几行，`住宅节点` 换成你的节点或策略组名字，并且放在其他规则前面：

```
- DOMAIN-SUFFIX,claude.ai,住宅节点
- DOMAIN-SUFFIX,claude.com,住宅节点
- DOMAIN-SUFFIX,anthropic.com,住宅节点
- DOMAIN-SUFFIX,ipinfo.io,住宅节点
```

**Shadowrocket**：在“配置”→“规则”里新增 `DOMAIN-SUFFIX` 类型的规则，域名同上，策略选住宅节点。

**v2rayN**：它的路由规则一般只能选“代理 / 直连 / 阻断”，不方便指定某一个节点。用 v2rayN 的话，最简单的办法是用 claude 时直接切到住宅节点。

看不懂也没关系：不分流，用 claude 时直接全局走住宅节点，最不容易出错。

### 不开 tun 模式会怎样？

claude 桌面端的部分请求、系统发出的 DNS 查询，可能会直接用国内网络连出去，claude 就会看到你的国内 IP。

### “远程 DNS”是什么？开了 tun 为什么还要测泄漏？

开了 tun 也建议测一遍，因为浏览器自己的“安全 DNS”、WebRTC 都有可能绕过去。

**远程 DNS**：`1.1.1.1` 是 Cloudflare 的 DNS 服务器，`8.8.8.8` 是 Google 的。“远程”指的是**通过代理**去问它们。重点在“通过代理”，而不在“国外”：如果用国内网络直接去问 `8.8.8.8`，对方看到的提问者还是你的国内 IP。所以**国外 DNS 不等于安全，查询也要走代理才行。**

### 改 Google 账号地区、注册后先用几天，是必须的吗？

都不是硬性要求，是我的个人经验，anthropic 没有公布过相关规则。

- **Google 账号地区**：指的是你的 Google 账号适用哪个国家/地区的服务条款，和 Google Play 的付款地区不是一回事。改地区不会删除你的邮件、云盘等数据。
- **先用几天**：我的想法是，先留下一段正常使用的记录再订阅，看起来更像真实用户。用完免费额度、等它主动弹出升级提示，也是同样的考虑。

### 美区 Apple ID 怎么注册？地址要真实吗？礼品卡买多少？

- **注册**：

1. 用浏览器打开 appleid.apple.com，手机、电脑都可以（下面是手机的截图）。

![[09附件/订阅claude-AppleID-1-打开网址.jpg|262]]

2. 点右上角的箭头展开菜单，选“创建你的 Apple 账户”。

![[09附件/订阅claude-AppleID-2-创建账户.jpg|262]]

3. 国家/地区选“**美国**”，姓名可以填拼音，生日要满 18 岁。邮箱用前面注册的 Gmail，要求是没注册过 Apple ID（QQ 邮箱现在已经不能用了）。手机号可以用 +86 国内号码接收验证码。

![[09附件/订阅claude-AppleID-3-选择美国.jpg|262]]

4. 完成邮箱和手机验证，账号就建好了。好了之后，重新登录一次，确认地区是美国。**付款方式不用填写**。

- **地址**：选免税州是为了不扣销售税，余额刚好够付订阅费。地址要是真实存在、格式正确的美国地址，但不一定是你所在的地址，去网上搜都可以找到免税州地址。

- **礼品卡金额**：以 claude app 里显示的价格为准。app 内价格可能和网页版不一样，所以比订阅价格多充一点。

### 订阅时提示购买未完成怎么办？

我遇到过：在 app 里订阅 Pro 时提示“Purchase Not Completed”，付款被拒绝，没订阅上。我的建议是：**别自己硬扛，让 AI 带着你走完。**

1. **先问 AI**。把报错截图、App Store 账户设置的截图发给 AI（比如 claude 免费版、ChatGPT 都可以），说明你在用美区 Apple ID 订阅 claude 时提示购买未完成。它会帮你逐项检查设置，比如付款方式、账单地址、是否允许 App 内购买。
2. **按 AI 说的联系客服**。检查完还是不行的话，AI 最后一般会让你联系 Apple 客服。打开苹果自带的“支持”app（Apple Support），在里面找在线客服。
3. **注意账号的区别**。用来订阅的是美区账号，但“支持”app 里登录的是你 iCloud 的主账号，也就是国区账号。所以客服大概率会给你转接海外客服，对方说英文。**别担心，继续靠 AI**：客服发一句，你复制给 AI；AI 给出回答，你再复制给客服。开头记得让 AI 帮你跟客服说清楚，你要处理的是 App Store 上登录的那个美区账号，不是 iCloud 账号。
4. **最好的情况是客服让你等 72 小时**。我就是这样。客服会给你一个 Case ID，记下来。**这 72 小时里什么都别做**：不要尝试购买，不换账号，也不要改付款信息和账单地址。
5. **72 小时后再买**。还是失败的话，带着 Case ID 再联系客服，同样让 AI 帮你沟通。
