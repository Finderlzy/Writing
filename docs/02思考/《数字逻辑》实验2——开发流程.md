> 写于 2026-10-27

开发流程主要集中在软件开发，硬件部分没有，软件开发完之后，通过 USB 下载到硬件上面即可。软件开发主要有几个部分：**新建工程 ——> 写描述源文件（HDL）-> 实现与仿真 -> （仿真没问题）添加约束 -> 生成 bitstream**。

新建工程为什么要提一嘴，因为**工程路径不能有中文**，别问我怎么知道。

用 Verilog 语言描述电路：
1. 左侧 Flow Navigator 里点 **Add Sources**。
2. 选 Add or create **design** sources → Next → **Create File**，File type 保持 Verilog，File name 填工程名字，OK → Finish。
3. 弹出的 Define Module 窗口直接点 OK，再点 Yes 确认，端口我们自己在代码里写。
4. 在 Sources 窗口双击 `（工程名字）.v` 打开，在这里面写代码。
5. 写完之后 Ctrl+S 保存。

写完 HDL 之后，在正式上板子之前，要先做仿真测试。仿真测试就是用电脑模拟输入信号，得到输出信号，并生成波形图。我们通过看波形图，可以判断这个代码写的对不对，然后去 debug 。

写仿真文件并跑仿真：
1. 点 **Add Sources** → 这次选 Add or create **simulation** sources → Next → Create File，文件名 `（工程名字）_tb` → OK → Finish，Define Module 窗口直接 OK、Yes。
2. 在 Sources 窗口展开 **Simulation Sources** → sim_1，双击 `（工程名字）_tb.v`，编写测试代码。
3. 保存。确认 Simulation Sources 里 `（工程名字）_tb` 是加粗的（作为仿真的顶层）。
4. 左侧 Flow Navigator 点 **Run Simulation** → **Run Behavioral Simulation**。
5. 波形窗口打开后，Vivado 默认只跑 1000ns。点上方工具栏的 **Run All**（或按 F3）让它跑到 `$finish`，再点放大镜旁边的 **Zoom Fit** 看全图。

仿真确定没问题之后，就可以写约束文件了。约束文件的作用是把代码中的变量，绑定到实际芯片的引脚上面。

写约束文件：
1. **Add Sources** → 选 Add or create **constraints** → Next → **Create File**，文件名 `（工程名字）` → OK → Finish。
2. 在 Sources 窗口展开 **Constraints → constrs_1**，双击 `（工程名字）.xdc`，查手册确定每个变量绑定什么引脚。
3. 保存。

生成 bitstream：
1. 左侧 Flow Navigator 最下面点 **PROGRAM AND DEBUG → Generate Bitstream**。如果提示要先跑综合和实现，点 Yes。
2. 它会依次自动做 Synthesis → Implementation → 生成 bitstream，也就是之前讲的整条翻译链。右上角会显示进度，要等几分钟。完成后弹出窗口，选 **Open Hardware Manager** → OK。

下载到板子：
1. 用 USB 线把 EGO1 连到电脑（接板子上标着 JTAG/UART 的那个口），打开板子的电源开关。
2. Hardware Manager 顶部出现绿色提示条，点 **Open target → Auto Connect**。
3. 连上后再点 **Program device**，弹窗里 bitstream 文件路径会自动填好，点 **Program**。
4. 下载完，就 OK 了。
