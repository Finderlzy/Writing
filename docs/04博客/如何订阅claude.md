## 整体思路
---
我的理解是：anthropic 会从很多地方判断你是谁、在哪里，比如 IP、DNS、浏览器、时区、账号地区、付款方式。**只要其中一项露出“我其实在国内”，就有风险。**

所以下面每一步，其实都在做同一件事：**让每一项信息都不露出“我在国内”，而且像一个普通用户。**

**整体流程：** 一、准备住宅 IP → 二、配置代理软件 → 三、防泄漏 → 四、改时区 → 五、注册 claude → 六、订阅 → 七、订阅之后。

这里面涉及好几个账号和环节，先看清它们的关系：

```
【你是谁】  Google 账号 ──注册/登录──▶ claude 账号
                                          ▲
【从哪来】  手机/电脑（tun、分流）──▶ 住宅 IP ──▶ claude.ai
            （注册、使用、订阅，全程都走这条线）     │
                                          │
【谁付钱】  支付宝 ─买─▶ 礼品卡 ─充值─▶ 美区 Apple ID 余额
                                   │
                                   ▼
                    在 claude iOS app 里升级，用余额付款
                    订阅加到你的 claude 账号上
```

**claude 账号是用 Google 账号注册的，和 Apple ID 没有关系**，美区 Apple ID 只负责付钱。

## 一、准备住宅 IP
---
这一块是最重要的，千万不要用万人蹬的机场节点。我们要的效果是：**anthropic 看到的是一个家庭宽带的 IP，而且只有你自己在用。**

下面三种方案都能达到这个效果，区别在于花多少钱、折腾多少：

| 方案                    | 链路                           | 折腾程度 | 适合谁          |
| --------------------- | ---------------------------- | ---- | ------------ |
| 一：普通服务器 + 住宅 IP（白嫖已失效，思路可参考） | 电脑 → VPS → 住宅 IP → claude.ai | 中    | 愿意跟着视频敲几行命令  |
| 二：住宅 IP 服务器           | 电脑 → 住宅 IP 服务器 → claude.ai   | 中    | 想自建，但不想再套一层  |
| 三：直接买住宅节点             | 电脑 → 住宅节点 → claude.ai        | 低    | 不想碰服务器，导入就能用 |

**选好方案后，只看对应的那一小节，看完直接跳到「确认出口 IP」**，其他方案不用看。

不管选哪种，买之前都先找商家要 IP，用 [ipinfo.io](https://ipinfo.io/what-is-my-ip)、[scamalytics.com](https://scamalytics.com/) 交叉测一下：IP 类型是“住宅/ISP”，风险分数低。不要用 ping0.cc。

拿不定主意的话，可以先看一位读者的实测：[[04博客/读者实测：方案一和方案三的住宅 IP 对比|方案一和方案三的住宅 IP 对比]]。他用五个检测网站对比了两个方案的延迟和风险评分。

>[!note] 为什么：机场 IP、机房 IP 和住宅 IP
>机场的 IP 是成百上千人在共用，很可能早就被 anthropic 标记过了。
>
>每个 IP 都登记在某个组织名下，网站一查就知道。VPS 放在机房里，IP 登记在云服务商名下，就是**机房 IP**，普通人不会从机房上网，所以容易被当成代理。**住宅 IP** 登记在电信运营商名下，是分给家庭宽带用的，看起来就是普通人在上网。检测网站上的 **ISP** 类型，指的是运营商的 IP 放在机房里长期固定使用，也算这一类。
>
>不用 ping0.cc，是因为它会暴露你国内的真实 IP。

### 方案一：普通服务器 + 白嫖住宅 IP

这是我之前用的方案，也是视频里录的方案。VPS 负责“翻出去”，住宅 IP 负责“最后一跳”。

>[!warning] 白嫖的住宅 IP 已失效
>2026-10-17 白嫖的住宅 IP 断连之后，这里**不再推荐具体的住宅 IP 商家**，但这个方案的思路还是可以参考的。不想自己找住宅 IP 的，直接看方案二。

**1. 买服务器**

在 [VoyraCloud](https://www.voyracloud.com/?ref_code=HYEWZ46M) 买一台云 VPS（我用的就是它家的云 VPS），按下表选：

| 选项   | 怎么选                                |
| ---- | ---------------------------------- |
| 系统   | **Debian 12**（不要选 Ubuntu）             |
| 配置   | 1 核 CPU、1 GB 内存就够                  |
| 流量   | 每月几百 GB 足够                         |
| 机房位置 | 美国、日本、新加坡等                         |

已经装成别的系统的，在商家后台把系统重装成 Debian 12；商家最高只有 Debian 11 的，选 Debian 11 也行，脚本会自动先升级到 Debian 12。

买完在商家控制台记下**服务器 IP** 和 **root 密码**。

**2. 准备住宅 IP**

原来这里推荐的是 proxy.qsu.hk 的免费住宅 IP，断连之后我把这部分推荐去掉了。

想继续走这个方案的话，需要自己找一个 **SOCKS5 协议**的住宅/ISP 代理，记下**住宅 IP、端口、用户名、密码**，第 3 步运行脚本时要填。买之前先找商家要 IP 测一下，买到之后在「确认出口 IP」里再统一测一次。

**3. 连上服务器，运行脚本**

1. 打开命令行：Windows 按 `Win + R` 输入 `cmd`；Mac 打开“终端”。
2. 输入下面的命令，`你的服务器IP` 换成真实 IP。问 `Are you sure...` 时输入 `yes`；出现 `password:` 时输入 root 密码（**屏幕不显示，正常**），回车。开头变成 `root@...:~#` 就连上了。

```bash
ssh root@你的服务器IP
```

3. 粘贴这行命令，回车：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Finderlzy/reality-setup/v2.0.2/setup.sh)
```

4. 问服务器 IP 对不对时，和你的一样就回车；问住宅代理时，依次填第 2 步记下的 IP、端口、用户名、密码。
5. 等几分钟（弹出紫色/蓝色对话框就回车；Debian 11 的服务器会先自动升级到 Debian 12，要多等 5～15 分钟），看到 `节点自测 Reality：成功` 和 `节点自测 Hysteria2：成功`。
6. 最后会打印两个节点，**通过剪贴板**或扫二维码导入代理软件，**不要发给别人**：
   - **主节点**：`vless://` 开头，平时用这个。忘了就运行 `cat /root/vless.txt`。
   - **备用节点**：`hysteria2://` 开头，主节点连不上或很慢时换它。忘了就运行 `cat /root/hy2.txt`。
   - 用 Clash Verge 的，见文末「用 Clash Verge 怎么导入？」。
7. 最后打印的“面板”几行**截图保存**，排查问题时要用。
8. 商家后台有防火墙/安全组的话，放行 **TCP 443 和 UDP 443**。
9. 升级过系统的（Debian 11 升到 12），最后会提示重启：找个方便的时候运行 `reboot`，节点会自动起来。

提示“住宅代理连不上”：去商家后台检查端口、账号密码、IP 白名单（把服务器 IP 加进去）、套餐是否生效，再运行一次命令。其他问题看文末「附：打开面板排查」。想重装看文末「装过了，想重装？」。

脚本内容公开在 [reality-setup](https://github.com/Finderlzy/reality-setup)，运行前可以先看一眼。

>[!note] 为什么：脚本帮你做了什么
>自建节点的好处是只有你自己在用，IP 不会被别人用脏。但普通云 VPS 的 IP 是机房 IP，anthropic 能识别出来，所以还要再套一层住宅 IP。
>
>脚本把原来要手动做的事一次做完：装 3x-ui 面板 → 建一个 VLESS + Reality 主节点（TCP 443）→ 建一个 Hysteria2 备用节点（UDP 443）→ 添加住宅 IP 出站，**只让 anthropic 相关的域名和 ipinfo.io 走住宅 IP**，其他网站照旧从 VPS 出去。这样住宅流量只花在刀刃上，也方便你用 ipinfo.io 检查出口。另外还开了防火墙、SSH 防爆破、BBR 和自动更新。
>
>两个节点访问 claude 时，出口都是同一个住宅 IP，所以换备用节点不算“换节点”。
>
>想自己动手、弄懂每一步的，看这两篇：[[04博客/自建梯子：VPS + 3x-ui + VLESS Reality|自建梯子：VPS + 3x-ui + VLESS Reality]]、[[04博客/给 VPS 节点套上住宅 IP|给 VPS 节点套上住宅 IP]]。

### 方案三：直接买住宅节点

完全不想碰服务器的话，就直接买现成的住宅节点。比如 ipequal，它卖的是 VLESS Reality 节点，出口是美国静态住宅 IP，国内直连，导入订阅链接就能用。

1. 在 ipequal 注册，购买套餐，**“使用类型”选 1 人独享**。我**没用过**，因为一直买不到，是看到很多大佬推荐才放在这里，建议先买一个月试试。
   - 还没有节点：[ipequal](https://www.ipequal.com/?ref=6adabd0307)（国内可直接打开）
   - 已经有节点：[ipequal](https://www.equaldcdn.com/?ref=6adabd0307)（需要开代理打开）
2. 复制订阅链接，导入代理软件（Clash Verge、v2rayN、小火箭等都支持，**尽量通过剪贴板导入**）。
3. 选中这个节点，开启代理。已经有节点的，也可以只让 claude 走住宅节点，见文末「分流规则具体怎么写？」。

>[!note] 为什么要选 1 人独享
>共享套餐是几个人用同一个 IP，和机场一个道理，用的人多了照样可能被标记。怎么间接确认是不是真的独享，见文末「“1 人独享”怎么确认真的只有我在用？」。

### 确认出口 IP

1. 开着代理打开 [ipinfo.io](https://ipinfo.io/what-is-my-ip)，页面最上面显示的就是你现在的出口 IP。它是住宅 IP、类型是“住宅/ISP”，就说明成功了。**把这个 IP 复制下来。**
2. 把复制的 IP 粘贴到 [scamalytics.com](https://scamalytics.com/) 等检测网站里查，风险分数低就可以用。不要用 ping0.cc。具体怎么看，见[[04博客/读者实测：方案一和方案三的住宅 IP 对比#怎么看 IP 质量|怎么看 IP 质量]]。

**记住这个 IP 所在的地区**，后面选时区、改 Google 账号地区时都会用到。

>[!note] 测出来不是住宅 IP？
>- 方案一、二：脚本已经让 ipinfo.io 走住宅 IP，测出来是 VPS 的 IP 的话，说明住宅出站没生效，看「附：打开面板排查」。
>- 方案三用了分流的：要把 `ipinfo.io` 也加进分流规则，否则测出来的是原来节点的 IP。

## 二、配置代理软件
---
1. **电脑开 tun 模式**。以 v2rayN 为例：右键 → **以管理员身份运行** → 主界面底部打开“启用 Tun”。
2. **确认 claude 走代理**。不管用“规则”还是“全局”模式，claude 相关的域名都不能直连。不放心的话，用 claude 时直接开全局。
3. **手机**：Shadowrocket 这类软件打开就行，确认 claude 走的是你的节点。
4. **用 claude 时固定用这一个节点，不要换来换去。**

>[!note] 为什么要开 tun
>普通的“系统代理”只对浏览器这类会读系统代理设置的软件生效。claude 的桌面客户端、系统发出的 DNS 查询可能不认系统代理，就会用国内网络直连出去，claude 就会看到你的国内 IP。
>
>tun（虚拟网卡）模式会在系统里虚拟出一张网卡，接管整台电脑的流量，不管软件认不认代理，都会被送进节点。iOS 上的 Shadowrocket 本身就是以 VPN 的方式接管整台手机，相当于自带 tun 模式。
>
>不换节点，是因为一会儿美国、一会儿日本，本身就很可疑。

## 三、防泄漏
---
就算 IP 换好了，还有几个地方可能会把你的真实位置漏出去。检测网站用 [browserleaks.com](https://browserleaks.com)，它把 IP、DNS、WebRTC 分开测；也可以用 [ipleak.net](https://ipleak.net/)，一个页面全测完。

### 1. DNS

1. 开 tun 模式（上一节已经做了）。
2. v2rayN → DNS 设置：国外域名用远程 DNS（`1.1.1.1` 或 `8.8.8.8`），并且通过代理查询。
3. v2rayN → 路由设置：“域名解析策略”选 `AsIs`。
4. 关掉浏览器的“安全 DNS”，或者把它也改成国外的 DNS 服务商：
   - Chrome：设置 → 隐私和安全 → 安全 → 关闭“使用安全 DNS”。
   - Edge：设置 → 隐私、搜索和服务 → 关闭“使用安全 DNS”。

**检测**：打开 [browserleaks.com/dns](https://browserleaks.com/dns)，结果里不能有国内的 DNS（比如 China Telecom、China Unicom）。

>[!note] 为什么：DNS 泄漏和“远程 DNS”
>访问一个网站之前，电脑要先问 DNS 服务器“这个域名对应哪个 IP”。如果这一步没走代理，而是问了国内运营商的 DNS，对方就知道你在国内，而且知道你在访问 `claude.ai`。
>
>tun 模式会把系统的 DNS 请求接管过来，这是最主要的一步。但浏览器自己的“安全 DNS”可能绕开代理软件自己去查，所以开了 tun 也要测。
>
>**远程 DNS**：`1.1.1.1` 是 Cloudflare 的 DNS 服务器，`8.8.8.8` 是 Google 的。“远程”指的是**通过代理**去问它们。重点在“通过代理”，而不在“国外”：用国内网络直接去问 `8.8.8.8`，对方看到的提问者还是你的国内 IP。所以**国外 DNS 不等于安全，查询也要走代理才行。**
>
>`AsIs` 让代理软件只按域名分流，不会为了判断走哪条线先在本地查一次 DNS。它是远程 DNS 的补充，不能代替上面的设置。

### 2. WebRTC

- Chrome / Edge：装插件“WebRTC Control”；或者在 uBlock Origin 设置里勾选“防止 WebRTC 泄露本地 IP 地址”。
- Firefox：地址栏输入 `about:config`，把 `media.peerconnection.enabled` 改为 `false`。

**检测**：打开 [browserleaks.com/webrtc](https://browserleaks.com/webrtc)，“Public IP”只能是你的住宅 IP。

>[!note] 为什么：WebRTC 泄漏
>WebRTC 是浏览器用来做语音、视频通话的技术。它为了建立连接，可能绕过代理，直接把你的真实 IP 暴露给网页。

### 3. IPv6

检测网站上如果出现国内的 IPv6 地址，在电脑网卡设置里关掉 IPv6。

>[!note] 为什么：IPv6 泄漏
>如果你家的网络有 IPv6，而代理没有接管 IPv6，IPv6 的流量可能会直接连出去。关掉是最简单的办法。

## 四、改时区
---
时区选 claude 支持的地区，比如台湾、新加坡；不确定就选住宅 IP 所在城市的时区，比如洛杉矶的 IP 就选 `America/Los_Angeles`。**中国大陆和香港不行。** 我选的是台湾。

**手机和电脑都要改。**

**电脑（Windows）**：设置 → 时间和语言 → 日期和时间 → 关闭“自动设置时区” → 手动选时区。改完可以在 browserleaks.com 的 JavaScript 页面里看看浏览器报告的时区对不对。

**iPhone**：
1. 设置 → 隐私与安全性 → 定位服务 → 系统服务（滑到最底下）→ 关闭“设定时区”。
2. 设置 → 通用 → 日期与时间 → 关闭“自动设置” → 手动选城市。

两步都要做。只做第 2 步的话，手机可能还会根据定位把时区改回来。

>[!note] 为什么：都是 UTC+8，还要改吗
>很早之前就有人说过：anthropic 会检测时区。
>
>时区不一定要和住宅 IP 的所在地一致，但要是 claude 支持的地区，也就是 claude 官方公布的可用国家和地区名单，中国大陆和香港不在里面，台湾在。我选台湾，是因为它和北京一样是 UTC+8，看时间不会别扭。
>
>北京和台北的时差一样，但浏览器能读到的不只是时差，还有时区的名字，比如 `Asia/Shanghai` 和 `Asia/Taipei`。名字对不上，一样会露馅。

## 五、注册 claude
---
### 1. 准备 Gmail（已有可跳过）

后面注册 claude 要用 Google 账号，注册美区 Apple ID 要用 Gmail（**QQ 邮箱现在已经不能注册美区 Apple ID 了**）。

1. **手机代理也配好**。Gmail 在手机上注册。
2. **下载 Gmail**。iOS 在 App Store 直接搜索 Gmail；安卓先下载 Google Play，再从里面下载 Gmail。Google Play 要从手机自带的应用商店或其他可信来源下载，来路不明的安装包可能被改过。
3. **创建账号**。打开 Gmail，在“设置电子邮件”里选择“Google”，点“创建账号”，跟着提示操作。手机号验证可以用 +86。

### 2. 修改 Google 账号关联地区（可选）

打开 policies.google.com/terms ，页面上会写“国家/地区版本”。如果显示的是中国大陆或者香港，可以在同一个页面里申请更改为住宅 IP 所在的地区。Google 会人工审核，可能要等一段时间，审核期间最好一直处在住宅 IP 的网络环境下。

### 3. 注册

1. **前面四节全部做完、检测都通过，再去注册。** 不要边注册边调。
2. **用 Google 账号注册。**
3. **一个 IP 不要注册好几个账号。**
4. **注册后先正常用几天，不要急着订阅。** 最好把免费额度用完，等它主动弹出升级提示，再订阅。

>[!note] 为什么：改地区、先用几天是必须的吗
>都不是硬性要求，是我的个人经验，anthropic 没有公布过相关规则。
>
>- **Google 账号地区**：我是用 Google 账号注册 claude 的，所以**个人觉得**让它和住宅 IP 对上会好一点，网上并没有依据。它指的是你的 Google 账号适用哪个国家/地区的服务条款，和 Google Play 的付款地区不是一回事，改了也不会删除你的邮件、云盘等数据。
>- **先用几天**：先留下一段正常使用的记录再订阅，看起来更像真实用户。等它主动弹出升级提示，也是同样的考虑。

## 附：购买未完成
---
出问题才需要看这一节。

我遇到过：在 app 里订阅 Pro 时提示“Purchase Not Completed”，付款被拒绝，没订阅上。我的建议是：**别自己硬扛，让 AI 带着你走完。**

1. **先问 AI**。把报错截图、App Store 账户设置的截图发给 AI（比如 claude 免费版、ChatGPT 都可以），说明你在用美区 Apple ID 订阅 claude 时提示购买未完成。它会帮你逐项检查设置，比如付款方式、账单地址、是否允许 App 内购买。
2. **按 AI 说的联系客服**。检查完还是不行的话，AI 最后一般会让你联系 Apple 客服。打开苹果自带的“支持”app（Apple Support），在里面找在线客服。
3. **注意账号的区别**。用来订阅的是美区账号，但“支持”app 里登录的是你 iCloud 的主账号，也就是国区账号。所以客服大概率会给你转接海外客服，对方说英文。**别担心，继续靠 AI**：客服发一句，你复制给 AI；AI 给出回答，你再复制给客服。开头记得让 AI 帮你跟客服说清楚，你要处理的是 App Store 上登录的那个美区账号，不是 iCloud 账号。
4. **最好的情况是客服让你等 72 小时**。我就是这样。客服会给你一个 Case ID，记下来。**这 72 小时里什么都别做**：不要尝试购买，不换账号，也不要改付款信息和账单地址。
5. **72 小时后再买**。还是失败的话，带着 Case ID 再联系客服，同样让 AI 帮你沟通。

## 附：打开面板排查
---
方案一、二的节点出问题时，用 SSH 隧道打开 3x-ui 面板查看。面板只监听服务器本机，外网打不开，这是脚本故意设置的。

1. 在**自己电脑**的命令行运行（换成你的 IP），输入 root 密码，**窗口不要关**：

```bash
ssh -L 8080:127.0.0.1:8080 root@你的服务器IP
```

2. 浏览器打开 `http://127.0.0.1:8080/访问路径`，用截图里的用户名密码登录。
3. 忘了就在第 1 步的窗口里运行：

```bash
cat /etc/x-ui/install-result.env
```

`XUI_WEB_BASE_PATH` 是访问路径，`XUI_USERNAME`、`XUI_PASSWORD` 是用户名、密码。

在服务器上运行 `node-selftest` 可以随时重新自测两个节点。

## 常见问题
---
这一部分是正文没展开的细节，卡住了再来查，不看也能照着正文做完。

### 用 Clash Verge 怎么导入？

Clash Verge 导入不了 `vless://`、`hysteria2://` 这种分享链接。在服务器上运行 `cat /root/clash.yaml`，复制全部内容，在 Clash Verge 里新建一个本地配置粘贴进去保存。两个节点都在里面，默认选中备用节点 Hysteria2，因为 Clash 的内核连 Reality 节点目前有兼容问题，还在排查。

### 装过了，想重装？

在服务器上运行同一行脚本命令就行。脚本发现装过会先问你，回答 `y` 删掉旧的重新装，回答别的什么都不动。重装后节点链接会变，代理软件里要删掉旧节点、重新导入。

**重装前先关掉电脑上的代理软件**（或者关掉 TUN / 全局模式），再 SSH 连服务器。不然 SSH 可能正好走的是这台服务器上的节点，脚本一删旧节点，SSH 就跟着断了，出现 `Connection to ... closed by remote host`，之后还可能连不上服务器。新版脚本遇到这种情况会提示你先关代理，什么都不删。已经遇到的，关掉代理（或者干脆重启电脑）再 SSH 连上，重新运行一次命令就好。

### “1 人独享”怎么确认真的只有我在用？

说实话，**没法百分百确认**，只能间接看：

- 连续几天测 IP，地址一直不变；
- scamalytics 上的风险分数一直很低，没有慢慢变高；
- 买之前问清楚商家，是“独享 IP”，还是只是“独享带宽”。

所以才建议先买一个月试试。

### 分流规则具体怎么写？

意思是只让 claude 相关的网站走住宅节点，其他网站照旧走原来的节点。方案一、二的脚本已经在服务器上做好了分流，不用管这一条；这里说的是方案三“已经有节点”的情况。

至少要包含这几个域名：`claude.ai`、`claude.com`、`anthropic.com`，再加上用来检测的 `ipinfo.io`。

**Clash Verge（mihomo 内核）**：在规则里加上下面几行，`住宅节点` 换成你的节点或策略组名字，并且放在其他规则前面：

```
- DOMAIN-SUFFIX,claude.ai,住宅节点
- DOMAIN-SUFFIX,claude.com,住宅节点
- DOMAIN-SUFFIX,anthropic.com,住宅节点
- DOMAIN-SUFFIX,ipinfo.io,住宅节点
```

**Shadowrocket**：在“配置”→“规则”里新增 `DOMAIN-SUFFIX` 类型的规则，域名同上，策略选住宅节点。

**v2rayN**：它的路由规则一般只能选“代理 / 直连 / 阻断”，不方便指定某一个节点。用 v2rayN 的话，最简单的办法是用 claude 时直接切到住宅节点。

看不懂也没关系：不分流，用 claude 时直接全局走住宅节点，最不容易出错。
