## 标签选择器

css是用来设计样式的，一个页面常见的可设计元素就是`<h1>`、`<body>`之类的。
```css
h1 {
  color: purple;
}
```

## 类选择器

可是我们自己设计页面的时候，肯定会出现很多别的元素，它们不是常见的那些，这个时候就需要**类**了。类在我看来就是自定义元素。

```css
.skill {
  color: green;
  font-weight: bold;
}

// 自定义一个skill元素的样式 
```

点号不是随便加的装饰，而是 CSS 语法==用来区分"我选的是标签类型"还是"我选的是自定义的 class 名"的标志==——没有点/井号前缀，浏览器就会把它当成标签名去找
