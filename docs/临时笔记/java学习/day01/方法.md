## 是什么

是函数。程序的**最小执行单元**。

## 定义方法

```text
public static 返回值类型 方法名(参数){
	...... ← 一堆代码
	
	return 返回值
}
```
> [!note] 补充
> 定义要写在类里面，`main`外面

> [!note] 补充
> `public`决定“谁能用这个方法”，`static`决定“这个方法属于类，还是属于对象”。

## 调用方法

`方法名(参数);`

## 为什么会有带返回值的方法？

`void`返回给了控制台，但是有的时候我们（调用者）需要拿到方法中得到的东西，所以有带返回值的方法


## 方法的重载

有一些方法，它们的名字相同（sum），它们所实现的功能相同（求和），但是**参数不同**，从而能够实现不同的求和。这种在同一个类里面，名字和功能相同，但是参数不同的方法，就是重载。因为参数不同，所以返回值可以不一样。

## 方法的内存

方法运行在**栈内存**里。每执行一个方法，方法都会**入栈**。在方法里面创建的变量，会随着方法的出栈而销毁。 ^d3bc4d

## 基本数据类型和引用数据类型

基本数据类型的空间中存储的是**真实的数据**，而引用数据类型的空间中存储的是**其他空间的地址**。因此，只要有`new`就是引用数据类型，因为`new`是在**堆**内存开辟新的空间，变量是创建在方法里的，而方法是[[方法#^d3bc4d|运行在栈内存里]]的。
