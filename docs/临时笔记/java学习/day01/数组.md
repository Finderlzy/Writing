## 定义

Java数组的定义和[[../../C++/类]]的定义很相似：
`数据类型[] 数组名 = new 数据类型[]`    -------    `类 对象名 = new 类`

## 初始化

Java把这种：`int[] arr = {1, 2, 3};` 称之为“静态初始化”。
把这种：`int[] arr = new int[3];` 称之为“动态初始化”。

我感觉动态初始化得是c++的[[../../C++/容器库/Sequence Container|vector]]这种。。。。。。不对，这只是初始化。vector是**动态数组**。

无所谓，一个名字而已

## 为什么那样子叫作”动态初始化“

刚刚问了gpt一个问题：
```text
java可以这么定义数组吗：

num = 10;
int[] arr = new int[num];

我觉得应该不可以，因为c和c++不行，而编程语言的语法是相似的
```

gpt说可以，然后我就知道为什么这样子叫做动态初始化了。甚至可以这样：
```text
Scanner sc = new Scanner(System.in);

int num = sc.nextInt();
int[] arr = new int[num + 1]; <---- 在里面再计算一下
```
