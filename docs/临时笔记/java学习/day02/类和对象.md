## 面向对象思想

“面向”可以理解为去使用，“对象”可以理解为一个具体的东西。因此面向对象就是**使用一个东西**。

## 类和对象是什么

类可以理解为**一种东西的设计图**，有了这个设计图，才可以创造出这种东西。而对象就是那个**具体的东西**。就好比汽车工程图是类，而具体的汽车（如兰博基尼）就是对象。

一个类里面会有——成员变量，可以理解为**属性**，名词；成员方法，可以理解为**行为**，动词。

## 使用类和对象

### 创建类

假设我要创建一个手机的类。一个手机会有品牌和价格这两个属性，然后手机可以用来打游戏，因此就有一个行为是打游戏。
```
public class Phone {  
    // 属性——成员变量  
    String brand;  
    double price;  
  
    // 行为——成员方法  
    public void playGame(){  
        System.out.println("play game");  
    }  
}
```

科学地创建一个类：[[封装]]。

### 创建对象

创建对象的语法：`类名 对象名 = new 类名();`
```
static void main(String[] args) {  
    // 创建一个手机对象  
    Phone p = new Phone();   
}
```

### 类的注意事项

一般而言，每一个Java文件尽量就定义一个类就好了，而且类名和文件名要保持一致。

到目前为止，我见到了2种类。一种是描述某种事物的类，这种叫做**[[标准的JavaBean|JavaBean]]类**；还有一种是像`main`的类，这种叫做**测试类**。

由于JavaBean类已经用来定义这种类了，所以一般都是在测试类使用JavaBean类。
