> 写于 2026-10-20

今天思考了一下昨天在[[03文章/《怎样花两年时间去面试一个人》|《怎样花两年时间去面试一个人》]]中遗留的那个问题：

“[[03文章/《怎样花两年时间去面试一个人》#^2a1f41|只是关于做项目，我其实是有一些疑问在的。这篇文章是好几年前的，他们那个时候是没有 agent 的，可能连 LLM 都还没有。而现在 agent 的 coding 能力是非常强大的，未来我们大概率不会完完全全手写代码，所以关于”如何做项目”，我认为我还得再寻找方法。]]” 

遇到问题，先尝试抽象问题，提炼出本质。“如何做项目”，这个问题太宽泛了，是要问：是什么、为什么还是怎么做？是什么。这个问题就不用回答了。

为什么？为什么要做项目。因为按照刘未鹏先生的方案，通过做项目，应聘者可以提升能力，招聘者可以透过项目了解一个程序员。可是那是过去，现在还是这样吗？

我开始回忆我和一位在字节实习过的学长的记忆。他提到，面试官会看你做的项目，问你问题。比如说：为什么用这个技术方案？你是怎么想到的？这个方案和那个某某某方案相比，优势在哪里？由于这是支离破碎的记忆，所以我是不完全认可的，但是我又不好意思再问学长，所以只好去别的地方查找资料了。我都有点想每次和前辈聊天都偷偷录音了。

我想起了之前写的《[[02笔记/专题/学习方法/面向实习的学习计划|面向实习的学习计划]]》，然后翻出了这张图片。
![[09附件/Pasted image 20261020101236.png]]

里面提到，相比于项目本身是什么，我们更应该在意的是：对于项目需求要有自己的思考。这和学长提到的，技术方案是类似的。

也就是说，在现在 agent 十分发达的现在，**我们需要向面试官证明的能力是：判断力**。判断需求该用什么架构、技术栈、模块的功能以及怎么组织。而对于具体的代码细节，就可以交给 agent 。

那么接下来的问题就是：如何提升技术判断力呢？

刷抖音的时候，我曾经刷到这样的视频：《当医学生去看病》。当医生问他“哪里不舒服”的时候，普通人是只能大概大概说出”肚子“、“手臂”之类泛泛的描述，但是医学生可以直接说出那一个部位。当医生问他“什么感受”的时候，普通人的回答往往是“疼”、“痒”、“发红”，而医学生则是一堆专业术语。最后医生盯着他看了一会，然后丢给他一张单子，说：“自己写要哪些药。”

我现在就是普通人，我的目标是医学生。

医学生是怎么有一定的判断力的呢？不难想到，学习。没有知识作为基础，他们不可能能够识别出这个部位和症状是什么。我们也同样，需要学习，当有了一定的知识，我们才能独立地判断这个需求要选择哪些架构。感觉在说废话。

有了一定的知识，医学生可以通过诊断来验证自己的理解，也就是实践经历。我们也同样需要，也就是做项目。那如何通过做项目来提升自己的判断力呢？这也就回到了上面没有回答的那个问题：“怎么做项目。”我认为，在有了知识的积累之后，就不能完完全全地把项目交给 agent 了，**我们要参与里面的所有决策**。自己先针对需求确定技术架构，和 agent 讨论，如果意见不同，则双方要给出各自的理由。

这么一看，其实和传统的教育方式没有什么太大的区别呀。我是不喜欢这种方式的，因为学习的时候很枯燥。也就是说：我不认同这么推理下来的结论。那是哪里出了问题呢？

我回忆了自己的学习经历，想起了自己通过研究如何订阅 claude 学到的东西。我觉得还有一条路，而且这条路更适合我。

我对很多的东西都感兴趣，那我不妨自己做一个。我先选定一个东西，我的目标就是做出它。而现在我什么都会，这个时候我就不得不去查资料，然后学习，学这个学那个。而不是跟着教程，从“hello world”开始，然后到函数......为什么这样和刚才那样不同呢，明明都是先学再做？我觉得，这个是因为兴趣。之前那个方案，我不是为了做东西而去学习，少了一个明确的目标。

那这样会不会偏离我最终想要去的公司呢？那就“选定一个东西”的时候，选一个，和我想要去的公司所做的产品，类似的东西。

梳理一下。

问题最开始是：“在 agent 时代，如何做项目？”我先把它抽象为了“为什么要做项目？”通过学长的传授以及之前写的文章，我得到了结论：**要向面试官证明我有技术判断力**。

自然而然地，引出了下一个问题：“如何提升自己的技术判断力？”最开始，我通过类比医学生，得到了和传统教育相同的路线（学习知识，然后做项目检验）。但是我不认可这个结论（因为学习的时候是枯燥的）。于是我从自己的亲身经历，得到了另一个结论：**通过项目驱动学习来学习，通过做项目提升技术判断力**。

而为了不偏离我想去的公司，最开始要好好决定这个项目是什么。

最后还有一个问题：“做项目的时候，具体要怎么做？”我的结论是：**完全参与到项目的决策中**，而不是当一个局外人、普通人。而具体的代码细节，花的时间可以少一点。
