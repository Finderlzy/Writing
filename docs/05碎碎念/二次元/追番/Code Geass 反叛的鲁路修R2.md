## 总体评价

==神中神==。与其他的战斗番完全不一样的立意和结局。传统的热血少年漫结局都是==靠着友情、爱的力量打败反派，世界恢复和平==；而鲁路修完全不一样——主角设计好了一切，背负一切的恨意死去，打败主角的正义使者和主角约定好守护这个世界，这种崇高的奉献，是我目前唯一见到的。

其实佐助的想法和这个有点像——佐助是发现：当人们有共同的敌人的时候，就会和平，于是就想自己当那个“敌人”。虽然也是背负一切的恨意，但是此时的和平是阴影之下的和平，每个人都在担心死亡的来临，这和鲁路修的光明的和平是不一样的，所以只是有一点像。

除此之外，这部番还让我明白一些政治的东西。比如说尤菲的“日本特区”为什么会双赢？我的理解是，日本人民想要一个没有差异的、公平的日本，”日本特区“可以做到。而鲁路修他们是”起义军“，也就是忠诚于日本的军队。所以只要尤菲愿意和zero联手，二者就能共赢。可如果zero不愿意，那么他们就是”反叛军“了。唉，很好的想法，可惜，偏偏那时Geass失控了。
