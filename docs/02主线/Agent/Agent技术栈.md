## 模型

==模型是大脑，它负责处理输入，经过思考之后，给出输出。==

## agent

可以叫做**智能体**，也可以叫做**代理人**，我觉得叫做代理人更加方便理解。

==模型是部署在远端的，无法直接操作用户本地的电脑，所以需要一个代理人。==
用户写指令 -> agent把指令发给模型 -> 模型思考后之后输出给agent -> agent根据指令去干活

指令一般是一段json代码，用来表示这个指令的含义，agent能理解。
```json
{
  "action": "edit_file",
  "file": "main.py",
  "change": "replace xxx with xxx"
}
```

## harness

agent在干活的时候需要一些工具，比如上面这个指令就是编辑文件，而==harness就是那个工具==，**具体是什么我还没有了解**。

除此之外，==harness还是能力==。比如记忆系统、上下文管理。

## mcp

==第三方厂家给各种大模型明确的标准，便于各种大模型调用这个第三方网站。==

有的时候，大模型想要调用外部网站的功能，比如说查看GitHub的某个项目。GitHub写了一个mcp server，只要模型按照GitHub的mcp写一个json，就能调用GitHub MCP Serve的提供的功能，里面就有查看项目的功能。
