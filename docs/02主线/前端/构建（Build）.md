浏览器只看得懂三件套，但是现代前端网页通常会使用**前端框架**来实现。里面就会有不是三件套的东西。

例如我今天学的[[Astro的初步了解|Astro]]：
```astro
---
import '../styles/global.css';
const pagetitle = "首页";
---
<title>{pagetitle}</title>
```

这些浏览器都看不懂。这个时候，就需要先构建源代码，==把源代码转化为浏览器看得懂的三件套==。除此之外，==构建的时候还会优化代码，把一些代码打包，以及压缩优化==。

构建结束后会一般会生成一个dist文件，这个一般就是最后传给浏览器的文件
