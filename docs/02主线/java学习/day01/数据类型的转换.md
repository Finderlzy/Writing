运算的时候，只要数据类型不相同，都会先转换数据类型，再继续运算

## 隐式转换（自动类型提升）
 
数据范围大小排序：byte < short < int < long < float < double。当数据范围小的和数据范围大的进行运算时，数据范围小的**转换为**数据范围大的。

特性：btye和short在进行运算之前都会先转换为int。

## 显示转换（强制类型转换）

数据范围大的是无法直接**赋值（不是运算）** 给数据范围小的，得先强制类型转换。

使用括号，括号里面是想要转换成为的数据类型。
```java
double a = 33.11;
int b = (int) a;
```
注意：显示转换是可能会出问题的。
