链表是一种线性的数据结构。

```cpp
struct Node{
    int value; // 链表存储的数据
    Node* next; // 指向下一个链表，所以是Node*
};
```

## 举例

### 例1
```cpp
// 定义节点结构
struct Node {
    int value;    // 数据
    Node* next;   // 指向下一个节点的指针
};

// 创建链表
Node* head = new Node;  // head是Node*类型
head->value = 24;      // 给第一个节点赋值
head->next = new Node; // 创建第二个节点
head->next->value = 8;
head->next->next = nullptr; // 最后一个节点指向null
```
![[../../09附件/Pasted image 20260715111121.png]]
注意：
- 创建head时，系统在==[[内存|栈空间]]的一个地址==上，写入了一个指针，指向[[内存|堆空间]]的数据
- 通过指针访问成员要用"->"

### 例2
```cpp
  Node a;      // 创建对象
  a.value = 1; // 直接访问成员
  a.next = nullptr;
```
![[../../09附件/Pasted image 20260715111530.png]]
这个时候是直接在栈空间的一个地址上，既写入了数据，又写入了一个指针。

## 强调

==变量名是栈空间的一个地址，不是指针==
