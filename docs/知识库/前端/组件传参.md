为了更好地复用，[[组件]]所表达的东西不一定是固定的，换句话说，==组件也有变量==。当这个变量是需要新页面的数据时，就需要传参

## 组件页（子组件）
```
// 组件在'Social.astro'
---
const { platform, username } = Astro.props;
---
```
==**Astro.pros**==，说明了`platform`和`username`这两个变量需要新页面传参

## 调用组件页（父组件）

```
---
import Social from './Social.astro';
---

// 传参的方式⬇
<Social platform="twitter" username="astrodotbuild" />`
```
这里给`platform`传入的值是“twitter”；给`username`传入的值是“astrodotbuild”

## Props默认值
`const { platform, username = "astrodotbuild" } = Astro.props;`

默认值写在**变量名后面**（`变量名 = 默认值`）

只有当对应属性**完全没传**（值为 `undefined`）时，才会使用默认值；传了就覆盖
