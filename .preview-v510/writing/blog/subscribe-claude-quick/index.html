您好，这个是免费测试活动的产品，是共享的，并发点高会导致有些人使用不了，这个在后台也查询不到，不包售后的，如果实在用不了可以重新购买一个试试，https://proxy.qsu.hk/
19.9优惠码：QIANSU998
999优惠码：DSKUGFU23

也就是说，这是免费测试产品，IP 是共享的，用的人一多就可能有人连不上，而且商家后台也查不到具体谁断了，不提供售后。对方的建议是重新买一个试试。

需要说明的是，以上是商家的说法，我原样转达，没有验证，也不代表我的判断。

更新：我已经把自己的原有账号换到了新的 IP 上，目前正常，过程写在了方案一断连后：给账号更换 IP。还没换的，先照着那篇准备好新节点、测过质量再换；换好之前，不要用这个账号反复登录、来回切换节点，免得把账号本身也搞出问题。

另外，有读者在商家这里买了 999 套餐的四个 IP，试过之后也全都连不上，ip 检测显示端口直接拒绝连接。也就是说，被拒的不只是免费白嫖的那部分。以上是读者自己的反馈，同样没有经过我验证。

一、准备住宅 IP

这里只写视频里的方案：普通服务器 + 住宅 IP。2026-10-17 白嫖的住宅 IP 断连之后，第 2 步不再推荐具体的住宅 IP 商家，但整体思路还是可以参考的。想直接买住宅服务器或住宅节点的，看原理版的方案二、方案三，做完回来接「确认出口 IP」。方案一和方案三的实测对比见读者实测。

不要用机场节点。

第 1 步：买服务器

在 VoyraCloud 买一台云 VPS，按下表选。注意买的是云 VPS，不是它家的住宅服务器（住宅服务器我买过一次，测出来是机房 IP，见原理版方案二）。

选项 怎么选
系统 Debian 12（不要选 Ubuntu）
配置 1 核 CPU、1 GB 内存就够
流量 每月几百 GB 足够
机房位置 美国、日本、新加坡等

已经装成别的系统的，在商家后台把系统重装成 Debian 12；商家最高只有 Debian 11 的，选 Debian 11 也行，脚本会自动先升级到 Debian 12。

买完在商家控制台记下服务器 IP 和 root 密码。

第 2 步：准备住宅 IP

  1. 自己找一个 SOCKS5 协议的住宅/ISP 代理。买之前先找商家要 IP 测一下。
  2. 在商家后台记下住宅 IP、端口、用户名、密码。
  3. 买到之后先不用测，等脚本跑完在「确认出口 IP」里统一测。

第 3 步：连上服务器，运行脚本

用 SSH 连上服务器：

  1. 打开命令行：Windows 按 Win + R 输入 cmd；Mac 打开“终端”。
  2. 输入下面的命令，你的服务器IP 换成真实 IP：
ssh root@你的服务器IP

  1. 问 Are you sure... 时输入 yes。

  2. 出现 password: 时输入 root 密码（屏幕不显示，正常），回车。

  3. 开头变成 root@...:~# 就连上了。

运行脚本：

  1. 粘贴这行命令，回车：
bash <(curl -fsSL https://raw.githubusercontent.com/Finderlzy/reality-setup/v2.0.1/setup.sh)

  1. 回答问题：
问题 怎么填
服务器 IP 是 xxx 吗？ 和你的服务器 IP 一样就回车，不一样就输入正确的
住宅代理 IP、端口、用户名、密码 第 2 步记下的

  1. 等几分钟（弹出紫色/蓝色对话框就回车；Debian 11 的服务器会先自动升级到 Debian 12，要多等 5～15 分钟），看到 节点自测 Reality：成功 和 节点自测 Hysteria2：成功。


  1. 最后会打印两个节点，通过剪贴板或扫二维码导入代理软件，不要发给别人：
    - 主节点：vless:// 开头的链接，平时用这个。忘了就运行 cat /root/vless.txt。
    - 备用节点：hysteria2:// 开头的链接，主节点连不上或很慢时换它。忘了就运行 cat /root/hy2.txt。
    - v2rayN：配置项 → 从剪贴板导入；手机 Shadowrocket 也是从剪贴板导入。用 Clash Verge 的看原理版用 Clash Verge 怎么导入？。
  2. 最后打印的“面板”几行截图保存。
  3. 商家后台有防火墙/安全组的话，放行 TCP 443 和 UDP 443。
  4. 升级过系统的（Debian 11 升到 12），最后会提示重启：找个方便的时候运行 reboot，节点会自动起来。

视频和截图里是旧版脚本

视频和截图录制时，脚本只有一个节点，端口是 8555。现在脚本改成了 443 端口，并多了一个备用节点，以本文为准。

想重装：先关掉电脑上的代理软件，再 SSH 连服务器，运行同一行命令，问到删不删旧的时回答 y。重装后要重新导入节点。不关代理的话 SSH 可能会断开、之后连不上，原因见原理版装过了，想重装？。

报错或连不上：看原理版的方案一和附：打开面板排查。

确认出口 IP

  1. 开着代理打开 ipinfo.io，最上面显示的就是你的出口 IP。类型是“住宅/ISP”就成功了。复制这个 IP，记下所在地区，第四节要用。
  2. 把 IP 粘贴到 scamalytics.com 查，风险分数低就行。不要用 ping0.cc。

二、配置代理软件

  1. 电脑开 tun 模式。以 v2rayN 为例：右键 → 以管理员身份运行 → 主界面底部打开“启用 Tun”。
  2. 确认 claude 走代理。不确定的话，用 claude 时直接开全局。
  3. 手机：Shadowrocket 这类软件打开就行，确认 claude 走的是你的节点。
  4. 用 claude 时固定用这一个节点，不要换来换去。

三、防泄漏

1. DNS

  1. v2rayN → DNS 设置：国外域名用远程 DNS（1.1.1.1 或 8.8.8.8），并且通过代理查询。
  2. v2rayN → 路由设置：“域名解析策略”选 AsIs。
  3. 关掉浏览器的“安全 DNS”：
    - Chrome：设置 → 隐私和安全 → 安全 → 关闭“使用安全 DNS”。
    - Edge：设置 → 隐私、搜索和服务 → 关闭“使用安全 DNS”。

检测：打开 browserleaks.com/dns，结果里不能有国内的 DNS（比如 China Telecom、China Unicom）。

2. WebRTC

  • Chrome / Edge：装插件“WebRTC Control”；或者在 uBlock Origin 设置里勾选“防止 WebRTC 泄露本地 IP 地址”。
  • Firefox：地址栏输入 about:config，把 media.peerconnection.enabled 改为 false。

检测：打开 browserleaks.com/webrtc，“Public IP”只能是你的住宅 IP。

3. IPv6

检测网站上如果出现国内的 IPv6 地址，在电脑网卡设置里关掉 IPv6。

四、改时区

时区选 claude 支持的地区，比如台湾、新加坡；不确定就选住宅 IP 所在城市的时区。中国大陆和香港不行。

电脑（Windows）：设置 → 时间和语言 → 日期和时间 → 关闭“自动设置时区” → 手动选时区。

iPhone：

  1. 设置 → 隐私与安全性 → 定位服务 → 系统服务（滑到最底下）→ 关闭“设定时区”。
  2. 设置 → 通用 → 日期与时间 → 关闭“自动设置” → 手动选城市。

两步都要做。

五、注册 claude

  1. 前面四节都做完、检测都通过，再注册。
  2. 用 Google 账号注册。
  3. 一个 IP 只注册一个账号。
  4. 注册后先正常用几天，最好用完免费额度、等它弹出升级提示，再订阅。

还没有 Gmail，或者想改 Google 账号的关联地区，看原理版的五、注册 claude。

六、订阅（iPhone）

安卓用户看原理版的六、订阅（iPhone）。

第 1 步：注册美区 Apple ID

已经有美区 Apple ID 的跳过。

  1. 浏览器（手机、电脑都行）打开 appleid.apple.com → 点右上角箭头 →“创建你的 Apple 账户”。


  1. 国家/地区选“美国”；姓名可以填拼音；生日要满 18 岁；邮箱用 Gmail；手机号可以用 +86。

  1. 完成邮箱和手机验证。
  2. 重新登录一次，确认地区是美国。付款方式不用填。

第 2 步：在 App Store 登录

  1. 打开 App Store（不是“设置”） → 右上角头像 → 拉到最底部，退出原账号。
  2. 登录美区 Apple ID。
  3. 配置账单寄送地址，付款方式不要动，保持“无”：
  4. 右上角头像 → 你的名字 →“账单寄送地址”（“付款方式”应该显示“无”）。

  1. 跳到“添加付款方式”页面，不用填，直接返回。

  1. 返回后进入“管理付款方式”，点下面的“账单寄送地址”→ 右上角“编辑”，填地址并保存。地址填免税州的（比如俄勒冈州），要真实存在、格式正确，网上能搜到。


  1. 搜 Claude，认准开发者是 Anthropic，下载。
  2. 设置 → 屏幕使用时间 → 内容与隐私访问限制 → iTunes 与 App Store 购买项目 → App 内购买项目 → 选“允许”。

第 3 步：买礼品卡充值

  1. 手机浏览器搜索 pockyt shop，打开 shop.pockyt.io，点左上角“游客”。


  1. 登录页“其他登录方式”选支付宝，在支付宝里授权登录。

  1. 在支付宝里：“美国”→“App Store & iTunes”→ 输入面额 → 购买。先买 2 美元，到账了再买 5 美元，一点点加。显示“缺货”的话，等页面上写的恢复时间再买。


  1. 在“订单”里复制礼品卡号码 → App Store → 右上角头像 →“兑换代码”→ 填入号码。


  1. 余额要比 claude app 里显示的订阅价格多一点。

不要买来路不明的便宜卡，可能是黑卡，兑换后 Apple ID 可能被锁。

第 4 步：在 app 内订阅

  1. 打开 Claude app，用 Google 账号登录你的 claude 账号。
  2. 点升级 → 选方案 → 用 Apple ID 余额付款。
  3. 订阅可以在 App Store → 右上角头像 →“订阅”里管理或取消。

提示“购买未完成”的，不要反复重试，看原理版的附：购买未完成。

七、订阅之后

  • 刚开始少用，慢慢增加使用量。
  • 一直用同一个节点、同一个住宅 IP。
  • 不要在很多设备上登录，没走代理的设备上绝对不要登录。
