整体思路与方案选型

这一章先不操作。我们把三件事讲清楚：Claude 的风控在看什么，你手里的几个账号分别管什么，以及两条节点方案怎么选。后面的步骤都建立在这三件事上。

风控在看什么

我的理解是：Anthropic 会从很多地方判断你是不是一个普通的海外用户，而不是只看你的 IP。至少包括这几项：

  • IP 的归属地和类型。 请求是不是来自 Claude 支持的国家？这个 IP 登记在家庭宽带名下，还是云服务商的机房里？
  • IP 的独享程度。 这个 IP 是不是有很多人同时在用？一个普通家庭不会有几十台设备昼夜不停地访问 Claude。
  • DNS 和 WebRTC 泄漏。 你在查域名、打网页电话的时候，有没有把国内的真实 IP 露出去。
  • 设备环境。 系统时区、浏览器语言、账号地区，是不是和 IP 对得上。
  • 账号和支付。 注册邮箱、应用商店地区、付款账单地址，是不是自洽。

只要其中一项露出“我在中国大陆”，或者“我像是在用劣质代理”，账号的风险就会升高。注意，这是经验判断，不是 Anthropic 公布的规则；也正因为它没有公布，我们才只能把每一项都尽量做对。

整套教程的核心其实只有一句话：让 Claude 能看到的每一项信息，都指向一个 Claude 支持地区的普通用户，并且用得像个普通人。

整体流程

下面这条线就是全书的顺序。每一步都在做同一件事：减少一处会露出“我在国内”的地方。

  1. 清理旧账号和配置
  2. 选择方案，准备节点和住宅 IP
  3. 导入代理软件，测 IP 质量，防泄漏，改时区（客户端配置与环境验证：电脑端）
  4. 配置手机，注册 Gmail，登录 Chrome，先用两天，修改 Google 账号地区，注册 Claude
  5. 订阅（iPhone 走 iOS 端，安卓走 安卓端）
  6. 日常维护与故障处理

账号和链路的关系

先把几个容易混的东西分开：

  • Google 账号（Gmail）：你的核心身份，用来注册并登录 Claude。
  • 美区 Apple ID 或 Google Play：只是付款通道，用来绕开国内的银行卡。
  • Claude 账号：用 Google 账号注册，和 Apple ID 没有绑定关系。

也就是说，Claude 账号是用 Google 账号注册的，和 Apple ID 没有关系；美区 Apple ID 只负责付钱。哪怕支付账号之后受限，你的 Claude 账号本身仍然是独立的。

链路上则是三层：

你的电脑 / 手机
      ↓  加密、伪装
海外服务器（节点）
      ↓  最后一跳
住宅 IP
      ↓
Claude 官方服务器

方案一和方案二的区别，只在于“住宅 IP”这一层是自己套上去的，还是服务器本身自带的。

清理旧账号和配置

在开始之前，先把旧环境清掉。

你之前登录过的账号、用过的配置，都是在原来的网络环境下留下的，里面可能带着“我在国内”的信息。新账号一登录，这些旧信息就可能跟着过来，后面做得再干净也白费。

要清理的地方有三个：网页端、Claude Code、手机 App。

打开 claude.ai，点左下角头像 → Settings → Account，在“Log out of all devices”这一行点 Log out。如果你在这台电脑上用过 Claude Code，换另一个 Agent，让它清掉本机 Claude Code 的缓存和配置（比如 ~/.claude.json 及相关文件）。手机上装过 Claude App 的，在 App 里退出登录；也可以直接卸载重装。

方案一和方案二

要让请求以“独享住宅 IP”的形态到达 Claude，有两条路。它们的目的完全一样，成本也差不多，区别在稳定性和实现复杂度。

对比项 方案一：普通 VPS + 住宅 ISP 代理 方案二：住宅 IP 服务器（我用的）
工作原理 买一台便宜的机房 VPS，在它外面套一个静态住宅 ISP 代理，访问 Claude 时由 ISP 出去 服务器本身的出口就是住宅 IP，不需要再套一层
主要优点 VPS 可以随时换，只要住宅 IP 不变；成本和流量可以分开控制 结构简单，一台机器搞定，少维护一个代理环节
主要缺点 多一层转发，多一个服务商；分流规则和故障点也更多 纯住宅服务器单价更高，机器配置通常比较基础
适合谁 愿意折腾服务器、想自己控制每一层的人 想省事、希望一台机器解决的人
对应章节 方案一：搭建专属住宅代理节点 方案二：配置住宅 IP 服务器

为什么不推荐直接买住宅节点

市场上也有商家直接卖做好的“住宅节点”，给你一条订阅链接，导入代理软件就能用。这种方式最省力，但有一个关键问题：你很难确认这个节点是不是真的 1 人独享。

如果商家把同一个住宅出口卖给了多个人，只要其中一个人行为不端，你的 Claude 账号就可能被连带封禁。自己搭节点，出口和凭证都在自己手里，这个问题才可控。所以这一版不再把“直接买节点”作为推荐路线；如果你已经在用，至少先确认商家说的是“独享 IP”，而不只是“独享带宽”。

接下来怎么选

  • 愿意折腾，想自己控制服务器和住宅出口：去 方案一。
  • 想省事，直接买一台自带住宅 IP 的服务器：去 方案二。

不管选哪个，最后都要回到电脑上导入代理软件、测 IP、防泄漏、改时区。那部分在 客户端配置与环境验证：电脑端。
