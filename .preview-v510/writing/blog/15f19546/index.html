前言

我想订阅 Claude。

在那之前，我一直在用 GPT。它很强，第一次使用 gpt-6-astra 的时候，给我极大的震撼；但每次回答都很长，读起来有点累。后来我想起 Claude：有一次我把自己写的文章给它看，它的回答让我高兴了很久。于是我开始琢磨两件事：怎么订阅它，以及怎么不被封号。

真动手的时候才发现没那么简单。我先去 B 站找教程，没找到合适的；又去 X 上翻，找到一些，但很多看起来像广告。最后只能自己一点一点试。这篇教程就是那条路的记录。

先说清楚它是什么：一个普通人碰巧走通的一次经验，不是标准答案，也不是保证。我的订阅到现在还不到一个月，时间还短，没法保证这套方法长期有效，只能说它目前对我管用。

我也出过事。2026-10-17，教程里原来推荐的一条免费住宅 IP 线路被商家切断了，没有提前通知。那家商家说的是“永久免费”，我信了，也没在教程里提醒大家：免费得来的东西随时可能被收回。跟着做的朋友因此白花了时间，有的还花了钱。我后来找到了换 IP 的办法，一个个去通知，但这件事让我明白，光写一句“风险自负”不够，得把风险摆在你面前，让你自己判断。

流程有点繁琐，因为每一步都是我踩过坑之后留下来的。我会尽量把每一步“在干什么”“为什么要这么做”讲清楚。这样就算哪天某个细节失效了，你也知道该往哪个方向调。文中没写到的情况，我不一定能给出答案，请多包涵。

开始之前，先想清楚这几件事

  1. 要花钱。 Claude 本身的订阅费是每月 20 美元；网络环境也要钱。我用的是方案二，住宅 IP 服务器每月 9 美元。
  2. 会失败。 钱花出去了，也可能付款失败，也可能刚订阅就被封号。请先确认自己能承担这笔试错成本。
  3. 会失效。 文中提到的商家都是小商家，线路、价格、政策随时可能变。越便宜、越“免费”的东西，越要做好它哪天突然没了的准备。所以建议一律先按月买，确认能稳定用了再续费。
  4. 要自己动手。 中途卡住很正常，耐心一点。真卡住了，后记里有交流群，可以来群里一起排查。

如果你不能承担账号被封、钱打水漂的风险，可以再去找找别的方法。很遗憾，我没法保证你跟着走就一定不会被封。

关于文中的推广链接

还有一件事要坦白：文中的购买链接都是我的推广链接。通过它们购买，你的价格只会低，不会高，但我会拿到一点佣金。介意的话，直接搜商家名字就行。

每个链接后面都写了我自己有没有用过；没用过的是很多大佬推荐的，请自己判断。
