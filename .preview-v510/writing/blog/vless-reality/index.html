下篇：给 VPS 节点套上住宅 IP

这篇教程会带你从零搭一个只给自己用的节点。做完之后，你的电脑和手机都能通过自己的服务器上网。

整体流程： 买 VPS → 远程连上 VPS → 安装 3x-ui 面板 → 放行端口 → 在面板里建节点 → 把节点导入电脑/手机。

你需要准备： 一台电脑、一个支持银行卡或支付宝的支付方式。大概需要 30–60 分钟。不需要编程基础，所有命令都可以直接复制粘贴。

原理放在文末，想先搞懂再动手的可以先看原理。

一、购买 VPS

VPS 就是一台放在国外机房、24 小时开机的云服务器。我们要做的，是让它替你访问外网。

这是我使用的购买网站：https://www.voyracloud.com/?ref_code=HYEWZ46M

这是我的推广链接。通过它购买，你的价格只会低，不会高，但同时我会拿到一点佣金。不介意的话可以用，介意的话直接搜商家名字就行。

二、远程连接 VPS

VPS 在云端，没法直接操作。我们用 SSH 连上去，连上之后你的命令行窗口就相当于 VPS 的终端，在里面输入的命令都是在 VPS 上执行的。

1. 打开本地命令行

  • Windows：按 Win + R，输入 cmd 回车；或者在开始菜单搜索"PowerShell"。Windows 10/11 自带 SSH，不用另外安装。
  • Mac：打开"启动台"，搜索"终端"。
  • Linux：打开"终端"。

2. 连接

输入下面的命令，把 你的服务器IP 换成真实 IP：

ssh root@你的服务器IP

接下来会依次出现：

  1. 第一次连接会问 Are you sure you want to continue connecting (yes/no/[fingerprint])?，意思是"是否信任这台主机"，输入 yes 回车。
  2. 然后出现 root@xxx's password:，输入 root 密码。输入密码时屏幕不显示任何字符，这是正常的，输完直接回车。密码可以复制后在命令行里右键（或 Ctrl + Shift + V）粘贴。

看到命令行开头变成 root@...:~# 就说明连上了。

3. 看命令前先搞清两件事

命令在哪里运行。 本文的命令分两种：

  • 在 VPS 上运行（绝大多数）：apt、x-ui、ufw、ss、curl 这些，都要在 SSH 连上之后、开头是 root@...:~# 的窗口里输入。
  • 在 本地电脑 上运行（只有两条）：ssh root@... 和 ssh -L ...（SSH 隧道），在没连 SSH 的命令行窗口里输入。

不管你用的是 Windows 还是 Mac，VPS 上的命令都一样，因为它们是在 VPS（Linux）上执行的。

中文要替换。 命令里的中文（你的服务器IP、面板端口、访问路径、节点端口）都是占位符，要换成你自己的实际值再运行。直接照抄会报错，比如：

直接照抄 报错
ufw allow 面板端口/tcp ERROR: Bad port
curl -k https://127.0.0.1:面板端口/访问路径/ URL using bad/illegal format

三、安装 3x-ui

3x-ui 是一个网页管理面板，让你用点鼠标的方式配置节点，不用手写配置文件。

版本说明

本文按 2026 年 10 月的 3x-ui 版本编写。脚本更新后，问题的顺序和措辞可能略有不同，但意思基本一样。

1. 更新系统

刚买的服务器，软件一般不是最新的，先更新一下：

apt update && apt upgrade -y
apt install curl wget -y
  • 第一行更新系统软件，可能要跑几分钟，等它结束、重新出现 root@...:~# 再进行下一步。
  • 中途如果弹出紫色/蓝色的对话框（比如问要不要重启某些服务），直接按回车选默认项。
  • 第二行安装下载工具 curl 和 wget，后面的安装脚本要用。

2. 安装前：放行 80 端口

安装过程中会给面板申请 SSL 证书（让面板能用 https 安全访问），申请时需要用到 80 端口。

  • 系统防火墙：新机器一般默认没开，不用管。
  • 商家后台：如果有防火墙/安全组，先在里面放行 TCP 80 端口。

3. 运行安装脚本

bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)

4. 回答安装问题

脚本会依次问你几个问题，按下表回答：

问题 怎么选 说明
数据库（SQLite / PostgreSQL） 选 1 SQLite（直接回车） 自己用完全够，PostgreSQL 是给几百个用户的大面板准备的
Would you like to customize the Panel Port settings? y 后填一个端口（比如 8080），或 n 让它随机生成 记下这个端口，后面放行防火墙要用
Choose SSL certificate setup method 选 2 Let's Encrypt for IP Address（直接回车就是它） 没有域名就选这个
Is xxx the correct incoming public IPv4 address? 确认显示的是你的服务器 IP，回车 如果不对，输入 n 再手动填
Do you have an IPv6 address to include? 没有就直接回车跳过
Port to use for ACME HTTP-01 listener 直接回车，用默认的 80 申请证书用的端口
Would you like to set this certificate for the panel? y 把证书装到面板上

申请证书时会刷出一大堆 [Thu Oct ...] 开头的日志，还有一段 -----BEGIN CERTIFICATE-----，都是正常的。看到 Certificate issued successfully 就说明成功了。

关于 IP 证书

证书有效期只有约 6 天，但会自动续期，不用管。前提是 80 端口一直保持放行，续期时也要用到它。

SSL 不要选 4（跳过）

选 4 后面板只能走不加密的 http，脚本接着还会问"是否只绑定 127.0.0.1"。如果答了 y，面板就只能通过 SSH 隧道访问，浏览器直接输入 IP 是打不开的。我第二次搭的时候就踩了这个坑，解决办法见面板打不开。

5. 保存面板信息

安装结束后，终端会打印一个 Panel Installation Complete! 的信息框，重点是这几项：

项目 说明
Username / Password 面板登录的用户名和密码（随机生成的）
Port 面板端口
WebBasePath 访问路径，一串随机字符，比如 L8pQzzPiF9SZJmHtAW
Database 数据库，应该显示 SQLite (/etc/x-ui/x-ui.db)
Access URL 完整的面板地址，形如 https://服务器IP:端口/访问路径，直接复制到浏览器就能用

一定要截图保存。 访问路径相当于面板的"暗门"，地址里少了它，面板是打不开的。

忘了也没关系，随时可以用下面的命令查看端口和访问路径（webBasePath 那一行就是访问路径，Access URL 是完整地址）：

x-ui settings

密码不会显示。忘了的话，输入 x-ui 打开管理菜单，选 7（Reset Username & Password）重新设置。

6. 认识 x-ui 管理菜单

直接输入 x-ui 会打开一个带编号的管理菜单，输入编号回车就能执行。常用的几项：

编号 功能
7 重置用户名和密码
8 重置访问路径
10 修改面板端口
11 查看当前设置（端口、访问路径、证书状态）
14 重启面板
16 查看运行状态
20 SSL 证书管理
23 防火墙管理

菜单底部的 Panel state 和 xray state 都显示 Running，就说明面板和代理内核都在正常运行。按 Ctrl + C 退出菜单。

四、开启防火墙并放行端口

这一步决定了外面能不能连到你的服务器。防火墙的作用是"只开需要的门，其他门全关上"。需要放行的端口有：

端口 用途 什么时候确定
22 SSH 远程连接 固定
80 申请和续期 SSL 证书 固定
面板端口 用浏览器打开 3x-ui 第三步安装时
节点端口 代理软件连接节点 第五步建节点时

两个端口都要放行

很多人只放行了面板端口，结果面板能打开，节点却连不上。面板端口和节点端口都要放行。

1. 安装并开启系统防火墙

很多 VPS 默认没有开防火墙，等于所有端口都对外敞开。用 3x-ui 自带的菜单开启：

  1. 输入 x-ui 打开管理菜单，输入 23（Firewall Management）回车；
  2. 在防火墙子菜单里输入 1（Install Firewall）回车。

它会自动安装 ufw（Ubuntu/Debian 常用的防火墙），放行 22（SSH）、80、443、2053、2096 这几个端口，然后开启防火墙。因为 22 已经放行，所以 SSH 不会断。

完成后输入 0 返回主菜单，再按 Ctrl + C 退出。

先放行 SSH

如果你不用菜单，而是自己用 ufw enable 开启防火墙，一定要先执行 ufw allow 22/tcp 放行 SSH，否则开启后 SSH 会立刻断开，你就连不回服务器了。

2. 放行面板端口和节点端口

上面自动放行的端口里没有你的面板端口，需要手动加上（把 面板端口 换成你的实际端口，比如 ufw allow 8080/tcp）：

ufw allow 面板端口/tcp

看到 Rule added 就成功了。

节点端口如果用 443，上一步已经放行了；如果用别的端口，同样执行一次：

ufw allow 节点端口/tcp

最后检查一下：

ufw status

第一行显示 Status: active，列表里能看到 22、80、443、面板端口（以及你的节点端口），就没问题了。

3. 商家后台的防火墙

有些商家在网页后台还有一层防火墙（可能叫"防火墙""安全组"）。这一层在 VPS 外面，ufw 管不到它。如果有，也要在里面放行上面这些端口，协议选 TCP。

4. 打开面板

在本地电脑的浏览器访问（注意是 https）：

https://服务器IP:面板端口/访问路径/

也就是安装结束时打印的 Access URL。

打开后是登录页，页面上有"语言"选项，可以切换为简体中文。用第三步保存的用户名和密码登录。

如果一直转圈、打不开，而端口也确实放行了，很可能是直连被干扰了（我就遇到了，而且是长期打不开）。原因见面板打不开。不用纠结，直接用下面的 SSH 隧道。

5. 用 SSH 隧道打开面板（直连打不开时用）

SSH 隧道的意思是：借着已经能连上的 SSH，把 VPS 上的面板"搬"到你本地电脑的一个端口上。它不受面板端口放行和线路干扰的影响，也更安全（面板端口甚至可以不对公网放行）。

在本地电脑新开一个命令行窗口（不是已经连着 VPS 的那个），运行：

ssh -L 18080:127.0.0.1:面板端口 root@服务器IP

输入密码登录后，这个窗口不要关。然后在本地浏览器访问：

https://127.0.0.1:18080/访问路径/
  • 浏览器会提示证书不匹配，点"高级"→"继续前往"。
  • 如果安装时没配证书，把 https 换成 http。
  • 窗口一关，隧道就断了，下次要用时再运行一次。

用隧道打开面板，导出的节点地址会变成 127.0.0.1

面板生成节点链接时，用的是浏览器地址栏里的地址。通过隧道访问时，导出的链接里地址就成了 127.0.0.1，导入代理软件后一定连不上。解决办法见第五步的导出节点链接。

6. 修改面板路径

安装时随机生成的访问路径不好记，可以改成你自己记得住的：

  1. 进入左侧菜单"面板设置"，找到面板路径那一栏，改成你自己的路径（别用 admin 这种太容易猜的）；
  2. 点"保存"，再点"重启面板"。

之后要用新路径打开面板：https://服务器IP:面板端口/新路径/。忘了的话，在 VPS 上运行 x-ui settings 就能看到。

五、创建节点

在面板里，入站 = 节点，客户端 = 用户。我们先建一个入站（节点），再给它加一个客户端（你自己）。

1. 添加入站

点击左侧菜单"入站" → "添加入站"。只需要填下面几项，其他都保持默认：

标签页 设置项 填写内容
基础配置 备注 随便写，方便自己认，比如节点所在地"洛杉矶"
基础配置 端口 推荐 443；被占用时改用 10000–65000 之间的端口
安全 安全 选 Reality
安全 目标 输入一个网站，比如 www.microsoft.com:443（冒号是英文冒号），输入完点旁边的"扫描"

填完滑到最下面点保存（按钮可能叫"添加"或"创建"）。回到入站列表，能看到刚建的节点，"启用"开关是打开的，就说明建好了。

为什么推荐 443

Reality 会把你的流量伪装成访问某个正常网站的 HTTPS 流量，而 HTTPS 默认就走 443 端口，用 443 最不显眼。

目标填什么网站

选大公司官网就行（比如上面的微软），要求是国内没被墙、不是你自己的网站。点"扫描"后结果不可用的话，换一个网站再试。

2. 检查点：节点端口放行了吗？

这一步最容易漏

漏了的话，导入软件后测速会一直超时。建好入站后，马上回到 VPS 终端确认一下。

先看 Xray 实际监听的端口：

ss -tlnp | grep xray

输出类似这样：

LISTEN 0  4096   127.0.0.1:11111   0.0.0.0:*   users:(("xray-linux-amd6",...))
LISTEN 0  4096   127.0.0.1:62789   0.0.0.0:*   users:(("xray-linux-amd6",...))
LISTEN 0  4096           *:8555          *:*   users:(("xray-linux-amd6",...))

找 *:端口 这一行，比如上面的 *:8555，节点端口就是 8555。127.0.0.1 开头的是 Xray 内部用的端口，不用管。

放行这个端口（443 在第四步已经放行过，可以跳过）：

ufw allow 节点端口/tcp

确认放行成功，列表里能看到节点端口就对了：

ufw status

商家后台有防火墙/安全组的话，也要放行这个端口。

3. 添加客户端

客户端就是"谁能用这个节点"。给自己用的话，建一个就够了。点击左侧菜单"客户端" → "添加客户端"，填下面几项，其他保持默认：

标签页 设置项 填写内容
基础 备注 随便写，比如 me
基础 关联入站 选择刚刚建的节点
凭据 Flow 选 xtls-rprx-vision，不要漏

保存即可。

4. 导出节点链接

回到"入站"列表，点击铅笔图标旁边的三个点（"菜单"）：

选择"导出链接"，会得到一段以 vless:// 开头的很长的代码。复制下来，下一步要用。

这段链接里包含了服务器地址、端口、UUID、公钥、SNI 等全部连接信息。它就是你节点的"钥匙"，不要发给别人或公开贴出来。

二维码

在"客户端"页面点开某个客户端，也能看到它的"链接"和"二维码"。手机导入时直接扫二维码最方便。

用 SSH 隧道打开面板的，一定要看这里。 链接里 @ 后面、端口前面的就是节点地址，比如：

vless://xxxxxxxx@127.0.0.1:8555?type=tcp&security=reality...

如果地址是 127.0.0.1，说明它用了浏览器地址栏的隧道地址，导入后肯定连不上。两种解决办法：

  • 临时改：导入代理软件后，打开节点详情，把"地址"改成你的服务器 IP。
  • 一劳永逸：在面板里编辑这个入站，打开"外部代理"（External Proxy），地址填服务器 IP，端口填节点端口，保存。之后导出的链接和二维码都会带上正确的地址。

常见问题

面板打不开

先确认面板本身在正常运行。 在 VPS 上运行：

x-ui status

看到 Active: active (running) 就说明面板在跑（按 q 退出）。然后在 VPS 上自己访问一次面板（换成你的端口和访问路径）：

curl -k https://127.0.0.1:面板端口/访问路径/

能返回一大段 HTML，说明面板没问题，问题出在你的电脑到 VPS 这段路上。

curl 加了 -I 返回 404 是正常的

curl -kI ... 发的是 HEAD 请求，面板不响应这种请求，会返回 404 Not Found。不要被它误导，去掉 -I 再试。

面板没问题的话，按顺序检查：

  1. 地址对不对：是 https 还是 http？末尾的访问路径有没有带上？最好直接复制 x-ui settings 里的 Access URL。
  2. 端口放行了没有：ufw status 里有没有面板端口，商家后台有没有放行。
  3. 是不是直连被干扰了：见下面的"TLS handshake error"。
  4. 面板是不是只监听了本机：见下面的"127.0.0.1"。

日志里一堆 TLS handshake error

x-ui status 输出的最后几行日志里，如果有很多这样的记录：

http: TLS handshake error from 你的本地IP:端口: read tcp ... i/o timeout

说明问题不在 VPS 上，而在你和 VPS 之间的线路上：TCP 连接已经到了服务器，但浏览器发出的 HTTPS 握手包在路上被丢掉了，服务器一直等不到，最后超时。"国外 IP + 非标准端口 + IP 证书"这种 HTTPS 连接特征很明显，很容易被识别和干扰。这种干扰时有时无，所以可能偶尔能打开，大部分时候打不开。

这时候怎么改防火墙都没用。SSH 隧道能进去，是因为它把面板流量包在 SSH（22 端口）里，外面看不出里面是 HTTPS，也就不会被拦。

想直接访问面板，可以试这几种办法：

办法 做法 效果
继续用隧道（推荐） 每次用面板前运行一次 ssh -L 命令 最稳；面板端口还可以不对公网放行，不会被扫描
换面板端口 x-ui 菜单选 10 改端口（比如 2053、2096 或 10000 以上的端口），ufw 和商家后台都要放行新端口 有一定概率有效，不保证
用域名访问 买一个域名解析到 VPS，用域名申请证书来访问面板 比 IP 直连隐蔽、稳定，但要花钱，步骤也多

面板只在建节点、改配置时才用，平时用不到，所以用隧道并不麻烦。具体步骤见SSH 隧道。注意用隧道打开面板时，导出的节点地址要改，见导出节点链接。

面板只监听了 127.0.0.1

在 VPS 上运行：

ss -tlnp | grep 面板端口
  • 显示 *:面板端口 或 0.0.0.0:面板端口：正常，问题不在这里。
  • 显示 127.0.0.1:面板端口：面板只允许 VPS 自己访问，外面当然打不开。这通常是因为安装时 SSL 选了"跳过"，又选择了只绑定本机。

解决办法：

  1. 先补上证书：输入 x-ui，选 11 查看设置，问到 Generate SSL certificate for IP now? 时输入 y，后面的问题都直接回车，最后问 Would you like to set this certificate for the panel? 时输入 y。
  2. 再取消"只绑定本机"：用 SSH 隧道进入面板，在"面板设置"里把"面板监听 IP"清空，点"保存"，再点"重启面板"。
  3. 再运行一次 ss -tlnp | grep 面板端口，变成 *:面板端口 后，就能用 https://服务器IP:面板端口/访问路径/ 直接打开了。

节点连不上

按顺序检查：

  1. 节点地址是不是 127.0.0.1：用 SSH 隧道打开面板时导出的链接，地址会变成 127.0.0.1。在代理软件里把地址改成服务器 IP，详见导出节点链接。我第一次导入到手机就是卡在这里。
  2. 节点端口有没有放行：系统防火墙和商家后台都要看，按第五步的检查点走一遍。测速一直超时，多半就是这两个原因之一。
  3. 在 VPS 上运行 x-ui，看菜单底部 xray state 是不是 Running；
  4. 客户端的 Flow 有没有选 xtls-rprx-vision；
  5. 客户端里的端口、UUID、公钥、SNI 是否和面板一致（用导出链接一般不会错，改过入站设置后记得重新导出）；
  6. 本地电脑或手机的系统时间是否准确，时间差太多也会连不上；
  7. 换一个 Reality 目标网站试试，有些网站不适合做伪装目标。

链接导入 Clash Verge 失败

不同代理软件用的内核不同：

软件 内核
v2rayN Xray-core
Clash Verge Mihomo
Hiddify sing-box

这三个内核都支持 VLESS + Reality，问题出在导入方式：v2rayN 和 Hiddify 可以直接粘贴 vless:// 链接；Clash Verge 主要使用 YAML 配置或订阅链接，直接粘贴不一定能导入。新手建议直接用 v2rayN。

原理

全局链路图

一句话原理

VPS 上运行代理服务端（Xray），你的设备作为客户端连过去，把流量加密后交给 VPS，由 VPS 替你访问目标网站。

代理协议是什么

代理协议是客户端（你的电脑）和代理服务器（VPS）之间约定好的一套通信规则，它解决这些问题：

  • 客户端怎么向服务器证明身份？
  • 客户端想访问哪个网站，怎么告诉服务器？
  • 数据怎么封装、加密、伪装？
  • 服务器怎么把数据转发出去，再把结果传回来？

本教程用的 VLESS 就是一种代理协议，Reality 则负责伪装。

3x-ui 和 Xray 的关系

3x-ui 只是一个可视化面板，真正干活的是底层的 Xray。部署后：

  1. Xray 在服务器的某个端口（如 443）上监听。服务器有公网 IP，只要有客户端连这个 IP + 端口，Xray 就会接收并处理。没有监听端口，外面根本找不到服务入口。
  2. 面板生成连接信息（地址、端口、UUID、公钥等），也就是你导出的那段链接。
  3. 你的代理软件用这些信息，主动连到服务器。

浏览器为什么会把请求发给 Xray

正常情况下，浏览器访问网站会直接连目标网站。但开了代理软件后，流量会先被它截下来：

  1. 代理软件在本地监听一个端口（比如 10808），或者用 TUN 模式接管整个系统的网络；
  2. 系统被设置成"所有流量先交给本地代理"；
  3. 代理软件按节点配置把数据重新封装、加密，再发到 VPS 上 Xray 监听的端口；
  4. VPS 解密后，替你访问真正的网站，再把结果传回来。

所以不是浏览器自己去连节点，而是代理软件在替你转发。不开代理软件，浏览器根本不会去连节点端口。
