前言

2026-10-17，方案一白嫖的住宅 IP 断了，用方案一的朋友现在都连不上 claude。商家的回复和读者的反馈如下（这一部分原来放在教程“一、白嫖 ISP”的开头，那一页现在已经删掉了）。

商家的回复是：

您好，这个是免费测试活动的产品，是共享的，并发点高会导致有些人使用不了，这个在后台也查询不到，不包售后的，如果实在用不了可以重新购买一个试试，https://proxy.qsu.hk/
19.9优惠码：QIANSU998
999优惠码：DSKUGFU23

也就是说，这是免费测试产品，IP 是共享的，用的人一多就可能有人连不上，而且商家后台也查不到具体谁断了，不提供售后。对方的建议是重新买一个试试。以上是商家的说法，我原样转达，没有验证，也不代表我的判断。

另外，有读者在商家这里买了 999 套餐的四个 IP，试过之后也全都连不上，ip 检测显示端口直接拒绝连接。也就是说，被拒的不只是免费白嫖的那部分。以上是读者自己的反馈，同样没有经过我验证。

之前我让大家先别用 claude，因为我在找办法把原有账号换到新的 IP 上。现在我自己换完了，账号目前正常，所以把过程写下来。

先叠个甲：这只是我自己换了一次的经历，只能说它目前对我管用，没法保证长期有效，也没法保证每个人都能成功。

整体流程： 准备新节点 → 隔一段时间 → 在网页端退出所有设备 → 再隔一小会 → 用新节点登录。

一、准备好新节点

旧的住宅 IP 已经断了，所以先得有一个新的、能用的节点。

一定要先测一下干不干净。 换 IP 就是为了让账号继续活下去，要是换上去的是一个机房 IP，或者风险分很高的 IP，那还不如不换。怎么测，见 测 IP 质量，测完 AS Type 是 isp、Privacy 是 false、Scamalytics 分数低，再往下走。

我是怎么准备的

我这次是去 VoyraCloud 买了一台住宅服务器，也就是方案二。买好之后照着 SSH 连接服务器 做，再导入代理软件就行。

为什么没去千宿网络的主站

千宿网络就是方案一里白嫖住宅 IP 的那家（proxy.qsu.hk），它的主站 qsu.hk 也卖住宅服务器。这次我没去它的主站买，原因是这次断连让我对它产生了不信任：

  • 它没有提前预告，直接就把活动产品的线路断了。
  • 商家的说法是并发高、拥堵了。但我个人更倾向于认为是主动切断，想把用户引到主站去买。这只是我的猜测，没有证据。

当然，它主站服务器的 IP 质量是不错的，这一点我不否认。介不介意，大家自己判断。

二、隔一段时间

新节点准备好之后，不要马上就开着它去登录 claude，先隔一段时间。

我的理解是：同一个账号，前一刻还在这个 IP，下一刻突然就跳到另一个 IP，看起来不太像一个普通人。隔一段时间再换，会自然一点。这是我的个人经验，没有依据。

三、在网页端退出所有设备

隔了一段时间之后，打开 claude 网页端，退出所有设备上的登录：

  1. 点左下角的账号（你的名字或头像那里），选 Settings。
  2. 切到 Account，找到 Log out of all devices，点右边的 Log out。
  3. 弹窗问你确不确定，点 Log out of all devices 确认。

这样网页端、桌面端、手机 app 上的登录都会一起退掉。操作过程我录了屏，放在文章最后。

四、再隔一小会，重新登录

退出之后，再过一小会，开着新节点重新登录 claude。

登录之前，记得确认代理软件用的是新节点，而且已经测过它的质量。能正常登录、正常使用，就说明换好了。

最后

最后，我想跟大家说声对不起。

方案一是我推荐的。说到底，是我贪心，图便宜，把一个免费活动产品写进了教程，结果让那么多人跟着我一起被这个商家坑了。线路断掉的这段时间，很多人担心自己的账号，不知道该怎么办，一直很焦虑。这些都是因为我，我真的非常抱歉。

也借这件事跟大家说一句：不管是谁推荐的东西，包括我，都要有自己的判断，不要盲从。 我的教程只是我自己的经历，我会犯错，商家也可能随时变卦。多看看、多测测，想清楚风险再决定。

我以后也会更加注意自己推荐的东西。我没办法把每一家都买来实测，但我推荐的每一家，都会写清楚为什么推荐它：是因为口碑，还是因为我自己测过。比如 DMIT，我推荐它是因为它是老牌商家，风评一直很好；丽萨和 VoyraCloud，则是我自己买来实测过的。理由写清楚了，大家就能知道这个推荐有多少分量，再自己判断要不要用。

完
