二、购买 ISP 代理

推荐买 Decodo。先说明：我自己没有用过 Decodo，推荐它只是因为它在 Proxyway 2026 年的 ISP 代理测试里排第一；它的价格很贵。不管在哪家买，都选 SOCKS5 协议，脚本只支持 SOCKS5。

买完在商家后台记下住宅 IP、端口、用户名、密码，下一步运行脚本时要填。住宅 IP 可能是一串域名，比如 r52u2gaa.isp201.iisp.asia，照着记下来就行。

先测一下质量

每个人拿到的 IP 都不一样，别人测出来好，不代表你拿到的也好，一定要自己测。

  1. 先关掉电脑上的代理软件，否则测出来的 IP 不对。
  2. 打开命令行：Windows 按 Win + R 输入 cmd；Mac 打开“终端”。
  3. 输入下面这行，用户名、密码、地址、端口 换成上面记下的：
curl -x socks5h://用户名:密码@地址:端口 https://ipinfo.io/json
  1. 返回结果里 "ip" 那一行就是出口 IP，把它复制下来。
  2. 打开 https://ipinfo.io/ 加上这个 IP（比如 https://ipinfo.io/1.2.3.4），看 AS Type 和 Privacy；再把这个 IP 粘贴到 scamalytics.com 查风险分。怎么看，见 测 IP 质量。

连不上的话：

  • 密码里有 @、:、# 这类符号，命令会被拆错。可以在商家后台换一个只有字母和数字的密码。
  • 商家后台有 IP 白名单的话，把你自己现在的 IP 加进去。

测出来质量不好

可以找商家客服换一个 IP，换完再测一次；也可以回到 选择方案，换别的方案。
