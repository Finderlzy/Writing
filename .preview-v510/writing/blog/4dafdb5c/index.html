改时区

时区选 claude 支持的地区，比如台湾、新加坡；不确定就选住宅 IP 所在城市的时区，比如洛杉矶的 IP 就选 America/Los_Angeles。中国大陆和香港不行。

手机和电脑都要改。

电脑

  • Windows：设置 → 时间和语言 → 日期和时间 → 关闭“自动设置时区” → 手动选时区。
  • Mac：系统设置 → 通用 → 日期与时间 → 关闭“使用你的当前位置自动设定时区” → 手动选城市。

改完可以在 browserleaks.com 的 JavaScript 页面里看看浏览器报告的时区对不对。

iPhone

  1. 设置 → 隐私与安全性 → 定位服务 → 系统服务（滑到最底下）→ 关闭“设定时区”。
  2. 设置 → 通用 → 日期与时间 → 关闭“自动设置” → 手动选城市。

两步都要做。

安卓

设置 → 系统 → 日期和时间 → 关闭“自动设置时区” → 手动选时区。不同品牌的菜单位置不太一样，找不到就在设置里搜“时区”。

上一步：防泄漏 ｜ 下一步：选择手机系统
