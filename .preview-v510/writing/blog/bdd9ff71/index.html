方案二：住宅 IP 服务器

1. 购买住宅服务器

在下面任选一家买一台住宅服务器：

  • VoyraCloud（我现在用的就是它家的住宅服务器：第一台测出来是机房 IP，后来买的一台是 ISP 类型，见 它的实测。）
  • QSU（主站的住宅服务器我没有使用过，有朋友说质量不错，见 它的实测。）
  • 丽萨主机（我买过一台它家的美国 9929 双 ISP 住宅 IP VPS，测出来是 ISP 类型，Scamalytics 5 分，见 它的实测。）

按下表选：

选项 怎么选
系统 Debian 12（不要选 Ubuntu）
配置 1 核 CPU、1 GB 内存就够
流量 每月几百 GB 足够

已经装成别的系统的，在商家后台把系统重装成 Debian 12。

商家最高只有 Debian 11 的，选 Debian 11 也行：脚本会自动先把系统升级到 Debian 12。

买完在商家控制台记下服务器 IP 和 root 密码。

商家说是住宅服务器，分到你手上的不一定真是住宅 IP。 买到之后一定要按 测 IP 质量 测一下，不是住宅 IP 的话，找商家退款或者换 IP。

2. 把服务器变成节点

照着 三、把服务器变成节点 做，问住宅代理 IP 时直接回车跳过（方案二不用套 ISP）。做完不要点那一页的“下一步”，直接去 导入代理软件。

上一步：选择方案 ｜ 下一步：导入代理软件
