账号注册与订阅全流程：iOS 端

这一章把账号和订阅一次走完：从注册 Gmail 开始，准备美区 Apple ID，用礼品卡充值，最后在 Claude 的 iOS App 里完成订阅。如果你已经有可用的 Google 账号，或者已经有美区 Apple ID，可以跳过对应的阶段。

先分清三个身份

动手之前，不要把下面几个账号搞混：

  • Google 账号（Gmail）：你的核心身份，用来注册并登录 Claude。
  • 美区 Apple ID：付款钱包。只在 App Store 登录，用来存放礼品卡余额。
  • Claude 账号：用 Google 账号注册，和 Apple ID 没有绑定关系。

付款的链条是这样的：

支付宝 ─买─▶ 礼品卡 ─充值─▶ 美区 Apple ID 余额 ─付款─▶ Claude 订阅

Anthropic 看到的付款方是 美区 App Store；支付宝只用来买礼品卡，不会直接出现在 Claude 的订阅里。

注册 Gmail

为什么不直接用国内邮箱？因为一个带有海外属性的 Google 账号，比国内邮箱更像一个普通海外用户；而且注册美区 Apple ID 时，QQ 邮箱也容易被拦截。先确认手机的代理已经打开，出口是你的住宅 IP。

打开 Gmail App，在“设置电子邮件”里选择 Google，点 创建账号，跟着指引走。姓名没有英文名就用拼音，出生日期要满 18 岁。如果要求手机号验证，可以用国内的 +86 手机号；这个验证是随机触发的，遇到就填，收短信即可。最后设置一个可靠的密码，并记好辅助邮箱。

视频 07-1：注册 Gmail

登录 Chrome，完善资料

Gmail 注册好之后，你就有了一个完整的 Google 账号。接下来在电脑上用它登录 Chrome，后面注册 Claude 会方便很多。确认电脑的代理已经打开，下载并安装 Chrome。

打开 Chrome，点右上角头像 → 登录，用刚注册的 Gmail 登录；再打开 myaccount.google.com，在“个人信息”里补上名字、头像、生日。一个真实用户的 Google 账号，这些资料一般是填好的；一个什么都没有的空账号，看起来就像刚注册来干别的事的。

视频 07-2：登录 Chrome 并完善 Google 账号资料

不要填付款信息

“付款和订阅”里什么都不要填，付款方式保持空着。绑一张国内的卡，等于直接告诉对方你在哪里。后面我们也用不到 Google 账号付钱。

先用两天

Google 账号也会封号。一个刚注册的新号，什么都没干，转头就去注册 Claude，有可能过几天 Google 账号自己先被封了，Claude 账号也跟着受牵连。所以建议先像普通人一样用两天：注册 X、Instagram，刷刷 YouTube，随便逛逛外网。

保持代理开着，让这个账号一直在你的住宅 IP 下活动；不要一上来就高频请求，也不要马上绑定支付信息。这两天里如果账号被封了，别慌，去 日常维护那章的申诉部分看怎么处理，一般很快能通过；一直没事，就继续往下走。

修改 Google 账号地区（可选）

Google 账号有一个“地区”，指的是你的账号适用哪个国家/地区的服务条款，和 Google Play 的付款地区不是一回事，改它不会删除邮件、云盘等数据。这一步不是硬性要求，只是我的个人经验，网上也没有明确依据。我的想法是：Claude 是用 Google 账号注册的，前面做了那么多，都是为了让每一项信息都对得上“我在海外”；如果 Google 账号地区还写着中国大陆或香港，就成了一个对不上的地方。不想改可以跳过。

保持代理开启，打开 policies.google.com/terms，页面上会写当前适用的“国家/地区版本”。如果显示的是中国大陆或香港，可以在同一页面申请更改到住宅 IP 所在的地区。Google 会审核，可能要等一段时间；审核期间最好一直处在住宅 IP 的网络环境下。

视频 07-3（可选）：修改 Google 账号地区

注册 Claude

终于到注册了。这一步本身很简单，用 Google 账号点几下就好；难的是注册之前和之后的讲究。注册是 Claude 第一次认识你，这一刻它看到的信息——IP、DNS、时区、账号——都会留下来；如果这时候还有哪一项没弄好，边注册边调，它第一眼看到的就是一个“有问题的人”，后面再补也晚了。

前面所有步骤都做完、检测都通过，再去注册。打开 claude.ai，点 Continue with Google，选择刚注册的 Gmail，按提示授权并完成注册，中途可能需要验证邮箱或手机号。

视频 07-4：注册 Claude

一个 IP 不要注册好几个账号。正常人一个人一个账号；同一个 IP 冒出一堆新账号，就像在批量注册。注册后先正常用几天，最好把免费额度用完，等它主动弹出升级提示，再去订阅；这也是我的个人经验，Anthropic 没有公布过相关规则。

注册美区 Apple ID

Apple ID 也分地区。国区 Apple ID 的 App Store 价格、能下载的 App、能用的付款方式，都是国区那一套。要用美区礼品卡、在美区 App Store 付款，就得有一个美区 Apple ID；已经有一个正常使用的美区 Apple ID 的，跳过这一阶段。

用浏览器打开 appleid.apple.com，手机、电脑都可以。点右上角的箭头展开菜单，选“创建你的 Apple 账户”。国家/地区选美国；姓名可以填拼音；生日要满 18 岁；邮箱用没注册过 Apple ID 的 Gmail；手机号可以用 +86。完成邮箱和手机验证后，重新登录一次，确认地区显示为美国。付款方式不用填。

视频 07-5：注册美区 Apple ID

只在 App Store 登录

iPhone 上有两个地方可以登录 Apple ID：“设置”里的和“App Store”里的。“设置”里的是 iCloud 账号，管照片、通讯录、备忘录；“App Store”里的只管买东西、下载 App。两边可以不是同一个账号，所以我们只在 App Store 里换成美区 Apple ID，“设置”里还是你原来的账号，照片和通讯录都不受影响。

不要在“设置”顶部登录美区账号

如果在 iPhone 的“设置 → 最顶部 iCloud”登录这个美区账号，相册、通讯录和备忘录会被云端合并同步，非常混乱。

打开 App Store，点右上角头像，拉到最底部，退出原账号，登录美区 Apple ID。首次登录外区账号，屏幕会提示“此 Apple 账户尚未在 iTunes Store 使用过”；点 检查（Review），打开“同意条款与条件”，点下一页。

接着配置账单寄送地址。点右上角头像 → 你的名字 → 账单寄送地址，这一页的“付款方式”应该显示“无”。如果跳到“添加付款方式”页面，不用填，直接返回；再进入“管理付款方式”，点下面的“账单寄送地址” → 右上角“编辑”，填一个免税州的真实地址，比如俄勒冈州。地址要真实存在、格式正确，但不一定是你所在的地址；网上搜“美国免税州地址”能找到。

最后在 App Store 搜索 Claude，认准开发者是 Anthropic，下载；再打开设置 → 屏幕使用时间 → 内容与隐私访问限制 → iTunes 与 App Store 购买项目 → App 内购买项目 → 选 允许。

视频 07-6：在 App Store 登录美区账号，配置账单地址，下载 Claude

为什么要填免税州

美区会按账单地址所在的州收销售税。填免税州就不会多扣钱；填了要收税的州，余额刚好等于订阅价格时，可能因为加上税不够扣而付款失败。

买礼品卡充值

美区 Apple ID 有了，但里面没有钱。我们又不能绑国内的卡，钱从哪来？答案是礼品卡。礼品卡就像一张充值卡：你花钱买下一串号码，把号码兑换到 Apple ID 里，余额就到账。我是在 Pockyt Shop 上用支付宝买的，这样支付宝只出现在“买礼品卡”这一步，不会出现在 Claude 的订阅里。

打开手机浏览器，搜索 Pockyt Shop，认准网址是 shop.pockyt.io。点左上角“游客”，在“其他登录方式”里选择支付宝，跳转到支付宝授权登录。在“美国”分类下选择 App Store & iTunes，输入面额购买：先买 2 美元，确认到账再买 5 美元，不要一下子买 20 美元；显示“缺货”的话，等页面上写的恢复时间再来。

买完在“订单”里复制礼品卡号码。回到 App Store → 右上角头像 → 兑换代码，填入号码，余额就充进美区 Apple ID 了。

视频 07-7：用支付宝买礼品卡并兑换到美区 Apple ID

买的时候注意：先小额，再慢慢加；不要买来路不明的便宜卡，便宜得离谱的可能是“黑卡”，兑换之后 Apple ID 可能被锁；余额要比订阅价格多一点，以 Claude App 里显示的价格为准，App 内价格可能和网页版不一样，还可能加销售税。也可以从别的靠谱渠道买，但不要买来路不明的便宜卡。

在 App 内订阅

为什么要在 Claude 的 iOS App 里订阅，而不是在网页上？因为只有在 App 里订阅，才能用 App Store 的余额付款；在网页上订阅，就要填银行卡。订阅会加到登录的那个 Claude 账号上：App 里登录的是用 Google 账号注册的 Claude 账号，付钱的是 App Store 里的美区 Apple ID，两边各管各的。

确认手机代理保持连接，出口是住宅 IP。打开 Claude App，用 Google 账号登录；点升级，选择方案，确认扣款来源是你的 Apple 账户余额，用面容 ID 或密码完成支付。

视频 07-8：在 Claude App 内用 Apple ID 余额订阅

订阅成功后，可以在 App Store → 右上角头像 → 订阅 里管理或取消。

如果提示“购买未完成”

订阅成功的可以跳过这一节。我遇到过：在 App 里订阅 Pro 时提示 Purchase Not Completed，付款被拒绝。我的建议是：别自己硬扛，让 AI 带着你走完。 因为这一步要和 Apple 客服打交道，而且很可能是英文客服；每一步该检查什么、该怎么跟客服说，AI 比我们自己摸索快得多。

先问 AI。把报错截图、App Store 账户设置截图发给 AI（Claude 免费版、ChatGPT 都可以），说明你在用美区 Apple ID 订阅 Claude 时提示购买未完成。它会帮你逐项检查，比如付款方式、账单地址、是否允许 App 内购买。检查完还是不行，AI 一般会让你联系 Apple 客服；打开苹果自带的“支持”App（Apple Support），找在线客服。

注意账号的区别：用来订阅的是美区账号，但“支持”App 里登录的是你 iCloud 的主账号，也就是国区账号，所以客服大概率会给你转接海外客服，对方说英文。继续靠 AI：客服发一句，你复制给 AI；AI 给出回答，你再复制给客服。开头让 AI 帮你跟客服说清楚：你要处理的是 App Store 上登录的那个美区账号，不是 iCloud 账号。

最好的情况是客服让你等 72 小时。我就是这样。客服会给一个 Case ID，记下来。这 72 小时里什么都别做：不要尝试购买，不换账号，也不要改付款信息和账单地址。72 小时后再买；还是失败，就带着 Case ID 再联系客服，同样让 AI 帮你沟通。

不要连续重试

反复点支付只会让风控更怀疑，可能把账号彻底锁住。

之后在电脑浏览器打开 claude.ai，用同一个 Google 账号登录，Pro 权益会自动生效。
